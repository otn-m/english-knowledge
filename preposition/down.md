# 認知言語学の観点に基づく英語 *down* の多義構造と概念拡張

## 1. 序論：*down* をどう捉えるか

英語の *down* は、前置詞、副詞、不変化詞（particle）、形容詞、名詞、動詞として用いられる高頻度語である。本稿では主に、前置詞・副詞・句動詞の不変化詞としての *down* を対象とし、その多義性を認知言語学・認知意味論の観点から整理する。*down the hill* のような物理的下降、*prices went down* のような数量の減少、*feel down* のような気分の低下、*write down* のような記録、*shut down* のような停止、*hand down* のような継承、*boil down* のような還元は、一見するとばらばらな語義に見える。しかし、多くの用法は、垂直軸、重力、接地、減少、安定、制御、終局状態といった関連する概念クラスターとして整理できる。

ただし、認知言語学的説明は、すべての用法が一つの原義から機械的に派生したことを証明するものではない。英語の句動詞には語史、慣用化、構文環境、コロケーション、談話上の慣習が深く関与する。したがって、本稿では *down* の多義性を「単一原理による完全な説明」としてではなく、身体的経験に基づく複数の意味クラスターが、慣用化した表現群の中で相互に関連しているものとして扱う。

### 1.1 身体化された認知と意味の基盤

認知言語学では、言語の意味は抽象的な記号操作だけではなく、身体を持った人間が環境と相互作用する経験と結びついていると考える。*down* の理解において基盤となるのは、人間が重力のある環境で生活しているという事実である。人は直立し、上方へ移動するには努力を要し、支えを失えば下方へ倒れる。水は低い方へ流れ、物体は落下し、身体の重心は休息や停止に伴って下がりやすい。このような経験は、垂直性（VERTICALITY）、経路（SOURCE-PATH-GOAL）、接触・接地（CONTACT/GROUNDING）、力（FORCE）などのイメージスキーマと関係する。

もっとも、「身体経験があるから必ずその表現が生じる」と短絡してはならない。身体経験は意味形成の重要な動機づけを与えるが、個別表現の成立には語彙化・構文化・社会的慣習が必要である。たとえば *write down* の *down* は、紙が物理的に下方にある経験と関係づけて説明できるが、だからといってすべての「記録」表現が必然的に *down* を取るわけではない。

### 1.2 イメージスキーマの階層性

イメージスキーマとは、反復的な知覚・運動経験から抽出される比較的抽象的な認知パターンである。Mandler らの議論を踏まえると、*down* の意味を考える際には、少なくとも次のような階層を区別できる。

| 認知構造のレベル | 定義 | *down* に関わる例 |
| :--- | :--- | :--- |
| 空間的プリミティブ | 物体の軌道、接触、包含、上下方向などの基本的な空間情報 | 物体が視野の中で上から下へ移動する、身体が座る・倒れる |
| イメージスキーマ | 経験から抽出される反復的な空間パターン | VERTICALITY、SOURCE-PATH-GOAL、GROUNDING、FORCE |
| スキーマ的統合 | 空間的構造と、感情・力・状態・評価などが結合した概念化 | *feel down*、*calm down*、*pin down*、*shut down* |

この区別は、*down* の説明を過度に単純化しないために重要である。*fall down* のような物理的下降は空間スキーマに近いが、*boil down to money* のような還元表現では、料理経験、量の減少、濃縮、議論の本質化という複数の要素が組み合わさっている。

### 1.3 多義性のネットワークとしての *down*

*down* の意味は、中心的な空間用法から放射状に広がるネットワークとして整理できる。ただし、中心義は一つに固定されるというより、「垂直軸における下方」「低い位置」「地面への接近」「活動・量・地位などの低下」という関連する中心クラスターとして捉える方が適切である。

本稿では、*down* の主要な意味領域を次のように整理する。

| 領域 | 典型的な意味 | 例 |
| :--- | :--- | :--- |
| 空間的下降・低位置 | 下方への移動、低い位置、坂・道に沿った移動 | *fall down*, *sit down*, *walk down the road* |
| 減少・低下 | 量、速度、温度、音量、強度の低下 | *prices go down*, *turn down the volume*, *slow down* |
| 感情・健康・評価 | 気分の落ち込み、病気、劣位、服従 | *feel down*, *come down with flu*, *look down on* |
| 停止・故障・崩壊 | 活動停止、構造崩壊、機能不全 | *shut down*, *break down*, *burn down* |
| 記録・固定・制御 | 書き留める、確定する、拘束する | *write down*, *pin down*, *nail down* |
| 継承・歴史 | 上位世代から下位世代へ伝える | *hand down*, *pass down*, *come down to us* |
| 現実化・本質化 | 具体的作業、本題、核心への還元 | *get down to business*, *boil down to* |
| 希釈・簡略化 | 質・濃度・複雑性を下げる | *water down*, *dumb down*, *play down* |

これらは相互に排他的ではない。たとえば *break down* は、機械の故障、議論の分解、精神的崩れ、交渉の決裂など複数の領域にまたがる。

## 2. 空間的プロトタイプ：垂直軸、重力、接地

### 2.1 下降移動と低位置

*down* の最も直観的な用法は、物理空間における下方への移動、または低い位置である。認知文法の用語で言えば、焦点化される対象をトラジェクター（TR）、基準となる対象をランドマーク（LM）とすると、*The ball rolled down the hill* では、ボールがTR、丘がLMであり、TRはLMの傾斜に沿って低い方向へ移動している。

この用法では SOURCE-PATH-GOAL スキーマが関与する。始点が高い位置にあり、経路が下方へ伸び、終点がより低い場所にある。ただし、*down* は常に純粋な垂直下降だけを表すわけではない。*walk down the street* の *down* は、必ずしも「坂を下る」ことではなく、話者が想定する方向に沿って道を進むことを表す場合がある。この場合、*down* は垂直性だけでなく、経路に沿った進行、地図上・通り上の方向づけ、場合によっては中心から周縁への移動を含む。

| 表現 | 中心的意味 | 注意点 |
| :--- | :--- | :--- |
| *fall down* | 重力に従って落ちる・倒れる | 制御喪失を含みやすい |
| *sit down* | 身体の重心を下げて座る | 休息・着席・安定化と結びつく |
| *lie down* | 横たわる | 活動から休息への移行を示す |
| *go down the hill* | 坂を下る | 垂直軸が明確 |
| *go down the road* | 道を進む | 垂直性より経路方向が前景化する場合がある |

### 2.2 重力の非対称性

上下の対立は幾何学的には対称に見えるが、身体経験においては非対称である。上へ移動するには筋力やエネルギーが必要であり、下へ移動する場合は重力が働く。支えを失えば倒れ、エネルギー供給が止まれば活動は低下し、最終的には静止する。この非対称性が、*down* の意味拡張に重要な役割を果たす。

ただし、この非対称性は常に否定的な意味を生むわけではない。重力に負けることは崩壊・敗北・病気・死と結びつきうるが、地面に落ち着くことは安定・休息・現実性・制御可能性と結びつきうる。*down* の理解で重要なのは、この二面性である。

### 2.3 視線、支配、接地

人間は直立しているとき、自分より低い位置にあるものを見下ろす。ここから、*look down on someone* のように、物理的な見下ろしが社会的・心理的な軽蔑へ拡張される。ただし、この拡張は単なる視線方向だけではなく、社会的階層、権力関係、評価語彙の慣用化とも結びついている。

一方で、地面は安定の基盤でもある。*settle down*、*down to earth*、*get down to business* では、浮遊・興奮・抽象性から離れ、安定した基盤や具体的作業に接触する感覚が前景化する。ここでは *down* は否定的ではなく、むしろ現実性や実行可能性を表す。

## 3. 減少・強度低下：LESS IS DOWN

### 3.1 量と垂直性の経験的相関

Lakoff と Johnson が論じた方向づけのメタファーの代表例に、MORE IS UP / LESS IS DOWN がある。物を積み上げると高さが増し、取り除くと低くなる。容器に水を入れると水位が上がり、減らすと水位が下がる。このような経験的相関により、数量・強度・温度・速度・活動水準といったスカラー量は、垂直軸で概念化されやすい。

| 表現 | 意味 | 概念化 |
| :--- | :--- | :--- |
| *Prices went down.* | 価格が下がった | 数値の減少を下方移動として捉える |
| *Turn down the volume.* | 音量を下げる | 音の強度を高さで捉える |
| *Slow down.* | 速度を落とす | 活動・速度の低下 |
| *Cool down.* | 冷える、落ち着く | 温度・興奮の低下 |
| *Slim down.* | 痩せる、簡素化する | 量・体積・規模の縮小 |

この用法はグラフ表現とも相互に補強し合う。グラフでは数値が増えると線が上がり、減ると線が下がる。しかし、グラフがメタファーの唯一の起源なのではない。数量と高さの対応は、グラフ以前の身体的・物理的経験にも根ざしている。

### 3.2 *calm down* とエネルギー準位

*calm down* や *slow down* における *down* は、単なる数量の減少ではなく、エネルギー準位や活動水準の低下として理解できる。興奮・怒り・不安は、心拍数の上昇、筋緊張、身体の活性化と結びつきやすい。これに対して落ち着くことは、身体的にも心理的にも緊張が緩み、重心が下がるような感覚を伴う。

このため、英語では *calm up* ではなく *calm down* が自然である。もっとも、これは英語の慣用化した表現であり、すべての言語で同じ方向づけが用いられるわけではない。さらに英語内部でも、*cheer up* のように気分の改善が *up* で表される場合がある。したがって、*down* は「悪い」だけでなく、「高ぶりを鎮め、安定状態へ戻す」方向にも機能する。

### 3.3 劣化・消耗としての低下

*wear down*、*run down*、*grind down* では、物理的・心理的な摩耗、消耗、機能低下が表される。*wear down a stone* は石が摩擦ですり減ることであり、*wear someone down* は人の抵抗力や意志を徐々に弱めることである。この場合、*down* は「厚み・力・抵抗力・機能水準の低下」と結びついている。

*run down* は、電池が切れる、建物が荒廃する、人が疲れ切る、誰かを非難する、車ではねるなど、複数の用法を持つ。これらをすべて単一の図式で説明するのは無理があるが、活動力の低下、状態の劣化、対象を下位に置く評価、物理的に倒す・衝突するという関連したクラスターとして整理できる。

## 4. 感情・健康・社会的地位

### 4.1 気分：SAD IS DOWN

*I feel down*、*He is down today* のように、*down* は気分の落ち込みを表す。これは、悲しみや落胆が身体姿勢の低下と結びつきやすいことに動機づけられている。人は落胆したとき、顔を伏せ、肩を落とし、背中が丸まり、視線が下がりやすい。この身体的反応が、感情表現のメトニミーとなり、さらに「悲しみは下」という概念メタファーとして定着していると考えられる。

ただし、HAPPY IS UP / SAD IS DOWN を単純な普遍法則として扱うことはできない。異文化間研究では、感情と垂直方向の対応に文化差が見られることがある。たとえば一部の言語・文化では、心が「下がる」ことが安定・満足と結びつくと報告されている。これは、英語にも *calm down* のように「下がること＝よい安定」となる用法があることと整合する。重要なのは、身体的基盤は共有されうる一方で、どの身体状態を肯定的に評価するかは文化や語彙体系によって変化しうるという点である。

### 4.2 健康・生命・機械の停止

健康や生命活動も垂直軸で概念化されやすい。活動可能な人は立っており、意識を失った人や死者は倒れる。ここから、HEALTH/LIFE IS UP、SICKNESS/DEATH IS DOWN という方向づけが生じる。

*come down with the flu* は「インフルエンザにかかる」という意味であり、病気によって活動水準が下がる感覚と結びつく。*strike down* は病気・神・暴力などが人を打ち倒すことを表す。*be down* は、サーバーやシステムが停止している状態にも使われる。ここでは、生きて活動している状態が「動作中・立っている・稼働している」ものとして捉えられ、停止した機械が「倒れた」「眠った」「死んだ」ように概念化される。

### 4.3 社会的地位・支配・服従

社会階層は、空間的高低として表現されやすい。*upper class*、*high status*、*look up to*、*look down on* といった表現が示すように、高い位置は権威・尊敬・優位と結びつき、低い位置は劣位・服従・軽視と結びつきやすい。

*put someone down* は、相手をけなす、侮辱する、評価を下げるという意味を持つ。*back down* は、主張や抵抗を撤回し、劣位を受け入れることを表す。*bow down* は物理的に身を低くすることで、服従や崇敬の態度を示す。*step down* は、役職という高い位置から降りることとして辞任を表す。

ただし、これらの表現は垂直性だけでなく、制度、儀礼、権力関係、慣用表現としての定着にも支えられている。*put down* には「物を置く」「動物を安楽死させる」「反乱を鎮圧する」「発言を書き留める」などの用法もあり、文脈によって意味が大きく変化する。

## 5. 記録・固定・制御：*write down* のクラスター

### 5.1 書き留めるという固定化

*write down*、*note down*、*jot down*、*copy down* における *down* は、情報を記録し、忘れられない形に固定することを表す。認知意味論的には、言葉や思考を揮発的・浮遊的なものとして捉え、それを紙や画面という媒体に定着させる操作として理解できる。

紙は多くの場合、机の上や視線より低い位置に置かれるため、書くことは物理的にも視線・手の動きを下方に向ける行為として経験される。しかし、重要なのは単なる物理的位置ではなく、「不安定な情報を安定した記録へ変える」という機能である。したがって *down* は、情報を操作可能で再参照可能な状態にすることを表している。

### 5.2 *write down* と *write up*

*write down* と *write up* の対比は、*down* と *up* のアスペクト的機能を理解するうえで有用である。

| 表現 | 焦点 | 典型的な用法 |
| :--- | :--- | :--- |
| *write down* | 記録・固定・保存 | 電話番号、アイデア、発言、メモを書き留める |
| *write up* | 整理・完成・公的形式化 | レポート、記事、実験結果をまとめる |

*write down* では、断片的な情報を失われないように固定することが中心である。*write up* では、素材を完成した形式へ仕上げることが中心である。この差は、*down* が接地・固定に、*up* が完成・提示・可視化に関わりやすいことを示している。

### 5.3 *pin down* / *nail down*：不確定性を拘束する

*pin down*、*nail down* は、動き回る対象をピンや釘で固定する物理的経験に基づく表現である。抽象的には、不明確な事実、曖昧な約束、逃げる相手、変動する条件を確定することを表す。

*pin him down to a date* は、相手に日付を確約させることであり、相手が曖昧さの中へ逃げ込む余地を狭める。*nail down the details* は、詳細を確定し、変更しにくい状態にする。この場合の *down* は、下方に押さえつけること、動きを止めること、制御可能な状態にすることと関係する。

## 6. 停止・破壊・完了・還元

### 6.1 *shut down* / *close down*：活動の停止

*shut down*、*close down* は、機械、店舗、工場、組織、システムの停止・閉鎖を表す。活動しているものは動いているものとして捉えられ、活動停止はエネルギーが失われ、運動が止まり、基底状態に落ちることとして概念化される。ここでは ACTIVITY IS MOTION、FUNCTIONING IS UP/RUNNING、NON-FUNCTIONING IS DOWN という複数の比喩が関与する。

コンピュータの *shut down* は慣用化した技術用語であり、単純な「落下」ではない。しかし、稼働状態を *up*、停止状態を *down* と呼ぶシステム用語とも整合する。

### 6.2 *break down*：故障・分解・崩れ

*break down* はきわめて多義的である。機械が故障する、交渉が決裂する、人が精神的に崩れる、物質を分解する、説明を項目ごとに分ける、という複数の用法を持つ。

| 用法 | 例 | 中心的な捉え方 |
| :--- | :--- | :--- |
| 故障 | *The car broke down.* | 機能的統一体が働かなくなる |
| 精神的崩れ | *She broke down in tears.* | 感情的制御が崩れる |
| 交渉決裂 | *Talks broke down.* | 社会的プロセスの構造が維持できなくなる |
| 分解 | *break down the data* | 複合体を構成要素へ分ける |

ここでの *down* は、崩壊・停止・分解・基礎要素への還元という複数の方向に広がっている。

### 6.3 *burn down* と *burn up*

*burn down* と *burn up* は、どちらも燃焼による完全な変化を表しうるが、事態の捉え方が異なる。

*burn down* は、建物・森・構造物が火災によって支えを失い、崩れ落ちることに焦点を当てる。垂直に立っていた構造が地面へ向かって崩壊するため、*down* が自然である。これに対して *burn up* は、紙、燃料、隕石、宇宙船などが燃焼によって消費され、煙や灰や熱として消えていくことに焦点を当てる。ここでは「崩れ落ちる」よりも「燃え尽きる」「消費される」ことが重要である。

したがって、宇宙船が大気圏で燃え尽きる場合は通常 *burn up* が自然であり、地上の家屋が火事で崩壊する場合は *burn down* が自然である。この差は、客観的事実だけでなく、話者が崩壊・消費・消失のどこに焦点を当てるかという事態把握にも依存する。

### 6.4 *boil down*：本質への還元

*It all boils down to money* の *boil down* は、料理の経験に基づく還元表現である。液体を煮詰めると水分が蒸発し、量は減るが、残るものは濃縮される。ここから、複雑な事態を余分な要素を取り除いて核心へ還元する意味が生じる。

この表現は興味深い。通常、LESS IS DOWN は減少や劣化と結びつきやすいが、*boil down* では量の減少が価値の低下ではなく、濃度や本質性の増加につながる。つまり、*down* は単なる下降ではなく、「余分なものが取り除かれ、底に残るものが核心として現れる」というプロセスを表している。

### 6.5 *water down* / *dumb down* / *play down*

*water down* は、液体に水を加えて濃度を下げることから、主張、法案、方針、表現などを弱める意味へ広がる。*dumb down* は、知的水準や複雑性を下げ、大衆向けに単純化することを表す。*play down* は、出来事や問題の重要性を低く見せる、軽く扱うことを表す。

これらでは、質、強度、重要性、知的水準が高さとして捉えられ、それを下げることが *down* で表される。ただし、*dumb down* にはしばしば批判的含意がある一方、*simplify* には必ずしも批判的含意はない。このように、語彙ごとの評価は慣用と文脈に依存する。

## 7. 時間・継承・歴史

### 7.1 *hand down* / *pass down*：世代を下る

*hand down*、*pass down* は、伝統、知識、財産、衣服、判決などを後の世代や後継者へ渡すことを表す。ここには、上位世代から下位世代へ、あるいは過去から現在・未来へ流れるという垂直的な時間観が関与する。

英語の *descendant* が「下る者」に由来するように、家系図ではしばしば祖先が上、子孫が下に配置される。また、川のメタファーで考えれば、過去は上流、未来は下流として捉えられることがある。*come down to us* は、文献・伝統・制度などが過去から現在の私たちへ伝わってきたことを表す。

ただし、英語の時間メタファーは垂直軸だけではない。*look forward to the future*、*look back on the past* のような前後軸も強力である。また、*up to now* のように、過去から現在までの蓄積を上方へ向かうものとして表す表現もある。したがって、英語における *down* の時間用法は、限定的な慣用クラスターとして扱うのが妥当である。

### 7.2 中国語などとの比較

中国語では、上／下が時間順序に体系的に用いられる。たとえば *上个月* は「先月」、*下个月* は「来月」を意味する。これは、英語の *hand down* や *down through the ages* と同様に、時間や順序を垂直軸で捉える例として比較できる。

ただし、言語が思考に与える影響については慎重な扱いが必要である。Boroditsky らの研究は、英語話者と中国語話者の空間時間マッピングに差がありうることを示唆したが、その解釈や再現性、影響の大きさについては議論がある。ここで重要なのは、垂直時間メタファーが英語にも中国語にも存在する一方、各言語での頻度、慣用化の程度、方向づけは異なるという点である。

## 8. 現実性・具体性・本題への移行

### 8.1 *down to earth*

*down to earth* は、現実的で、実際的で、気取らないことを表す。ここでは地面（earth）が、抽象的な空想や誇張から離れた現実の基盤として機能する。対照的に、*up in the air* は未確定・宙ぶらりんであることを表し、*have one's head in the clouds* は空想的・非現実的であることを表す。

この対立は、REALITY IS DOWN / FANTASY OR UNCERTAINTY IS UP として整理できる。ただし、英語では *high ideals* のように上方が肯定的に用いられる場合もあるため、*up* と *down* の評価は文脈依存である。

### 8.2 *get down to business* / *get down to brass tacks*

*get down to business* は、雑談や準備段階を終えて、本格的な作業に入ることを表す。*get down to brass tacks* は、細部や核心、実務的な本題へ入ることを意味する。これらでは、抽象的・周辺的・浮遊的な話から、具体的で操作可能な対象へ降りていく感覚がある。

*knuckle down* は、真剣に取り組むことを表す。語源的説明には諸説があり、ビー玉遊びなどで指の関節を地面につける姿勢と関連づけられることがあるが、確定的に断定するには慎重である。いずれにしても、現代英語では「腰を据えて取り組む」「逃げずに作業へ入る」という意味で定着している。

## 9. 句動詞における *down* の整理

*down* を含む句動詞は、空間スキーマだけでは完全には説明できない。多くは語彙ごとに慣用化しており、動詞との結合によって独自の意味を持つ。それでも、主要な意味機能を分類すると、学習上有用な見取り図が得られる。

| カテゴリー | コア・イメージ | 代表例 | 備考 |
| :--- | :--- | :--- | :--- |
| 空間的移動 | 下方・低位置・経路進行 | *sit down*, *fall down*, *go down the hill* | 垂直下降が典型だが、道に沿う用法もある |
| 減少・減衰 | LESS IS DOWN | *slow down*, *turn down*, *cool down*, *calm down* | 数量・強度・活動水準の低下 |
| 停止・閉鎖 | 活動停止・機能停止 | *shut down*, *close down*, *break down* | 機械・組織・交渉などに拡張 |
| 崩壊・破壊 | 構造の喪失 | *burn down*, *knock down*, *tear down*, *wear down* | 垂直構造の崩壊や抵抗力の低下 |
| 記録・固定 | 接地・拘束・制御 | *write down*, *note down*, *pin down*, *nail down* | 情報・約束・対象を動かない状態にする |
| 服従・劣位 | 地位の低下 | *back down*, *bow down*, *put down*, *step down* | 社会的・心理的上下関係 |
| 継承 | 世代・歴史を下る | *hand down*, *pass down*, *come down to us* | 垂直時間メタファーの限定的用法 |
| 本質化・具体化 | 核心・実務へ降りる | *boil down*, *get down to*, *knuckle down* | 余分なものを除く、現実の作業へ入る |
| 希釈・低評価 | 質・重要性の低下 | *water down*, *dumb down*, *play down* | 評価や強度を低くする |

この分類は、語義を固定するための絶対的な分類ではない。たとえば *put down* は、物を置く、発言を書き留める、相手を侮辱する、反乱を鎮圧する、動物を安楽死させるなど、複数のカテゴリーにまたがる。句動詞学習では、中心イメージを手がかりにしつつ、実際のコロケーションと文脈を確認する必要がある。

## 10. 類義的な *up* との対比

*down* の理解には、*up* との対比が役立つ。ただし、*up* と *down* は単純な反対語ではない。どちらも完了、強化、変化、状態移行を表しうる。

| 対比 | *down* | *up* |
| :--- | :--- | :--- |
| 空間 | 低い位置へ、地面へ | 高い位置へ、上方へ |
| 量 | 減少 | 増加 |
| 活動 | 鎮静・停止 | 活性化・開始・強化 |
| 完了 | 崩壊・停止・固定としての完了 | 消費・完成・可視化としての完了 |
| 例 | *burn down*, *write down*, *calm down* | *burn up*, *write up*, *cheer up* |

*burn down* と *burn up*、*write down* と *write up*、*calm down* と *cheer up* の違いは、単なる上下の反対ではなく、話者がどの局面に注目しているかを示す。*down* は、接地、低下、崩壊、固定、停止、本質への還元を表しやすく、*up* は、上昇、増加、完成、出現、可視化、活性化を表しやすい。ただし、どちらの語も句動詞として慣用化しており、個別に確認する必要がある。

## 11. 考察：*down* の意味を統一的に見る

*down* の多義性は、「重力」と「地面」という二つの経験的中心を軸に整理できる。重力は、崩壊・敗北・病気・死を生む力として否定的に機能する一方、休息・安定・鎮静・現実性・固定をもたらす力として肯定的にも機能する。地面は、落下の終点であると同時に、支え、基盤、現実、操作可能性の場でもある。

この二面性により、*down* は否定的な語ではなく、文脈によって評価が変わる語となる。*break down* は悪い意味になりやすいが、*calm down* は望ましい鎮静を表しうる。*put down* は侮辱にも記録にもなり、*boil down* は減少ではなく本質化を表す。このような多義性は、認知言語学的な意味ネットワークとして見ることで、丸暗記よりも体系的に理解しやすくなる。

一方で、認知言語学的説明には限界もある。個々の句動詞の意味は、身体経験だけでなく、歴史的発達、構文、慣用化、使用頻度、語用論的文脈によって定着している。したがって、*down* の理解では、中心イメージを過信せず、実際の用例を通じて意味範囲を確認することが重要である。

## 12. 結論

英語の *down* は、物理的な「下」だけを表す語ではない。垂直軸、重力、接地、低下、崩壊、鎮静、固定、停止、継承、現実化、還元といった複数の概念領域を結びつける、多義的な意味ネットワークを持つ語である。

このネットワークの中心には、身体を持った人間が重力下で生きるという経験がある。支えを失えば倒れ、活動水準が下がれば静まり、思考は記録されることで固定され、議論は煮詰められることで核心へ至る。*down* は、こうした経験を、空間・数量・感情・社会関係・時間・談話の領域へ写像するための語である。

ただし、*down* のすべての用法を単一の原理で説明し尽くすことはできない。むしろ重要なのは、身体的動機づけ、意味拡張、慣用化、構文、文脈が重なり合うことで、多義的な語の意味が形成されていると理解することである。この観点を取ることで、*down* の多様な句動詞や表現を、単なる暗記項目ではなく、一定のまとまりを持つ意味ネットワークとして把握できる。
