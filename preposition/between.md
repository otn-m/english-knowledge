# 認知言語学・概念意味論に基づく前置詞「between」の多義構造と空間・時間・抽象領域への拡張に関する包括的解説

## 1. 序論：空間関係から関係性の標示へ

英語の前置詞 **between** は、物理的な「二つのものの間に」という空間関係を表すだけでなく、人間関係、選択、比較、分配、時間的間隔、論理的差異、秘密の共有範囲など、多様な領域で用いられる高頻度語である。辞書的には「〜の間に」「〜の中間に」「〜のあいだで」と訳されることが多いが、実際の用法を詳しく見ると、between は単なる位置情報ではなく、複数の対象を個別に区別し、そのあいだに成立する関係を標示する語である。

認知言語学の観点では、前置詞の意味は、完全に恣意的な語義リストとしてではなく、身体的経験、空間認知、構文、慣用化、語用論的推論が相互に作用する意味ネットワークとして整理できる。たとえば、*The table is between the chair and the sofa.* では、椅子とソファという二つの参照点によって中間領域が定義される。一方、*the relationship between the two countries* では、国同士の物理的距離ではなく、外交的・制度的・社会的な関係が問題になっている。これらの用法は同一ではないが、複数の対象を区別し、その相互関係を捉えるという点で連続している。

本稿では、between の多義性を、認知言語学、認知文法、概念メタファー理論、語法研究の知見を参照しながら整理する。ただし、すべての用法が単一の空間スキーマから機械的に派生したと断定することは避ける。between の意味には、空間的な中間性を出発点とする説明が有効な場合が多いが、実際の用法は、語史、構文、共起語、慣用表現、談話文脈によっても大きく規定される。

特に重要なのは、between と among の違いである。学校文法ではしばしば「二つなら between、三つ以上なら among」と説明される。しかし、現代英語では *between the five nations* や *differences between English, French, and German* のように、三つ以上の対象にも between が用いられる。問題は単純な数ではなく、対象が個別に識別され、互いの関係・比較・交渉・分配などが前景化されているかどうかである。

したがって、本稿の中心的な主張は次のようにまとめられる。between は「二つのものだけに使う前置詞」ではない。むしろ、個別化された複数の対象、時点、状態、選択肢、概念のあいだに成立する空間的・時間的・論理的・社会的関係を標示する語である。

## 2. 語源学的基盤と「二者性」の慎重な位置づけ

### 2.1 語源に見る二者性・相互性

現代英語の **between** は、中英語 *bitwene* などを経て、古英語 *betwēonum*, *betweonum*, *betwinum* などの形に遡る。これらは、一般に *be-/bi-* 系の要素と、「二」に関係する語根を含む形と説明されることが多い。関連語として *betwixt* もあり、これも二者の間、二点間の関係を表す語として歴史的に用いられてきた。

ただし、古英語形の内部構造を単純に「bi + two」といった形に固定して説明するのは慎重であるべきである。歴史的形態には揺れがあり、語源辞典や歴史辞書でも説明の粒度に差がある。したがって、学術的には、between は語源的に二者性、相互性、中間性と関係するが、その語源だけから現代英語の用法全体を直接導くことはできない、と述べるのが妥当である。

語源的な二者性は、between の中心的傾向を理解するうえで有用である。between は、何かと何かを区別し、そのあいだにある空間・関係・差異・選択を捉える語である。そのため、二つのランドマークを基準にした空間関係は、現代英語でも非常に典型的な用法である。

例として、*The village lies between the river and the mountains.* では、川と山という二つの参照点があり、そのあいだに村が位置づけられる。*There is a difference between theory and practice.* では、理論と実践という二つの概念が区別され、その差異が問題にされる。このように、二項関係は between の意味構造の中心にある。

### 2.2 「二つだけ」という規範文法の限界

しかし、between が語源的に二者性と関係することと、現代英語で二つの対象にしか使えないことは別問題である。実際には、between はかなり早い時期から、三つ以上の対象にも使われてきた。現代の記述文法や主要辞書の語法解説でも、「between は二つ、among は三つ以上」という単純な規則は、実際の英語使用を十分に説明しないとされる。

たとえば、次のような表現は自然である。

- *a treaty between five countries*
- *the difference between English, French, and German*
- *the relationship between variables*
- *negotiations between several parties*

これらの表現では、対象が三つ以上であっても、それぞれが個別に識別可能な関係項として扱われている。五カ国間の条約では、五カ国が一つの塊としてぼんやり扱われているのではなく、各国が交渉主体として区別される。複数言語間の差異も、各言語が個別の比較対象として認識される。したがって、このような場合には among よりも between が自然になることがある。

一方、among は、対象が集合・群・環境として捉えられる場合に用いられやすい。たとえば、*hidden among the trees* では、個々の木が一つ一つ参照点として比較されているのではなく、「木々の集まり」の中に紛れている状態が表される。つまり、between と among の違いは、対象の数だけでなく、話者が対象をどのように概念化しているかに関わる。

### 2.3 語源は説明の手がかりであり、現代用法の規則ではない

語源は意味の歴史的背景を理解するうえで有益であるが、現代語の規則そのものではない。between の場合、語源的な二者性は、なぜこの語が相互関係、比較、選択、分配と強く結びつくのかを理解する手がかりになる。しかし、現代英語では、三つ以上の対象に対しても、個別的な関係が問題になる場合には between が十分に成立する。

この点を誤解すると、between/among の使い分けが不自然に単純化される。実際の英語理解では、「対象はいくつか」だけでなく、「それらは個別の関係項として捉えられているか」「集合の内部として捉えられているか」「比較・交渉・差異・分配の関係が前景化しているか」を見る必要がある。

## 3. 理論的枠組み：認知意味論と認知文法

### 3.1 身体化された認知と空間経験

認知言語学では、抽象的な意味の一部は、身体的・感覚運動的な経験と関係していると考える。人間は、物体の近くにいる、二つの物体のあいだを通る、障害物に挟まれる、橋で二点をつなぐ、といった空間的経験を繰り返す。このような経験から抽出される比較的抽象的な構造が、言語表現の理解に関与する。

between の場合、二つ以上の参照点によって定義される「間隔」「中間領域」「連結」「分離」「選択肢の集合」が重要になる。たとえば、*between a rock and a hard place* のような慣用句では、二つの障害物に挟まれて身動きが取りにくい身体的経験が、困難な選択や窮地の理解に比喩的に用いられている。

ただし、抽象的な between のすべてを身体経験だけに還元するのは不適切である。*the difference between A and B* や *between you and me* のような表現では、空間的な中間性が背景にあるとしても、実際の意味は構文、語用論、慣用化によって形成されている。認知言語学的説明は有用な整理枠組みであるが、語の意味を単一の身体スキーマへ還元するものではない。

### 3.2 between に関わる主要なイメージ・スキーマ

between の理解に関与する主なイメージ・スキーマは、次のように整理できる。

| スキーマ | 内容 | between における働き |
|---|---|---|
| REGION / INTERVAL（領域・間隔） | 二つ以上の境界や参照点によって定義される中間領域 | *between the houses*, *between 2 and 3* など |
| SOURCE-PATH-GOAL（起点・経路・着点） | 移動や変化を経路として捉える構造 | *walk between the buildings* など |
| LINK（連結） | 二つの対象をつなぐ物理的・心理的・論理的関係 | *a link between smoking and cancer* など |
| BARRIER（障壁） | 二つの対象の直接的接触を妨げる介在物 | *something came between us* など |
| ALTERNATIVE（選択肢） | 複数の候補が相互に区別されて提示される構造 | *choose between A and B* など |
| SCALE / DIFFERENCE（尺度・差異） | 対象間の類似性・相違を距離や間隔として捉える構造 | *the difference between A and B* など |

ここで注意すべき点は、これらのスキーマが独立した「語義」ではないことである。むしろ、between が用いられる文脈に応じて、どのスキーマ的側面が前景化するかが変わる。空間用法では REGION / INTERVAL が中心になり、関係用法では LINK が、断絶用法では BARRIER が、選択用法では ALTERNATIVE が強く働く。

### 3.3 トラジェクターとランドマーク

Ronald Langacker の認知文法では、空間関係を「トラジェクター（Trajector: TR）」と「ランドマーク（Landmark: LM）」の関係として記述する。TR は焦点化される対象であり、LM はその位置や関係を定義する参照点である。

between の特徴は、LM が通常一つではなく、二つ以上の参照点、または内部に識別可能な構成員を持つ集合である点にある。たとえば、*The table is between the chair and the sofa.* では、table が TR、chair と sofa が LM である。TR は、二つの LM によって定義される中間領域に位置づけられる。

抽象的用法でも同様の構造が見られる。*the relationship between the two countries* では、関係そのものが TR として捉えられ、二つの国が LM となる。*the difference between A and B* では、差異が TR として焦点化され、A と B が比較の基準となる。

| 構成要素 | 役割 | between における特徴 |
|---|---|---|
| TR | 焦点化される対象 | 物体、経路、関係、差異、選択、情報など |
| LM | 参照点 | 二つ以上、または内部に個別化可能な構成員を持つ集合 |
| Relation | TR と LM の関係 | 介在、通過、連結、隔たり、比較、分配、選択 |

この枠組みによって、between の空間用法と抽象用法を同じ形式で記述しやすくなる。ただし、抽象用法では TR や LM が物理的対象ではなく、概念、出来事、制度、人物関係などになるため、構文と文脈の影響がより大きくなる。

## 4. 空間的プロトタイプと位相的特徴

### 4.1 静的配置：二つの参照点の中間

between の最も基本的な用法は、二つの空間的ランドマークによって定義される中間領域に、対象が位置している状態である。

- *The table is between the chair and the sofa.*
- *The village lies between the river and the mountains.*
- *There is a narrow path between the two buildings.*

この用法では、LM が個別に識別されていることが重要である。椅子とソファ、川と山、二つの建物は、それぞれ異なる参照点として認識される。TR は、その参照点のあいだに位置づけられる。

この「間」は、必ずしも数学的に厳密な中点ではない。*The village lies between the river and the mountains.* という場合、村が川と山の正確な中央にある必要はない。重要なのは、川と山という二つの参照領域によって、その村の位置が概念的に定義されていることである。

### 4.2 動的経路：あいだを通る

between は静的位置だけでなく、移動経路も表す。

- *He walked between the two buildings.*
- *The road runs between the forest and the lake.*
- *A stream flows between the fields.*

この場合、TR は中間領域に静止しているのではなく、その領域を通過したり、そこに沿って伸びたりしている。二つの建物のあいだは、移動体にとって通路として概念化される。道路や川のような線状の TR は、二つの LM によって挟まれた経路として捉えられる。

ただし、between 自体が常に狭さや拘束を意味するわけではない。二つの建物の間が狭い場合には「通路」や「隙間」の感覚が強まるが、二つの国の間に広大な海がある場合にも between は使える。つまり、between は狭い隙間そのものではなく、複数の参照点によって定義される中間領域を表す。

### 4.3 境界性と半容器的な性質

between が表す中間領域は、しばしば容器に似た性質を帯びる。二つの壁の間、二つの山の間、二つの国境の間のような場合、LM が境界として機能し、TR の移動や視界を部分的に制限することがある。

しかし、between の空間は典型的には完全な容器ではない。*in the room* のように、四方や上下面が明確に囲まれているわけではなく、二つ以上の参照点によって間隔が定義されるだけである。そのため、between は CONTAINER スキーマそのものというより、REGION / INTERVAL スキーマを基本とし、文脈によって容器的・拘束的な解釈を帯びる語と考えるのが適切である。

この性質は、抽象的用法にも関係する。*between a rock and a hard place* では、二つの障害物に挟まれた空間が拘束的に解釈される。一方、*communication between departments* では、中間領域は拘束ではなく連絡経路として解釈される。同じ「間」が、文脈によって自由な経路にも、拘束空間にも、関係の場にもなる。

## 5. between と among：数ではなく個体化の問題

### 5.1 学校文法的規則の修正

between と among の違いは、英語学習で頻繁に扱われる。伝統的には「二つなら between、三つ以上なら among」と説明されることが多い。この規則は初歩的な目安としては役に立つが、実際の英語使用を説明するには不十分である。

between は、三つ以上の対象にも普通に使われる。特に、対象が個別に識別され、それぞれの相互関係、比較、交渉、分配、選択が問題になる場合には between が自然である。

- *The talks between Japan, the United States, and South Korea continued late into the night.*
- *The difference between red, orange, and yellow is gradual in some contexts.*
- *There are complex relationships between these variables.*

これらはいずれも、対象が三つ以上であっても、各要素が個別に関係項として扱われている。そのため、between が適している。

### 5.2 between：個別化された関係のネットワーク

between は、ランドマークが離散的・個別的に認識される場合に用いられやすい。これは、対象が二つの場合に最もわかりやすいが、三つ以上でも成立する。

- *the difference between A and B*
- *the relationship between the members of the committee*
- *trade between countries*
- *coordination between teams*

このような表現では、各要素が関係の項として区別される。関係は、一つの集合内部にぼんやり存在するのではなく、A と B、B と C、A と C のような個別的なつながりのネットワークとして捉えられる。

between の空間的イメージは、点と点を結ぶ線、または離散的な参照点のあいだに成立する間隔として整理できる。このため、比較、対照、交渉、接続、分配のように、個別の項を意識する文脈と相性がよい。

### 5.3 among：集合・群・環境の内部

among は、対象が集合・群・環境として捉えられる場合に用いられやすい。

- *She was standing among the crowd.*
- *The house was hidden among the trees.*
- *There was a sense of unity among the members.*

これらの例では、個々の群衆や木やメンバーが完全に無視されているわけではない。しかし、焦点は一対一の関係ではなく、集合の内部にいること、集団の中に分布していること、全体として共有されている性質にある。

among の空間的イメージは、点と点を結ぶ関係というより、ある集合的な媒体や環境の中に含まれる状態に近い。このため、所属、混在、共有、分布、集合的性質を表す文脈と相性がよい。

### 5.4 比較表

| 比較次元 | between | among |
|---|---|---|
| 基本的傾向 | 個別化された対象間の関係 | 集合・群・環境の内部 |
| 対象の数 | 二つが典型だが、三つ以上も可 | 三つ以上が典型だが、文脈依存 |
| 認知的焦点 | 関係、差異、比較、交渉、分配 | 所属、混在、共有、集合性 |
| 空間的イメージ | 点と点のあいだ、関係のネットワーク | 群・媒体・環境の中 |
| 典型的共起 | difference, relationship, negotiation, link, connection, choose | crowd, trees, members, group, scattered, hidden |
| 例 | *differences between languages* | *hidden among the trees* |

この違いは絶対的な規則ではなく、話者の概念化に依存する。たとえば、*distribute the money among the children* は、子どもたち全体への分配を表す自然な表現である。一方、*divide the money between the three children* も、三人それぞれの取り分を個別に意識する場合には可能である。

### 5.5 類型論的観点

Martin Haspelmath が論じるように、言語類型論では、個別言語の文法範疇と、言語間比較のための比較概念を区別する必要がある。英語の between/among の区別は、普遍的に同じ形で存在するものではない。日本語の「〜の間」は、二者間にも複数者間にも用いられるが、「群衆の中にいる」「木々に紛れる」のような among 型の文脈では「〜の中」「〜に混じって」などが自然になる。

したがって、between と among の違いを普遍的な認知法則として扱うのではなく、英語において語彙化された区別として理解するのが適切である。そのうえで、個体化と集合化という認知的傾向は、両者の使い分けを説明する有効な手がかりになる。

## 6. 関係・連結・断絶：抽象領域への拡張

### 6.1 関係を表す between

between は、物理的な中間領域から、人間関係、制度的関係、論理的関係へ拡張される。

- *the relationship between parents and children*
- *communication between departments*
- *trade between countries*
- *the link between smoking and cancer*

これらの用法では、between は二つ以上の対象を単に離しているのではなく、むしろ関係づけている。*relationship*, *communication*, *link*, *connection* などの語と共起する場合、between は、複数の対象を結ぶ関係の場を標示する。

この用法は、LINK スキーマによって説明できる。離れた対象同士が、経路、紐帯、通信、因果関係、制度的接続によって結ばれていると概念化される。ただし、LINK スキーマは between 自体が常に「結びつける」意味を持つということではない。連結の解釈は、多くの場合、共起する名詞や文脈によって生じる。

### 6.2 介在物と断絶

一方、between は断絶や妨害を表すこともある。

- *Something came between us.*
- *A wall stood between the two communities.*
- *Let nothing stand between you and your goals.*

これらの表現では、「間にあるもの」が二者を結ぶのではなく、直接的な接触や親密さを妨げる障壁として機能する。この場合、between は BARRIER スキーマと結びつく。

重要なのは、連結と断絶が完全な矛盾ではないことである。二者の「間」は、橋にも壁にもなりうる。境界は分離する線であると同時に、両者が接する面でもある。したがって、between は文脈によって、関係を成立させる場にも、関係を阻む介在物にもなる。

*Something came between us.* では、二人の関係に第三の要素が入り込み、心理的距離を作ったことが表される。ここには、**INTIMACY IS CLOSENESS**（親密さは近さ）という一般的なメタファーが関与していると考えられる。親密な関係は近接として、疎遠さは距離として理解されやすい。

### 6.3 境界としての between と共有空間

between は、境界や中間領域を通じて、共有空間を作ることもある。たとえば、隣人同士のあいだにある壁は、物理的には両者を分ける。しかし、その壁を共同で修理する、境界について交渉する、境界を意識するという行為を通じて、両者は関係づけられる。

このような例は、between の意味が単純に「接続」か「分離」かに分かれるわけではないことを示している。between は、二者が互いに無関係であることを表すのではなく、むしろ両者の関係が問題になる領域を設定する語である。そこでは、接続、分離、緊張、交渉、共有が文脈に応じて生じる。

### 6.4 *between you and me*：秘密の共有範囲

慣用表現 *between you and me* は、「ここだけの話だが」「あなたと私の間だけの話だが」という意味を持つ。

この表現では、between は物理的な位置ではなく、情報の共有範囲を限定する語として働く。「あなた」と「私」の関係が、第三者から閉じられた小さな共有空間として概念化される。ここでは、between は単なる中間領域ではなく、情報が漏れてはいけない範囲を設定している。

この用法を CONTAINER スキーマで説明することは可能である。ただし、between が容器そのものを意味するというより、会話参加者のあいだに形成される限定的な語用論的空間が、結果として容器のように解釈されると見るのが適切である。

## 7. 選択・葛藤・ジレンマ

### 7.1 *choose between*：選択肢の提示

between は選択の構文で頻繁に用いられる。

- *You must choose between A and B.*
- *She had to decide between staying and leaving.*
- *There is little difference between the two options.*

ここで between は、選択肢を相互に区別された候補として提示する。A と B は、同じ集合の中にぼんやり存在するのではなく、意思決定の対象として個別に並べられている。

この用法は、ALTERNATIVE スキーマとして整理できる。意思決定者は、複数の候補のあいだで判断する。場合によっては、それぞれの選択肢が異なる欲求、義務、損失、利益を伴うため、葛藤が生じる。しかし、*choose between* 自体が必ず強い葛藤を意味するわけではない。単に選択範囲を示す中立的表現として用いられる場合も多い。

### 7.2 力動性による説明の範囲

Leonard Talmy の力動性（Force Dynamics）は、主体が複数の力や制約にさらされる状況を説明するうえで有用である。between の選択用法でも、特にジレンマや葛藤が強い場合には、選択肢が主体を異なる方向に引くものとして解釈できる。

たとえば、*She was torn between duty and desire.* では、義務と欲望が主体を異なる方向へ引く力として概念化される。この場合、between は単に候補を列挙するだけでなく、主体が二つの力のあいだで引き裂かれている状態を表す。

一方、*Choose between tea and coffee.* のような文では、力動性を持ち出す必要はほとんどない。そこでは、between は単に二つの選択肢を提示しているだけである。したがって、力動性は between のすべての用法に適用すべき説明ではなく、葛藤・義務・圧力・制約が文脈上前景化している場合に有効な補助的説明である。

### 7.3 板挟みを表す慣用句

between の拘束的な意味が最も強く現れるのが、ジレンマを表す慣用句である。

- *between a rock and a hard place*
- *between the devil and the deep blue sea*

これらは、いずれも二つの望ましくない選択肢のあいだに置かれ、どちらを選んでも困難を避けられない状況を表す。ここでは、中間領域は自由な移動空間ではなく、二つの障害物や危険に挟まれた拘束空間として理解される。

この用法は、空間的経験と慣用化が結びついた例である。物理的に二つの硬いものや危険なものに挟まれると身動きが取りにくい。その身体的経験が、選択困難の比喩として定着した。ただし、これらは強く慣用化された表現であり、between の一般的意味だけから完全に予測できるものではない。

### 7.4 認知的負荷と選択

選択肢が複数ある場合、人間はそれらを比較し、判断し、どれかを選ぶ必要がある。そのため、between を含む選択表現は、文脈によって認知的負荷を伴う場合がある。しかし、between 自体が認知的負荷を意味するわけではない。負荷の大きさは、選択肢の数、価値、リスク、不可逆性、社会的圧力などによって決まる。

したがって、選択に関する心理学的研究や意思決定研究を between の説明に利用する場合には、注意が必要である。between は選択肢の関係構造を標示する語であり、心理的負担や葛藤は文脈によって付加される解釈である。

## 8. 時間・分配・論理関係への拡張

### 8.1 時間的 between：時点と時点のあいだ

between は時間表現にも用いられる。

- *between 2:00 and 3:00*
- *between Monday and Friday*
- *between childhood and adulthood*
- *in-between times*

この用法では、空間的なランドマークが時間的ランドマークに置き換えられる。二つの時点、出来事、人生段階、期間が参照点となり、そのあいだの時間的領域が between によって表される。

認知言語学では、時間を空間によって理解する **TIME IS SPACE** 型の比喩がしばしば論じられる。between の場合、空間的な「間隔」が時間的な「期間」へ写像されると考えられる。ただし、時間用法は英語の構文として十分に慣用化しているため、話者が毎回明示的に空間比喩を意識しているわけではない。

*between childhood and adulthood* のような表現では、二つの時点というより、二つの状態や人生段階の中間が問題になる。この場合、between は時間的間隔であると同時に、カテゴリー的にどちらにも完全には属さない過渡的状態を表す。

### 8.2 *in-between*：中間状態と境界性

**in-between** は、物理的・時間的・概念的な中間状態を表す語として用いられる。

- *an in-between stage*
- *in-between sizes*
- *the in-between period*

この表現では、二つの明確なカテゴリーや状態のどちらにも完全には属さないことが前景化される。たとえば、*in-between sizes* は、標準的なサイズ区分のどれかにぴったり合わない状態を表す。*an in-between stage* は、ある段階から次の段階への移行期を表す。

ここで between は、単なる二点間の位置ではなく、境界性、過渡性、曖昧さを表す方向へ拡張されている。これは、分類やカテゴリー化の問題とも関わる。人間はしばしば物事を明確なカテゴリーに分けようとするが、現実には多くの対象がカテゴリーの中間に位置する。in-between は、そのような境界的状態を表す語である。

### 8.3 分配：全体を複数の受け手に割り当てる

between は分配の文脈でも使われる。

- *The money was divided between the two partners.*
- *The work was split between the three teams.*
- *The responsibility was shared between several departments.*

ここでは、全体としての資源・作業・責任が、複数の受け手に割り当てられる。二者の場合には between が非常に自然である。三者以上の場合には among も一般的だが、受け手が個別の関係項として意識される場合や、それぞれの分担が明確である場合には between も用いられる。

分配用法では、between は「空間的な中間」ではなく、「全体を複数の個別項に対応づける関係」を表す。ここでも、重要なのは数そのものではなく、受け手が個別化されているかどうかである。

### 8.4 差異・比較・論理関係

between は、差異や比較を表す語とよく共起する。

- *the difference between A and B*
- *the distinction between fact and opinion*
- *the contrast between theory and practice*
- *the boundary between science and religion*

この用法では、A と B が概念的に区別され、その差異や境界が問題になる。認知的には、類似性を近さ、差異を距離として捉える **SIMILARITY IS CLOSENESS / DIFFERENCE IS DISTANCE** 型の比喩が関与していると考えられる。

ただし、between が差異そのものを作り出すわけではない。difference, distinction, contrast, boundary などの名詞が、比較・区別・境界づけの関係を前景化し、between はその関係項を導入する。したがって、この用法では、between は論理的・概念的な比較空間を構成する標識として機能する。

### 8.5 *read between the lines*：行間を読む

*read between the lines* は、「行間を読む」「明示されていない意味を読み取る」という慣用表現である。

この表現は、文字通りには、書かれた行と行のあいだにある空白を読むという不可能な行為を示す。しかし、実際には、明示的に書かれた文言の背後にある含意、意図、暗示を読み取ることを意味する。

この慣用句では、書かれた行がランドマークとなり、そのあいだの空白が非明示的な意味の場所として概念化される。これは、物理的な行間から抽象的な含意へ拡張した表現である。ただし、これを between の一般的語義から直接導くよりも、強く慣用化した表現として扱うのが学術的には安全である。

## 9. 関連表現と構文上の注意

### 9.1 between と *in between*

between は前置詞として目的語を取るのが基本である。

- *The shop is between the bank and the post office.*

一方、**in between** は、副詞的に単独で用いられることが多い。

- *There are two large houses, and a small shop in between.*

この場合、具体的なランドマークは文脈から回収される。in between は、すでに提示された二つの対象や状態の中間にあることを表す。

### 9.2 between と *betwixt*

**betwixt** は between と同系統の歴史的表現であり、現代英語では古風・文学的・詩的な響きを持つ。日常的な標準英語では between が一般的である。*betwixt and between* という表現は、「どちらつかず」「中途半端な状態」を表す慣用句として用いられる。

この表現では、between の中間性が、明確な所属や決着の欠如として解釈される。in-between と同様に、カテゴリー的な境界性や曖昧さが前景化される。

### 9.3 between と reciprocal relation

between は、相互関係を表す構文と相性がよい。

- *There was an agreement between the two sides.*
- *The conflict between the two groups continued.*
- *Mutual trust between partners is essential.*

このような文では、between は一方通行の関係ではなく、二者または複数者の相互関係を示す。agreement, conflict, trust, communication, cooperation などは、そもそも複数の参加者を必要とする関係名詞であり、between はその参加者を導入する役割を果たす。

### 9.4 between と境界の表現

between は boundary, border, line, distinction などと共起し、領域やカテゴリーの境界を表す。

- *the boundary between public and private life*
- *the line between criticism and abuse*
- *the distinction between description and prescription*

この用法では、between は単に二つの領域の中間にあるものを表すのではなく、二つの領域を分ける境界そのものを問題化する。特に抽象的な議論では、between は概念分析の重要な標識になる。何と何を区別しているのか、どこに境界線を引くのかを明示するために用いられる。

## 10. 総括：between は「関係の場」を作る前置詞である

between の多義性を総合すると、この語は単なる「二つのものの間」を表す前置詞ではなく、複数の対象を個別化し、そのあいだに成立する関係の場を構成する語であるといえる。

第一に、between の中心には、二つ以上のランドマークによって定義される中間領域がある。これは物理的な位置関係として最もわかりやすい。*between the chair and the sofa* のような表現では、二つの参照点のあいだに TR が位置づけられる。

第二に、この空間的構造は、時間、選択、差異、分配、人間関係、秘密の共有範囲などへ拡張される。*between 2 and 3* では時間的間隔が、*choose between A and B* では選択肢の集合が、*the difference between A and B* では概念的差異が、*between you and me* では限定された共有範囲が表される。

第三に、between と among の違いは、単純な数の違いではなく、対象の個体化の違いとして理解するのが妥当である。between は、対象が個別に識別され、それらの関係が問題になる場合に用いられやすい。among は、対象が集合・群・環境として捉えられる場合に用いられやすい。ただし、どちらも絶対的な規則ではなく、話者の概念化と文脈によって左右される。

第四に、between は連結と断絶の両方を表しうる。*a link between A and B* では関係をつなぎ、*something came between us* では関係を妨げる。これは矛盾ではなく、「間」が関係の場であると同時に、介在・境界・障壁にもなりうるためである。

最後に、between の理解には、認知言語学的な空間スキーマだけでなく、構文、共起語、慣用化、語用論を含む総合的な視点が必要である。between は、英語において、空間、時間、論理、社会関係を横断して「複数の対象のあいだにあるもの」を捉えるための、非常に重要な関係標識である。

## 11. 学習上の整理

英語学習の観点からは、between を次のように整理すると理解しやすい。

まず、最も基本的には「個別に識別できる対象のあいだ」と考える。二つの場合が典型だが、三つ以上でも、それぞれを個別に比較・関係づけ・分配・交渉するなら between が使える。

次に、among は「集合の中」「群の中」「環境の中」と考える。個々の対象よりも、全体のまとまりや内部性が前景化している場合に用いられやすい。

さらに、between は空間だけでなく、時間、選択、差異、関係、分配にも広がる。*between 2 and 3*, *choose between*, *difference between*, *relationship between*, *divide between* などは、それぞれ異なる意味領域に見えるが、いずれも複数の項を区別し、そのあいだの関係を表している。

したがって、between を暗記する際には、「二つだけ」という規則に固定するよりも、「個別化された複数項のあいだの関係」と捉える方が、実際の用法に合っている。
