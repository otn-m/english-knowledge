# 「Forth」の多様な意味の徹底解説

## 1. 序論：現代英語における *forth* の位置づけ

英語の *forth* は、現代英語では主として副詞または不変化詞として用いられる語です。中心的には「前へ」「先へ」「外へ」「見えるところへ」「その時点以後へ」といった方向性を表します。ただし、現代の日常英語で物理的な「前へ」を表す場合には、ふつう *forward* や *ahead* が用いられ、*forth* は *go forth*, *set forth*, *bring forth*, *put forth*, *back and forth*, *from this day forth*, *and so forth* などの慣用表現・定型表現の中で保存されている傾向が強い語です。

したがって、*forth* を単純に「forward の古風な言い換え」と見るだけでは不十分です。*forward* が比較的中立的に「前方へ」「進行方向へ」「進捗する方向へ」を表すのに対し、*forth* には、文脈によって「起点から外へ出る」「隠れていたものが現れる」「公的な場へ提示される」「ある時点から先へ続く」といった含みが生じます。ただし、それらすべてを単一の深層意味から必然的に導くことはできません。語史、慣用化、レジスター、構文、共起する動詞の意味が重なって、現在の多義的な用法が成立していると考えるのが妥当です。

本稿では、認知言語学の枠組み、とくにイメージ・スキーマ、概念メタファー、放射状カテゴリー、語用論的レジスターの観点から、*forth* の意味を体系的に整理します。ただし、認知言語学的説明は「すべての意味は身体経験から直接説明できる」という意味ではありません。身体経験にもとづく方向性や出現性は重要な手がかりですが、実際の用法は英語史上の変化と慣用句としての定着を強く受けています。

## 2. 語源と歴史的変化

### 2.1 古英語 *forþ* と「前方性・先行性・継続性」

*forth* は古英語 *forþ* に遡り、「前へ」「先へ」「さらに」「外へ」「進んで」といった意味を持っていました。語源的にはゲルマン語派の語彙群と関係し、ドイツ語 *fort*、オランダ語 *voort* などと比較されます。これらはいずれも「先へ進む」「その場を離れる」「続いていく」といった意味領域を共有しています。

ただし、*forth*, *fore*, *forward*, *further* の関係を、単純な派生関係として整理するのは不正確です。これらは互いに関連する語彙群ではありますが、それぞれが異なる歴史的経路と用法上の分化を経ています。現代語としては、*forward* が一般的な「前方へ」「進行方向へ」を担い、*forth* はやや文語的・形式的・文学的な語として、特定の表現に残ったと見るのが適切です。

### 2.2 現代英語における品詞上の位置

現代標準英語では、*forth* は基本的に副詞として扱われます。たとえば *go forth*, *come forth*, *bring forth*, *put forth* では、動詞に方向性・出現性・提示性を加える不変化詞として機能しています。一方、古い英語や文学的文体では、*forth of* のように前置詞的に解釈できる用法も見られますが、現代ではこれは古風・詩的・方言的な用法です。

この点は重要です。*forth* を「前置詞」として説明すると、現代英語の実態から少しずれます。現代英語で前置詞として「〜から外へ」を表すには、ふつう *out of*, *from*, *away from* などが使われます。*forth* は、独立した前置詞というより、動詞や定型句と結びついて方向・出現・提示・継続を表す副詞的要素として理解するのが自然です。

### 2.3 *forward* との分化

*forth* と *forward* はどちらも「前へ」という意味領域に関係しますが、現代英語ではかなり役割が異なります。*forward* は中立的・汎用的で、物理的移動、計画の進捗、未来への視線、メールの転送など、非常に広く使われます。これに対して *forth* は、日常的な方向指示ではあまり使われず、形式的・文学的・宗教的・法的な響きを帯びることが多い語です。

たとえば *go forward* は「前進する」「進める」という一般的表現です。一方、*go forth* は「旅立つ」「世に出る」「使命を帯びて出て行く」という響きを帯びやすく、しばしば聖書的・儀礼的・文学的な文体効果を生みます。この差は、*forth* の意味そのものだけではなく、現代英語における使用域の偏りから生じるものです。

## 3. 認知言語学的に見た *forth* の基本スキーマ

*forth* の用法は、完全に無秩序な寄せ集めではありません。しかし、ひとつの中心義からすべてが直線的に派生したと断定することもできません。むしろ、いくつかのスキーマが重なった意味ネットワークとして捉えるのが適切です。

### 3.1 SOURCE-PATH 型スキーマ：起点から先へ進む

最も基本的な説明軸は、SOURCE-PATH 型のスキーマです。これは、ある起点から離れ、進行方向へ向かうという構造です。*go forth* のような表現では、主体が家、共同体、現在位置、既存状態などから離れ、外部・未来・未知の領域へ向かうように概念化されます。

この場合、*forth* は単に「前へ」を意味するだけではありません。「あるところから出て、先へ進む」という出発性が前景化します。したがって、*go forth into the world* のような表現では、空間的移動に加えて、人生の新しい段階や公的世界への参入という比喩的含みも生じます。

### 3.2 CONTAINER 型スキーマ：内側・隠れた領域から外へ出る

*bring forth*, *come forth*, *burst forth*, *break forth* などでは、CONTAINER（容器）スキーマが関与します。ここでは、何かが内側・隠れた領域・潜在状態から、外側・可視領域・公的領域へ現れると捉えられます。

このスキーマでは、内部は「まだ見えないもの」「まだ公表されていないもの」「まだ生成されていないもの」として理解され、外部は「見えるもの」「聞き手や社会が認識できるもの」「現実化したもの」として理解されます。たとえば *bring forth evidence* は、証拠を隠れた状態から議論や裁定の場へ提示する表現として理解できます。

ただし、*forth* の中心義を「容器から外へ出ること」だけに限定すると、*from this day forth* や *and so forth* のような時間的・系列的用法を説明しにくくなります。そのため、CONTAINER スキーマは *forth* の全体を支配する唯一の原理ではなく、主要な意味クラスターの一つと見るべきです。

### 3.3 FORCE 型スキーマ：勢いを伴う出現・放出

*burst forth*, *shoot forth*, *spring forth*, *break forth* では、勢い・圧力・突然性が強く感じられます。この場合、*forth* そのものが「爆発」を意味するわけではありません。むしろ、*burst*, *shoot*, *spring*, *break* などの動詞が持つ力動的意味と、*forth* の外向き・前方的方向性が結びついて、「内部から外へ勢いよく現れる」という解釈が生じます。

したがって、*laughter burst forth* では、笑いが身体内部に蓄積された感情のように捉えられ、それが外部へ噴き出すように表現されます。これは、感情を流体や圧力として捉える概念メタファーと相性がよい用法です。ただし、この説明は特定の共起表現に対して有効なものであり、*forth* のすべての用法に力動性を読み込む必要はありません。

### 3.4 主要な近接語との概略比較

| 語 | 中心的な焦点 | 典型的な含意 | 例 |
|---|---|---|---|
| *forth* | 起点から先へ、外へ、見えるところへ | 出発、出現、提示、形式性 | *go forth*, *bring forth* |
| *forward* | 前方・進行方向 | 前進、進捗、未来志向 | *move forward*, *look forward* |
| *ahead* | 前方の位置・先行 | 先にある、事前に考える | *ahead of us*, *plan ahead* |
| *out* | 内部から外部へ | 外在化、除去、露出、完了 | *go out*, *bring out* |
| *away* | 起点から距離を取る | 離脱、不在、遠ざかり | *go away*, *fade away* |

この表は厳密な定義ではなく、意味の焦点を比較するための整理です。実際の意味は、動詞、目的語、文体、ジャンル、慣用性によって変化します。

## 4. 出現・産出・提示の用法

### 4.1 *bring forth*：「生み出す」「産出する」「提示する」

*bring forth* は、*forth* の代表的な表現です。意味は文脈によって、「生む」「産出する」「結果をもたらす」「提示する」「明るみに出す」などに広がります。

たとえば、植物が実を結ぶ、土地が作物を生み出す、人が子を産む、議論の中で証拠を提示する、といった場面で使われます。これらに共通するのは、何かが潜在的・内部的・未提示の状態から、現実世界・可視領域・公的領域へ出てくるという構造です。

認知的には、次のように整理できます。

| 領域 | 具体的内容 | *bring forth* の働き |
|---|---|---|
| 生物的領域 | 子を産む、芽が出る、実がなる | 生命・結果が外へ現れる |
| 生産的領域 | 作品・成果・案を出す | 内的能力や準備が成果になる |
| 議論的領域 | 証拠・理由・主張を提示する | 隠れていた情報が検討対象になる |
| 宗教的・文学的領域 | 実り、創造、啓示 | 潜在的なものが象徴的に現れる |

ただし、*bring forth* を常に「無から有を創造する」と解釈するのは強すぎます。多くの場合、それはすでに潜在していたもの、内部にあったもの、準備されていたものが外へ現れることを表します。また、聖書的・宗教的文脈で用いられる場合でも、すべての用例に特定の神学的構造を読み込むべきではありません。語義としては「生じさせる」「現れさせる」「提示する」と整理するのが安全です。

### 4.2 *come forth*：「前に出る」「現れる」「名乗り出る」

*come forth* は、主体が自ら前に出る、または呼びかけに応じて現れることを表します。たとえば *The witness came forth* は「証人が名乗り出た／前に出た」という意味になります。ここでは、群衆・匿名性・沈黙・隠蔽された状態から、注目される公的な位置へ移るという構図があります。

また、*The truth came forth* のように、隠されていた真実が明るみに出る場合にも用いられます。この用法は、認知言語学でよく論じられる KNOWING IS SEEING（知ることは見ることである）という比喩と関係します。見えなかったものが見えるようになることが、知られなかったものが知られるようになることとして理解されるためです。

ただし、*come forth* は現代ではやや形式的・文学的です。日常会話では *come forward*, *appear*, *come out*, *step forward* などの方が自然な場合が多くあります。*come forth* を使うと、単なる出現ではなく、儀礼性・劇的効果・公的提示の響きが加わりやすくなります。

### 4.3 *burst forth*, *break forth*, *spring forth*：突然の表出

*burst forth* は「突然噴き出す」「爆発的に現れる」、*break forth* は「突然起こる」「現れ出る」、*spring forth* は「湧き出る」「生じる」といった意味で用いられます。

これらの表現では、*forth* は外向きの方向性を担い、共起する動詞が突然性や力動性を担います。したがって、意味の中心は語全体として形成されます。たとえば *tears burst forth* では、涙が内側からこらえきれず外へ出るように表現されます。*The sun broke forth from behind the clouds* では、雲に隠れていた太陽が視界に現れる動きが強調されます。

この用法は、隠蔽から可視性への移行、内部圧力から外部表出への移行、停滞から現れへの移行を表す点で、*forth* の出現性をよく示しています。ただし、*forth* 単独に「爆発」「突破」「感情の噴出」の意味があるわけではありません。

## 5. 言語行為・論証・法的提示の用法

### 5.1 *set forth*：「述べる」「規定する」「明示する」

*set forth* は、法律文書、契約書、規則、学術的説明などで、「述べる」「示す」「規定する」「明示する」という意味で用いられます。たとえば *the principles set forth in this document* は「この文書に示された原則」という意味です。

この表現では、抽象的な内容が、読み手の前に配置される対象のように扱われます。*set* は「置く」「配置する」「整える」という意味を持ち、*forth* はそれを公的・可視的・共有可能な領域へ差し出す方向性を補います。したがって、*set forth* は、単に「言う」よりも、内容を体系的に明示し、文書上に提示するという響きを帯びます。

ただし、*set forth* という語それ自体が法的拘束力を持つわけではありません。法的効力は、契約書、法令、規則、判決、制度的手続きといった文書ジャンルや社会制度によって生じます。*set forth* は、そのような制度的文脈で「明示的に提示する」ために好まれる表現です。

### 5.2 *put forth*：「提示する」「発揮する」

*put forth* には大きく二つの代表的用法があります。一つは、案・主張・理論・議論を「提示する」用法です。もう一つは、努力・力・エネルギーを「発揮する」「注ぐ」用法です。

*put forth an argument* では、考えや主張が議論の場へ差し出され、他者が検討できる対象になります。これは IDEAS ARE OBJECTS（アイデアは物体である）という比喩と関係します。抽象的な考えが、あたかも共有空間に置かれた物体のように扱われるわけです。

一方、*put forth effort* では、努力が人の内部に蓄えられた資源のように捉えられ、それを外部の課題へ向けて出す、という構図になります。この場合の *forth* は、内的資源の外向きの発揮を表します。ただし、これも *forth* 単独の意味というより、*put*, *effort*, 文脈全体によって形成される意味です。

### 5.3 *hold forth*：「長々と話す」「自説を開陳する」

*hold forth* は「長々と話す」「自説をとうとうと述べる」という意味のイディオムです。多くの場合、やや批判的・皮肉的なニュアンスを伴います。話し手が一方的に話題を保持し続け、聴衆に向けて話を展開し続けるという構図が感じられます。

ここでの *forth* は、話が外へ向かって流れ出る方向性を支えています。しかし、*hold forth* の意味はすでにイディオム化しているため、構成要素の意味だけから機械的に予測することはできません。認知的には、話題・発話権・注意を保持し、それを聴衆に向けて差し出し続ける表現として理解できます。

## 6. 往復運動と相互作用：*back and forth*

### 6.1 物理的な往復

*back and forth* は、「行ったり来たり」「前後に」「往復して」という意味の定型表現です。物体の揺れ、人の移動、視線の移動、議論の応酬など、さまざまな場面で使われます。

基本的には、二つの方向の交替運動を表します。*back* が戻る方向、*forth* が進む方向を担い、両者が結合することで、単一方向ではなく反復的な往復が表されます。

### 6.2 なぜ *back and forth* なのか

英語には *to and fro* という古い表現もありますが、現代では *back and forth* が非常に一般的です。ここで *forth* は、単独では古風になりつつも、定型句の中で強く保存された語だと言えます。

二項表現には、音韻的・意味的・語用論的な順序制約が働くことがあります。*back and forth* もその一例として見られます。ただし、「なぜこの順序なのか」を一つの音韻規則だけで説明するのは単純化しすぎです。語史的慣用、音の収まり、意味的対称性、使用頻度が重なって、現在の形が定着したと考えるべきです。

### 6.3 対話・議論・思考への拡張

*back and forth* は物理的運動だけでなく、対話や議論にもよく使われます。たとえば *We went back and forth about the issue* は「その問題について何度も議論した」という意味です。ここでは、意見・反論・応答が交互にやり取りされる様子が、物理的な往復運動に見立てられています。

この用法は、コミュニケーションを「物のやり取り」として捉える導管メタファーや、議論を力の応酬として捉える比喩と関係します。ただし、すべての *back and forth* が対立や争いを表すわけではありません。穏やかな会話、共同作業、視線の移動、調整作業にも使われます。

## 7. 時間・系列・継続への拡張

### 7.1 *from this day forth*：「この日から先へ」

*from this day forth* は「この日から以後」「今日から先」という意味です。ここでは、時間が空間的な経路として捉えられています。現在または特定の日付が起点になり、そこから未来方向へ時間が進むと理解されます。

この表現は、結婚の誓い、公的宣言、文学的な転換点など、ある時点を境に状況が変わる場面で用いられやすい表現です。日常語では *from now on* や *from then on* がより普通ですが、*from this day forth* には形式性・儀礼性・不可逆的な節目の響きがあります。

### 7.2 *henceforth* と *thenceforth*

*henceforth* は「今後は」「これ以後」、*thenceforth* は「その時以後」「そこから先は」という意味です。どちらも、ある時点を起点として、それ以後の継続を表す語です。

現代英語では、*henceforth* は形式的・文語的な表現として残っています。*thenceforth* はさらに古風で、法律文書、歴史叙述、文学的文体などで見られることがあります。通常の会話では、*from now on*, *from then on*, *after that*, *thereafter* などが使われます。

### 7.3 *and so forth*：「など」「以下同様」

*and so forth* は、「〜など」「その他同種のもの」「以下同様」という意味です。ここでの *forth* は、列挙がさらに先へ続くことを示しています。

たとえば *books, articles, reports, and so forth* と言えば、明示された項目のあとにも同じ種類の項目が続くことを聞き手に推測させます。これは、列挙を空間的・時間的な系列として捉える用法です。ただし、*and so forth* は数学的に厳密な無限列を表すわけではありません。語用論的には、「同種のものがまだあるが、ここでは省略する」という合図です。

## 8. 類義語との比較

### 8.1 *forth* と *forward*

*forth* と *forward* はどちらも「前へ」と関係しますが、現代英語では *forward* の方がはるかに日常的で中立的です。*move forward*, *step forward*, *look forward*, *forward an email* など、物理的移動から抽象的進捗、情報転送まで広く使われます。

一方、*forth* は、*go forth*, *bring forth*, *set forth* など、一定の形式性や文学性を帯びた表現に集中しています。*go forward* は「前進する」ですが、*go forth* は「外へ出ていく」「旅立つ」「使命を帯びて進む」という響きを持ちやすい表現です。

### 8.2 *forth* と *ahead*

*ahead* は、相対的に「前にある」「先にある」ことを表します。*the road ahead* は「前方の道」、*plan ahead* は「先を見越して計画する」という意味です。*ahead* は位置・予測・先行性に焦点があります。

*forth* は、現在位置より前にあるものを指すというより、起点から外へ・先へ進む動きや、隠れたものが出てくる動きを表します。したがって、*look ahead* は自然ですが、現代英語で *look forth* は通常の表現ではありません。古風・詩的な文脈では「外を見る」という意味で現れることがありますが、現代の日常英語では *look out*, *look outside*, *look ahead* などが自然です。

### 8.3 *forth* と *out*

*out* は、容器・内部・境界の対立を強く表します。*go out*, *take out*, *bring out*, *find out* など、内部から外部へ、隠れた状態から明らかな状態へ、またはある状態の外へ出ることを広く表します。

*forth* も出現や外向きの移動を表すことがありますが、*out* より古風・形式的で、しばしば「前へ出る」「公的領域へ出る」「産出される」「提示される」という響きを帯びます。たとえば *bring out a product* は「製品を発売する／世に出す」という一般的表現ですが、*bring forth an idea* は「考えを生み出す／提示する」というやや形式的・抽象的な響きを持ちます。

### 8.4 *forth* と *away*

*away* は起点から距離を取ること、不在になること、離れていくことに焦点を当てます。*go away*, *run away*, *fade away* では、出発点からの距離や消失が重要です。

*forth* は、単に離れていくことよりも、先へ進むこと、外へ出ること、公的・可視的な領域に現れることを含みやすい語です。したがって、*go away* は「立ち去る」ですが、*go forth* は「旅立つ」「世に出る」「先へ進む」という文体的意味を帯びやすくなります。

## 9. レジスターと語用論

### 9.1 形式性・文学性・宗教的響き

現代英語における *forth* の重要な特徴は、意味だけでなくレジスターです。*forth* は日常会話では頻度が低く、法律文書、契約書、聖書的表現、文学、儀礼的スピーチなどで目立ちます。

たとえば *Go forth and prosper* のような表現は、相手に単に「行ってよい」と許可するのではなく、旅立ちや使命や祝福のような文体効果を生みます。これを日常会話で使うと、意図的に大げさな響き、ユーモラスな響き、または荘厳な響きが出ることがあります。

### 9.2 *go ahead* と *go forth* の違い

*go ahead* は、現代英語で非常によく使われる表現で、「どうぞ」「進めてください」「やってかまいません」という許可や促進を表します。対話の中で発話権を譲る場合にも使われます。

これに対して、*go forth* はこのような日常的な談話標識としては機能しません。*Go forth* は、文字通りには「外へ／先へ進め」ですが、現代では儀礼的・文学的・宗教的な送り出しの表現として響きます。したがって、両者は同じ「go + 方向語」に見えても、語用論的には大きく異なります。



## 10. 主要コロケーション別の詳解

ここまでの説明を、実際によく見られる表現ごとに整理します。*forth* は単独で自由に使われるというより、特定の動詞や副詞句と結びついて意味を形成する傾向が強いため、コロケーション別に見ることが重要です。

### 10.1 *go forth*

*go forth* は、「出て行く」「旅立つ」「前へ進む」という意味です。ただし、現代英語では単なる移動を中立的に表す表現ではありません。日常的に「前へ進む」と言う場合は *go forward* や *move forward* が自然です。*go forth* は、家・共同体・安全圏・既存状態から外へ出て、より広い世界や未来へ向かうという、儀礼的・文学的・宗教的な響きを帯びやすい表現です。

たとえば *Go forth and multiply* や *Go forth and prosper* のような表現では、話し手が聞き手を未来へ送り出すような効果が生じます。ここでは、単なる許可ではなく、祝福、使命、旅立ち、人生段階の転換が示唆されます。このため、現代の日常会話であえて用いると、荘厳さだけでなく、軽い冗談や大げさな文体効果を出すこともあります。

### 10.2 *come forth* / *step forth* / *stand forth*

*come forth* は「前へ出る」「現れる」「名乗り出る」を表します。*step forth* は実際に一歩前へ出る身体動作を連想させ、*stand forth* は「目立って現れる」「際立つ」という意味を帯びることがあります。

これらの表現では、背景・群衆・沈黙・匿名性から、前景・注目・可視性へ移行する構図があります。したがって、法廷の証人、志願者、告白者、隠されていた事実などと相性がよい表現です。ただし、現代の日常英語では *come forward* の方が普通です。*come forth* はやや古風・文学的で、*step forward* はより具体的で現代的です。

### 10.3 *bring forth* / *call forth* / *send forth*

*bring forth* は、何かを外へ出す・生み出す・提示する表現です。これに近いものとして *call forth* と *send forth* があります。

*call forth* は「呼び起こす」「引き出す」という意味です。たとえば *call forth a response* は「反応を引き起こす」という意味になります。ここでは、反応や感情が相手の内側に潜在しており、刺激によって外へ現れるように概念化されています。

*send forth* は「送り出す」「発する」という意味です。光、音、香り、人、命令、使者などが、起点から外へ出ていく場合に用いられます。*send out* と近い場合もありますが、*send forth* はより文語的・荘重な響きを持ちます。

### 10.4 *put forth* / *set forth* / *lay forth*

*put forth* は、案・主張・努力などを外へ出す表現です。*put forth a proposal* は「提案を出す」、*put forth effort* は「努力を払う」です。この場合、思考や力が内的資源として捉えられ、それを外部の課題や議論の場へ向けて差し出す構図があります。

*set forth* は、内容を整理して文書や議論の中に明示する表現です。法律、契約、規則、論文、報告書などで頻出します。*put forth* が「出す」行為に焦点を当てるのに対し、*set forth* は「整えて配置し、明示する」側面が強い表現です。

*lay forth* は現代では一般的ではありませんが、意味としては「展開して示す」に近く、*lay out* や *set out* と比較されます。現代英語では *lay out the argument*, *set out the reasons*, *set forth the principles* のような使い分けが自然です。

### 10.5 *break forth* / *burst forth* / *spring forth* / *issue forth*

これらは突然の出現や流出を表します。*break forth* は、光・音・感情・争いなどが突然現れる場合に用いられます。*burst forth* はより爆発的で、笑い・涙・叫び・水・溶岩などが勢いよく出る場面に適します。*spring forth* は、泉、生命、芽、発想などが湧き出る・生じる感覚を伴います。*issue forth* は「流れ出る」「発せられる」という文語的表現です。

これらでは、*forth* は外向きの方向性・可視化・現れを担い、動詞が出現の仕方を指定します。*break* は遮蔽や抑制の突破、*burst* は内部圧力の爆発、*spring* は自然発生的な湧出、*issue* は源からの流出や発出を示します。

### 10.6 *forthcoming*

*forthcoming* は形容詞で、「近く現れる」「今後予定されている」「提供される用意がある」「率直に情報を出す」という意味を持ちます。これは、*come forth* と同じく、まだ現れていないものがこれから現れるという方向性と関係します。

たとえば *the forthcoming book* は「近刊の本」、*further details will be forthcoming* は「さらなる詳細が今後提供される」という意味です。また、*He was not forthcoming with information* では、「彼は情報を進んで出そうとしなかった」という意味になります。この用法では、情報が内側・非公開領域にあり、それを外へ出すかどうかが問題になっています。

### 10.7 *forthwith*

*forthwith* は「直ちに」という意味の副詞です。語源的には *forth* と *with* の結合とされますが、現代英語では構成要素から意味を直接読み解くより、「即座に」「遅滞なく」という形式的表現として扱うのが適切です。法律・行政・形式的文書で見られることがあります。

*forthwith* を *with forth* のように分解して現代語感で理解しようとすると不自然です。これは歴史的に形成された語であり、現代では一語の副詞として機能します。日常語では *immediately*, *at once*, *right away* の方が一般的です。

### 10.8 *to and fro* と *back and forth*

*to and fro* は「行ったり来たり」を表す古風な表現です。*fro* は現代英語ではほとんどこの表現の中にしか残っていません。*back and forth* は現代でより一般的な表現です。

*back and forth* は物理的往復に加え、対話、議論、交渉、思考、視線移動にも用いられます。たとえば *emails went back and forth* であれば、メールが何度もやり取りされたことを表します。ここでは、情報や発話が二者間を移動するものとして概念化されています。

## 11. 発達・認知・相互行為研究での *back and forth*

*back and forth* は日常語であると同時に、心理学・発達研究・相互行為研究でも比喩的に使われる表現です。ただし、こうした研究用語としての使用は、*forth* の語義そのものを説明する根拠というより、*back and forth* という定型句が「相互的・反復的なやり取り」を表すために広く用いられている例として位置づけるべきです。

### 11.1 視線の往復と共同注意

乳幼児の語彙学習や共同注意の研究では、子どもが対象物と話し手の顔の間で視線を行き来させる行動が取り上げられることがあります。このような視線移動は、対象、発話、話し手の意図を結びつける過程の一部として解釈されます。

この場合、*looking back and forth* は、単なる眼球運動の記述であると同時に、複数の情報源を交互に参照して統合する認知的活動を表す比喩にもなります。ただし、「視線が意味を縫い合わせる」といった表現は説明のための比喩であり、神経認知機構そのものを直接記述するものではありません。

### 11.2 対話の往復と相互行為

会話はしばしば *back-and-forth conversation* と表現されます。これは、発話者と聞き手が交互に役割を入れ替えながら、発話・応答・確認・修正を行うためです。したがって、*back and forth* は単なる移動方向の反復ではなく、相互行為のリズム、タイミング、順番交替、応答性を含む表現として機能します。

この表現は、自閉スペクトラム症に関する一般向け・臨床的説明でも、「双方向的な会話の難しさ」を説明する際に使われることがあります。ただし、これは医学的診断概念を *forth* から説明できるという意味ではありません。むしろ、英語の *back and forth* が「滑らかな相互応答」を表す慣用的表現として定着していることを示す例です。

### 11.3 内言と自己内対話

心理学や認知科学では、内言や自己内対話を *back-and-forth* な過程として説明することがあります。これは、自分の中に複数の視点や応答が生じ、問いと答え、主張と反論、想起と評価が交互に現れるためです。

この用法では、*forth* は物理的方向を表しているわけではなく、対話的な往復性を表す定型表現の一部です。したがって、ここでも意味の中心は *forth* 単独ではなく、*back and forth* 全体にあります。

## 12. 学習上の注意：日本語訳だけでは捉えにくい点

### 12.1 「前へ」だけで覚えると誤解しやすい

*forth* を「前へ」とだけ覚えると、多くの用法が理解しにくくなります。たとえば *bring forth evidence* は「証拠を前へ持ってくる」と直訳するより、「証拠を提示する」「証拠を明るみに出す」と訳す方が自然です。*from this day forth* も「この日から前へ」ではなく、「この日以後」「今日から先」と理解する必要があります。

### 12.2 現代英語では使用域が限られる

*forth* は、文法的には理解しておく価値が高い語ですが、学習者が日常会話で頻繁に能動使用する語ではありません。自然な日常英語を目指す場合には、次のような置き換えを意識する方が実用的です。

| *forth* を含む表現 | 日常的な近似表現 | 注意点 |
|---|---|---|
| *go forth* | *go out*, *set out*, *move forward* | *go forth* は儀礼的・文学的 |
| *come forth* | *come forward*, *appear* | *come forth* は形式的・劇的 |
| *bring forth* | *produce*, *bring out*, *present* | 文脈により「産む」「提示する」 |
| *set forth* | *state*, *describe*, *set out* | 法的・学術的文脈で自然 |
| *put forth effort* | *make an effort*, *exert effort* | やや形式的 |
| *from this day forth* | *from now on* | 儀礼的・文学的 |
| *and so forth* | *and so on*, *etc.* | 比較的普通だがやや形式的 |

### 12.3 文体効果としての *forth*

*forth* を使うと、文に古風さ、格式、文学性、宗教的響き、儀礼性が加わることがあります。この文体効果を理解せずに使うと、意図せず大げさに聞こえることがあります。

たとえば、友人に「先に行っていいよ」と言う場合、自然なのは *Go ahead.* です。ここで *Go forth.* と言うと、相手を人生の旅に送り出すような、冗談めいた大げさな響きになります。したがって、*forth* は「意味」だけでなく「場面」と「文体」を合わせて理解する必要があります。

## 13. 意味クラスター全体の整理

*forth* の意味ネットワークは、次のように整理できます。

| 意味クラスター | 中心イメージ | 代表表現 | 日本語での自然な訳 |
|---|---|---|---|
| 出発・進行 | 起点から外へ、先へ | *go forth*, *set forth on a journey* | 旅立つ、出て行く、進み出る |
| 出現・顕在化 | 隠れた領域から見える領域へ | *come forth*, *burst forth* | 現れる、噴き出す、明るみに出る |
| 産出・生成 | 潜在的源から結果が生じる | *bring forth fruit* | 生む、産出する、実を結ぶ |
| 提示・明示 | 内容を公的な場へ差し出す | *set forth*, *put forth* | 述べる、提示する、明示する |
| 努力・力の発揮 | 内的資源を外へ出す | *put forth effort* | 努力を払う、力を出す |
| 時間的継続 | ある時点から先へ | *henceforth*, *from this day forth* | 今後、この日以後 |
| 系列の継続 | 同種項目がさらに続く | *and so forth* | など、以下同様 |
| 往復 | 戻る方向と進む方向の反復 | *back and forth* | 行ったり来たり、やり取り |

この表から分かるように、*forth* の意味は「前方移動」だけではありません。起点からの離脱、外部への出現、可視化、公的提示、未来方向への継続が、それぞれの表現で異なる仕方で前景化します。

## 14. まとめ：*forth* の意味ネットワーク

*forth* は、現代英語では比較的限られた用法に残る語ですが、その意味ネットワークは豊かです。中心には「起点から先へ進む」「外へ出る」「見えるところへ現れる」という方向性があります。ただし、用法ごとに前景化されるスキーマは異なります。

第一に、*go forth* では、起点から外へ出て先へ進むという出発性が強くなります。第二に、*bring forth*, *come forth*, *burst forth* では、隠れたもの・内在していたもの・蓄積されていたものが外へ現れるという出現性が強くなります。第三に、*set forth*, *put forth* では、考え・規則・努力を公的な場や課題へ差し出すという提示性・発揮性が前景化します。第四に、*from this day forth*, *henceforth*, *and so forth* では、時間や系列が先へ続くという継続性が表れます。第五に、*back and forth* では、*forth* が *back* と対になり、往復運動や相互作用を表します。

したがって、*forth* を理解する際には、「前へ」という一語訳だけでは足りません。より正確には、「起点から外へ／先へ進む」「潜在的・隠れた領域から可視的・公的領域へ現れる」「提示される」「その時点以後へ続く」という複数の関連した意味クラスターを持つ語として捉える必要があります。そして、それらの用法は現代英語では多くの場合、形式的・文学的・宗教的・法的なレジスターの中で保存・特化しています。
