# 認知言語学的観点に基づく英語前置詞・副詞「about」の多義性構造と概念拡張

## 1. 序論：認知言語学における前置詞研究と about の位置づけ

### 1.1 従来の研究における課題と認知言語学的転回

英語の **about** は、前置詞・副詞・不変化詞として多様な用法を持つ語である。空間的な「〜のあたりに」「あちこちに」、数量・時間の「およそ」、主題を表す「〜について」、さらに *be about to V* に見られる「まさに〜しようとしている」という近接未来の用法まで、その意味範囲は広い。

伝統的な文法記述や辞書的説明では、これらの用法はしばしば個別の語義として列挙される。これは実用上有効である一方、各用法のあいだにどのような意味的関連があるのかを見えにくくする場合がある。特に第二言語学習者にとっては、about を「〜について」「約」「あたりに」と別々に暗記するだけでは、語全体の感覚をつかみにくい。

認知言語学は、このような多義性を完全に恣意的なものとは見なさない。George Lakoff、Mark Johnson、Ronald Langacker、Leonard Talmy、Andrea Tyler、Vyvyan Evans らの研究は、前置詞や不変化詞の意味が、空間経験、身体経験、比喩、語用論的推論、文法化、慣用化などの相互作用によって形成されることを示してきた。

ただし、注意すべき点がある。認知言語学的分析は、about のすべての用法が一つの空間的プロトタイプから機械的・必然的に派生したことを証明するものではない。むしろ、複数の用法のあいだに見られる意味的連続性や、話者がそれらをどのような概念的まとまりとして理解しうるかを説明する枠組みである。

本稿では、about を「分散」「周辺性」「不特定な近接」「焦点の周囲」という意味傾向を持つ語として捉え、その空間用法、近似用法、主題用法、個人領域に関わる用法、句動詞用法を整理する。

### 1.2 理論的枠組み：イメージ・スキーマ、放射状カテゴリー、慣用化

本稿で用いる主な理論概念は、イメージ・スキーマ、放射状カテゴリー、概念メタファー、メトニミー、主観化、慣用化である。

**イメージ・スキーマ**とは、身体的・知覚的経験から抽出される比較的抽象的な認知パターンである。容器、経路、接触、支持、中心と周辺、近接、分散などがその例である。about の理解に関しては、厳密な円環や閉じた経路よりも、対象の周囲・近傍・領域内における不特定な位置づけや分散性が重要になる。

**放射状カテゴリー**とは、一つの中心的な用法をめぐって、関連する複数の用法がネットワーク状に広がるという考え方である。ただし、これは「すべての語義が単一の原義から一方向的に派生した」という意味ではない。語源、構文、慣用化、文体差、方言差も関与する。

**概念メタファー**は、空間や身体経験に関わる具体的領域が、時間、数量、主題、心理状態などの抽象領域を理解する手がかりになるという考え方である。たとえば「数量は空間上の点として捉えられる」「近似は基準点の近くにあることとして捉えられる」といった分析が可能である。

本稿では、about の意味を以下のような複数のクラスターとして整理する。

| 意味クラスター | 代表例 | 中心的特徴 |
|---|---|---|
| 空間的分散・移動 | *walk about the town* | あちこち、不規則、方向性の弱さ |
| 静的分散 | *clothes scattered about the room* | 領域内に散らばる配置 |
| 不特定な所在 | *Is John about?* | 近くにいる、あたりにいる |
| 近似 | *about 100 dollars* | 正確な点ではなく、その周辺 |
| 主題・関連性 | *talk about politics* | 対象をめぐる言説・関心 |
| 個人領域・属性 | *something about him* | 人に付随する性質・印象 |
| 句動詞・構文化 | *bring about*, *come about*, *set about*, *go about*, *be about to* | 方向転換、発生、着手、対処、切迫 |

## 2. 語源的背景と空間的基盤

### 2.1 about の語源：abutan / onbutan と「外側の近傍」

現代英語の **about** は、中英語 *aboute*、古英語 *abūtan / onbūtan* などに遡る。一般に、この形は *on*、*be*、*ūtan* などと関係し、「外側に」「周囲に」「そばに」といった空間的意味を持っていたと説明される。

この語源的背景から、about には「対象の内部そのものではなく、その外側・周囲・近傍に関わる」という意味傾向があったと考えられる。ただし、語源は現代英語の全用法を直接説明するものではない。現代の *talk about*, *about five*, *be about to* などは、長い歴史的変化、構文環境、慣用化の結果として成立している。

したがって、語源は about の意味理解に役立つ手がかりではあるが、「現代のすべての about の意味は *on + by + out* から論理的に導ける」と断定するのは避けるべきである。

### 2.2 about と around の歴史的・意味的関係

about と around は、いずれも「周囲」「近傍」「およそ」と関係する用法を持つ。しかし、両者は完全に同義ではない。

一般に、**around** は、対象を取り巻く経路、円環的配置、周回、迂回、周囲の領域を表す傾向がある。これに対して **about** は、より不特定で、方向性の弱い分散・近接・関連性を表す傾向がある。

ただし、この差は絶対的ではない。現代英語では、特に数量の近似において *about 100 people* と *around 100 people* は大きく重なる。また、空間的な「あたりに」「周辺に」については、地域差・文体差があり、現代アメリカ英語では *around* の方が日常的に好まれる場面も多い。一方、*Is John about?* のような用法は、現代ではややイギリス英語的、あるいは口語的・限定的な響きを持つ。

### 2.3 about の空間的プロトタイプ：分散・近傍・非特定性

about の空間的中心用法は、厳密な円や閉じた経路ではなく、対象や領域の周辺・近傍における不特定な位置づけとして捉えられる。

認知文法の用語で言えば、前置詞的関係は、焦点となる対象である **トラジェクター（Trajector: TR）** と、基準となる対象である **ランドマーク（Landmark: LM）** の関係として記述できる。

about の典型的な空間シーンは、次のように整理できる。

| 構成要素 | about における特徴 |
|---|---|
| TR | 移動する単一の主体、または複数の物体・人 |
| LM | 場所、領域、対象、人、数量基準、話題 |
| 空間関係 | LM の内部・周囲・近傍において、TR が特定の一点に固定されない |
| 機能的特徴 | 不特定性、分散性、ゆるやかな近接、焦点のぼかし |

たとえば *People were walking about the town* では、人々は町の中を特定の目的地に向かって一直線に進んでいるのではなく、あちこち移動している。ここでの about は、方向の定まらない移動、あるいは領域内の不規則な分散を表す。

## 3. 空間的用法の整理

### 3.1 無作為・不規則な移動

about の空間用法の一つは、領域内を不規則に移動することを表す用法である。

例：

- *People were walking about the streets.*
- *The children ran about the garden.*
- *He wandered about the town.*

これらの表現では、TR は明確な始点から終点へ向かうのではなく、LM によって定義される領域内をあちこち移動する。*wander*, *walk*, *run*, *move* などの動詞と結びつくと、about は目的地よりも移動の散漫さ、探索性、不規則性を前景化しやすい。

ただし、現代の日常英語、とくにアメリカ英語では、この意味で *around* が使われることも多い。*walk about the town* はやや文語的・イギリス英語的に感じられる場合があり、*walk around the town* の方が普通に聞こえる文脈も多い。

### 3.2 静的な分散配置

about は、物体が領域内に散らばっている状態も表す。

例：

- *Clothes were scattered about the room.*
- *There were papers lying about the office.*
- *Toys were spread about the floor.*

この用法では、移動そのものではなく、移動や配置の結果としての分散状態が焦点化される。TR は一点に集中しておらず、LM の領域内にばらばらに存在している。

ここで重要なのは、「about」が単に「中にある」という包含関係を示すだけではないという点である。*in the room* は部屋の内部にあることを表すが、*about the room* は部屋のあちこちに散らばっていることを示唆する。

この意味は、後に述べる「近似」用法とも関連づけて理解できる。正確な一点ではなく、その周辺に広がる範囲が意識されるからである。

### 3.3 不特定な所在・近接

about には、「近くにいる」「あたりにある」という所在用法もある。

例：

- *Is John about?*
- *There is no one about.*
- *He must be somewhere about the house.*

この用法では、TR の正確な位置は問題ではない。重要なのは、TR が話者の関心領域、探索領域、または利用可能な範囲内にいるかどうかである。

*Is John about?* は、単に「ジョンは存在するか」ではなく、「ジョンはこの近くにいて、会ったり呼んだりできる状態か」という意味合いを持つ。ただし、この用法は現代英語では地域差・文体差があり、一般的なアメリカ英語では *Is John around?* の方が自然な場合が多い。

### 3.4 about / around / at / in / on の比較

about の空間的特徴は、類似する前置詞との対比によって明確になる。

| 表現 | 中心的イメージ | 例 | about との違い |
|---|---|---|---|
| about | 不特定な近接・分散 | *papers about the room* | 領域内・周辺に散らばる |
| around | 周囲・迂回・周辺 | *walk around the lake* | 円環的・周回的な経路を示しやすい |
| in | 内部・包含 | *in the room* | 領域の内部にあることが焦点 |
| on | 接触・支持 | *on the table* | 表面への接触が焦点 |
| at | 点的な位置づけ | *at the station* | 場所を点として捉える |

この表はあくまで傾向を示すものであり、実際の用法は構文、動詞、名詞、文脈、方言差によって変わる。特に about と around は多くの場面で重なるため、両者の違いを過度に固定的に捉えるべきではない。

## 4. 数量・時間の近似用法

### 4.1 「約」「およそ」としての about

about の非常に重要な用法に、数量・時間の近似がある。

例：

- *It costs about 100 dollars.*
- *There were about fifty people in the room.*
- *It is about five o’clock.*
- *The meeting lasted about two hours.*

この用法では、基準となる数量や時刻が一つの点として想定され、実際の値はその点と完全に一致するとは限らないが、その近くにあると概念化される。

認知的には、これは「正確な一点」ではなく「その周辺領域」として数量や時間を捉える表現である。空間的な「あたりに」という感覚が、数量・時間領域へ拡張されたものとして理解できる。

ただし、「about は around より必ず曖昧である」「around は about より必ず口語的である」といった単純な区別は避けるべきである。実際には、両者はかなり重なる。

おおまかな傾向としては、次のように整理できる。

| 表現 | 傾向 |
|---|---|
| about | 最も一般的な近似表現の一つ。話し言葉・書き言葉の両方で広く使われる |
| around | about と近い。やや口語的に感じられる場合もあるが、文脈差が大きい |
| approximately | より形式的・技術的・学術的 |
| roughly | 概算性・粗さがやや強い |
| nearly / almost | 基準値に近いが、通常はそこに達していないことを示しやすい |

### 4.2 近似と分散の認知的関係

*about 100* という表現では、100 という数値が厳密な到達点ではなく、近似の中心として扱われる。実際の値は 97 かもしれないし、102 かもしれない。重要なのは、100 という基準点の周辺にあるということである。

この点で、about の近似用法は、空間的な「周辺」「あたり」と連続性を持つ。場所における *about the house* が「家のあたり」を表すように、数量における *about 100* は「100 のあたり」を表す。

ただし、これは比喩的な説明であり、すべての話者が実際に空間的イメージを明示的に思い浮かべているという意味ではない。多くの場合、この用法はすでに慣用化・文法化され、日常的な近似マーカーとして機能している。

## 5. 主題・関連性を表す about

### 5.1 talk about / think about / know about

about の代表的な抽象用法は、主題・関連性を表す用法である。

例：

- *We talked about politics.*
- *I was thinking about the problem.*
- *She knows a lot about linguistics.*
- *This book is about Buddhism.*

この用法では、about の目的語は、発話・思考・知識・文章・本などの内容が向かう主題を示す。日本語では多くの場合「〜について」と訳される。

認知的には、主題を一つの対象または領域として捉え、言説や思考がその周辺をめぐると考えることができる。*talk about politics* は、政治という対象の一点だけを扱うのではなく、それに関連する出来事、意見、背景、争点、人物などを含む領域を扱う。

この意味で、about は「対象そのものに接触する」というより、「対象をめぐる関連領域を扱う」表現として理解できる。

### 5.2 about と on の違い

主題を表す場合、about と on はしばしば近い意味を持つ。

例：

- *a book about linguistics*
- *a book on linguistics*
- *a lecture about climate change*
- *a lecture on climate change*

一般に、**on** は主題をより明確な対象・専門的テーマとして扱う傾向がある。学術論文、講義、専門書、報告書などでは *on* が自然な場合が多い。

一方、**about** はより広く一般的で、日常的な話題にも専門的な主題にも使える。*talk about linguistics* は自然だが、*talk on linguistics* は「講演する」という意味に近くなるか、文脈によってはやや硬く聞こえる。

| 表現 | 傾向 |
|---|---|
| talk about X | X について話す。日常的・一般的 |
| speak about X | X について話す。やや改まった表現にも使える |
| speak on X | X をテーマに講演する・発表するという含みが出やすい |
| a book about X | X に関する本。一般的 |
| a book on X | X を主題とする本。専門的・主題明示的に聞こえやすい |

ただし、この違いも絶対的ではない。多くの文脈では *about* と *on* は置き換え可能であり、ジャンル、文体、共起する名詞によって自然さが変わる。

### 5.3 about と concerning / regarding / as for

about は、主題・関連性を表す最も一般的な前置詞の一つである。これに対して、*concerning*, *regarding*, *with regard to*, *as for* などは、より形式的、または談話上の機能が明確な表現である。

| 表現 | 特徴 |
|---|---|
| about | 最も一般的。会話・文章の両方で使える |
| concerning | やや形式的。「〜に関する」 |
| regarding | 形式的・事務的 |
| with regard to | 非常に形式的。文書・論述向き |
| as for | 話題を切り出す・対比する談話標識 |

このように、about は主題を示す表現の中でも、最も汎用性が高く、日常的な語である。

## 6. 人・所有・属性に関わる about

### 6.1 something about him

about には、人の属性や印象に関わる用法がある。

例：

- *There is something about him.*
- *There is something strange about this place.*
- *What I like about her is her honesty.*

*There is something about him* は、「彼には何かがある」という意味である。ただし、その「何か」は彼の身体の内部にあるものというより、彼に付随して感じられる性質、雰囲気、印象、特徴を指す。

ここで about は、人や場所を単なる物理的対象としてではなく、その周辺に広がる性質・印象・関連情報を含むものとして扱っている。これは「個人領域」や「属性領域」と呼べる用法である。

ただし、「オーラ」のような語を用いる場合には注意が必要である。比喩としては分かりやすいが、学術的には、超自然的な意味を含む概念としてではなく、「人に付随して知覚・評価される性質」として説明する方が適切である。

### 6.2 have money about you / keep your wits about you

about は、人の身体や管理領域の近くに何かがあることを示す場合がある。

例：

- *Have you any money about you?*
- *He had a knife about him.*
- *Keep your wits about you.*

*Have you any money about you?* は、「身につけているか」「手元にあるか」「持ち合わせがあるか」という意味である。ここで重要なのは、お金がポケットの中にあるのか、鞄の中にあるのか、手に持っているのかではない。話者の関心は、それがその人の利用可能な範囲内にあるかどうかである。

*Keep your wits about you* は、直訳すれば「知力・判断力を自分の周りに保て」という表現であり、実際には「冷静さを保つ」「注意を怠らない」という意味である。ここでは、判断力や注意力が、自分から離れてしまわないように保持すべきものとして概念化されている。

## 7. be about to V：近接未来と境界への接近

### 7.1 「まさに〜しようとしている」

*be about to V* は、近接未来を表す構文である。

例：

- *I am about to leave.*
- *The train is about to depart.*
- *She was about to say something.*

この構文は、ある出来事がまだ始まっていないが、まさに始まる直前であることを表す。単なる未来を表す *will* とは異なり、出来事の発生が切迫している。

### 7.2 空間的近接から時間的近接へ

認知的には、出来事を一つの領域または境界として捉え、主体がその境界のすぐ手前にいると考えることができる。*I am about to leave* では、「leave」という出来事の内部にはまだ入っていないが、その発生点の直前にいる。

この意味では、about の「近傍」「周辺」「境界付近」という空間的性質が、時間的な切迫へと拡張されたものと説明できる。

ただし、この構文はすでに英語の文法構造として強く慣用化しているため、現代話者が常に明示的な空間イメージを意識しているわけではない。認知的説明は、この構文の意味が空間的近接と親和性を持つことを示すものであり、直接的な語源説明ではない。

## 8. 句動詞・慣用表現における about

### 8.1 bring about / come about

*bring about* と *come about* は、事態の発生や変化を表す。

例：

- *The new policy brought about major changes.*
- *How did this situation come about?*

*bring about* は「引き起こす」「もたらす」を意味し、作用主が何らかの結果を生じさせる。他方、*come about* は「起こる」「生じる」を意味し、事態がどのように成立したかを問うときによく使われる。

これらの表現には、about の「向きの転換」「状態変化」と関係する歴史的・意味的背景があると考えられる。特に *come about* には、船が向きを変えるという航海用語との関係が指摘されることがある。ただし、現代英語における因果・発生の意味を、航海用語だけから直接説明するのは単純化しすぎである。より適切には、「方向や状態が変わる」という意味領域から、事態の発生・変化を表す用法へ広がったものとして整理できる。

### 8.2 set about

*set about* は、「〜に取りかかる」「〜を始める」を意味する。

例：

- *She set about cleaning the room.*
- *They set about solving the problem.*

この表現では、活動や課題が一つの対象・領域として捉えられ、主体がその作業に関わり始める。about は、課題の周辺に自分の行為を配置し、そこから作業を開始するような意味合いを持つと説明できる。

ただし、*set about* は現代英語では慣用化した句動詞であり、個々の語の意味を足し合わせるだけでは十分に説明できない。*begin* や *start* よりも、やや意図的・組織的に作業へ取りかかる響きを持つことがある。

### 8.3 go about

*go about* は、複数の意味を持つ句動詞である。

例：

- *How should we go about this task?*
- *He went about his work quietly.*
- *She went about telling everyone the news.*

第一の用法では、「どのように対処するか」「どのように進めるか」という意味になる。課題を一つの対象として、その周囲を動きながら手順を探るという比喩で理解できる。

第二の用法では、「仕事をする」「日常的な活動を進める」という意味になる。ここでは、about の「あちこちに動く」「活動領域内で動き回る」という性質が残っている。

第三の *go about V-ing* では、「あちこちで〜して回る」という意味になる。これは空間的分散移動と行為の反復が結びついた用法である。

### 8.4 move about / run about / look about

about は移動・探索・視線の動詞ともよく結びつく。

例：

- *The dog ran about the yard.*
- *She looked about the room.*
- *He moved about nervously.*

これらの表現では、TR の移動や視線が一方向に固定されず、領域内の複数の地点へ向かう。about は、移動の分散性、探索性、落ち着きのなさ、または全体を見回す動きを表す。

*look about the room* は、部屋の中の一箇所だけを見るのではなく、部屋全体に視線を走らせることを意味する。この用法は、物理的な移動ではなく、視線や注意の移動として理解できる。

## 9. 言語間比較：about の特異性と一般性

### 9.1 英語における topic about の特徴

英語では、主題を表す表現として *about* が非常に広く用いられる。

例：

- *talk about religion*
- *think about the future*
- *a book about history*
- *questions about grammar*

他言語では、これに対応する表現が必ずしも「周辺」や「近接」に由来する語で表されるとは限らない。たとえば、ロマンス諸語では「〜について」に相当する表現として、所有・起点・関係を表す前置詞が用いられる場合が多い。イタリア語では *parlare di X*、フランス語では *parler de X* が基本的である。一方、専門的な主題を示す場合には、英語の *on* に近い表現が使われることもある。

ロシア語などのスラブ語では、主題を表す専用の前置詞・格構造が用いられる。したがって、英語の *talk about X* をそのまま「話題は周囲を巡るもの」とする概念化が、すべての言語に共通するわけではない。

### 9.2 近似表現としての about / around

数量・時間の近似については、多くの言語が「周辺」「近く」「およそ」に相当する表現を用いる。これは、数量や時間を点として捉え、その周辺に実際の値があると考える認知的傾向が、言語を超えて比較的理解しやすいことを示している。

ただし、具体的にどの語が近似を担うかは言語ごとに異なる。英語では about, around, approximately, roughly などが用いられるが、それぞれ文体・精度・談話機能に違いがある。

## 10. 学習上の整理：about の中核感覚

about の多義性を学習上整理するには、以下のように考えると分かりやすい。

about は、対象を一点として厳密に指し示す語ではなく、その周辺、近傍、関連領域、または不特定な範囲を扱う語である。

この中核感覚は、次のように各用法へ反映される。

| 用法 | 中核感覚 |
|---|---|
| *walk about the town* | 町の中をあちこち移動する |
| *papers about the room* | 部屋のあちこちに散らばっている |
| *Is John about?* | ジョンが近く・周辺にいる |
| *about 100 dollars* | 100ドルの周辺の金額 |
| *talk about politics* | 政治をめぐる話をする |
| *something about him* | 彼に付随する何らかの特徴 |
| *be about to leave* | 出発という出来事の直前にいる |
| *bring about change* | 状況の変化を生じさせる |
| *go about the task* | 課題にどう取り組むかを進める |

この整理により、about の多様な用法は、完全に無関係な暗記事項ではなく、「周辺性」「分散」「近接」「関連領域」という意味傾向を共有するネットワークとして理解できる。

## 11. 結論

英語の **about** は、空間的な「あたり」「周辺」「あちこち」という用法から、数量・時間の近似、主題・関連性、個人に付随する属性、近接未来、句動詞における発生・着手・対処などへ広がる多義語である。

その意味構造は、単一の原義からすべてが論理的に派生したものとしてではなく、複数の意味クラスターが相互に関連するネットワークとして捉えるのが適切である。

about の中心には、次のような意味傾向がある。

第一に、about は一点への厳密な到達や接触ではなく、対象の周辺・近傍・関連領域を示す。

第二に、about は方向性の明確な経路よりも、不特定な移動、分散、探索、全体的な関与を表しやすい。

第三に、about は空間的近接から、数量・時間の近似、主題への関連、出来事発生の切迫へと拡張される。

第四に、about の多くの用法は認知的に関連づけられるが、現代英語では慣用化・文法化しているものも多いため、すべてを空間図式だけで説明し尽くすことはできない。

したがって、about の理解において重要なのは、「〜について」「約」「あたりに」という訳語を個別に覚えることではなく、それらの背後にある「対象を厳密に一点化せず、その周辺・近傍・関連領域として捉える」という柔らかい焦点化の感覚を把握することである。
