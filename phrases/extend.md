# extend — 頻出フレーズ

| フレーズ・型 | 意味・使い方 |
|---|---|

| extend a contract | 契約を延長する |
| extend a visa | ビザの有効期間を延長する |
| extend a stay | 滞在を延長する |
| extend a period | 期間を延長する |
| extend working hours | 営業・勤務時間を延長する |
| extend the range | 範囲を広げる |
| extend coverage | 対象範囲を広げる |
| extend a service | サービスを拡大する |
| extend a network | ネットワークを拡張する |
| extend a building | 建物を増築する |
| extend a road | 道路を延伸する |
| extend from A to B | AからBまで広がる |
| extend across ... | …にわたって広がる |
| extend beyond ... | …を超えて広がる |
| extend into ... | …へ延びる |
| extend over a period | ある期間にわたる |
| extend your hand | 手を差し出す |
| extend your arms | 腕を伸ばす |
| extend an invitation | 招待する |
| extend an offer | 申し出をする |

| extend sympathy | お悔やみ・同情を表す |
| extend credit | 信用・融資を供与する |
| extend a loan | 融資する |
| extend protection to ... | …まで保護対象を広げる |
| extend the life of ... | …の寿命を延ばす |
| extend an existing system | 既存制度を拡張する |

## 要点

期間には `extend a deadline/contract`、範囲には `extend coverage/range`、儀礼的な表現には `extend an invitation/thanks` を使います。
