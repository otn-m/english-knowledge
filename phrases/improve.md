|---|---|
| improve quality | 品質を改善する |
| improve performance | 成績・性能を改善する |
| improve efficiency | 効率を高める |
| improve productivity | 生産性を高める |

| improve health | 健康を改善する |
| improve skills | 技能を向上させる |
| improve knowledge | 知識を深める |
| improve communication | 意思疎通を改善する |
| improve access to ... | ～へのアクセスを改善する |
| improve services | サービスを改善する |
| improve conditions | 状況を改善する |

## 要点

他動詞では何かを改善し、自動詞では状態が改善する。既存のものを上回るなら `improve on`。
