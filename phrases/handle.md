# handle — 頻出フレーズ

NGSL順位: 1041

| フレーズ・型 | 意味・使い方 |
|---|---|
| handle a situation | 状況に対処する |
| handle a problem | 問題を処理する |
| handle a complaint | 苦情に対応する |
| handle a request | 依頼を処理する |
| handle a case | 事件・案件を担当する |
| handle a crisis | 危機に対処する |
| handle pressure | プレッシャーに対処する |
| handle stress | ストレスに対処する |
| handle responsibility | 責任を担う |
| handle the job | その仕事をこなす |
| handle the matter | その件を処理する |
| handle the situation well | 状況にうまく対処する |
| carefully handle ... | …を慎重に扱う |
| properly handle ... | …を適切に扱う |
| be able to handle ... | …に対処できる |
| difficult to handle | 扱いにくい |
| easy to handle | 扱いやすい |
| cannot handle ... | …には対処できない |
| handle with care | 取り扱い注意 |
| handle food safely | 食品を安全に扱う |
| handle money | 金銭を扱う |
| handle data | データを処理する |
| handle equipment | 機器を扱う |
| handle a weapon | 武器を扱う |
| a door handle | ドアの取っ手 |
| a long handle | 長い柄 |
| turn the handle | 取っ手を回す |
| grab the handle | 取っ手をつかむ |
| get a handle on ... | …を把握する |
| fly off the handle | 急に激怒する |
| too hot to handle | 扱いきれないほど厄介な |
| a social media handle | SNSのユーザー名 |

## 要点

動詞では「扱う・対処する」、名詞では「取っ手」です。`get a handle on ...` は「…を把握する」を意味します。
