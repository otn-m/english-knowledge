# respectively — 頻出フレーズ

NGSL順位: 2018

| フレーズ・型 | 意味・使い方 |
|---|---|
| A and B, respectively | それぞれAとB |
| X and Y are A and B, respectively | XとYはそれぞれAとBである |
| X and Y scored A and B, respectively | XとYはそれぞれA点とB点を取った |
| X and Y cost A and B, respectively | XとYはそれぞれAとBの価格である |
| X and Y rose by A and B, respectively | XとYはそれぞれAとB上昇した |
| X and Y fell by A and B, respectively | XとYはそれぞれAとB低下した |
| X and Y increased to A and B, respectively | XとYはそれぞれAとBに増えた |
| X and Y decreased to A and B, respectively | XとYはそれぞれAとBに減った |
| X and Y accounted for A and B, respectively | XとYはそれぞれAとBを占めた |
| X and Y represented A and B, respectively | XとYはそれぞれAとBを表した |
| X and Y received A and B, respectively | XとYはそれぞれAとBを受け取った |
| X and Y won A and B, respectively | XとYはそれぞれAとBを獲得した |
| X and Y finished first and second, respectively | XとYはそれぞれ1位と2位だった |
| X and Y were born in A and B, respectively | XとYはそれぞれAとBで生まれた |
| X and Y live in A and B, respectively | XとYはそれぞれAとBに住む |
| X and Y belong to A and B, respectively | XとYはそれぞれAとBに属する |
| X and Y correspond to A and B, respectively | XとYはそれぞれAとBに対応する |
| X and Y refer to A and B, respectively | XとYはそれぞれAとBを指す |
| X and Y indicate A and B, respectively | XとYはそれぞれAとBを示す |
| X and Y are shown in Figures A and B, respectively | XとYはそれぞれ図AとBに示される |
| X and Y appear in Tables A and B, respectively | XとYはそれぞれ表AとBに載っている |
| X and Y use methods A and B, respectively | XとYはそれぞれ方法AとBを使う |
| X and Y have values A and B, respectively | XとYはそれぞれAとBの値を持つ |
| X and Y measured A and B, respectively | XとYはそれぞれAとBだった |

| X and Y employ A and B people, respectively | XとYはそれぞれA人とB人を雇う |
| X and Y produce A and B units, respectively | XとYはそれぞれA単位とB単位を生産する |
| X and Y require A and B hours, respectively | XとYはそれぞれA時間とB時間を要する |
| X and Y are known as A and B, respectively | XとYはそれぞれAとBとして知られる |
| X and Y mean A and B, respectively | XとYはそれぞれAとBを意味する |

## 要点

前に並べた複数項目と、後ろの情報を同じ順序で対応させる「それぞれ」を表します。
