# operate — 頻出フレーズ

NGSL順位: 915

| フレーズ・型 | 意味・使い方 |
|---|---|
| operate a machine | 機械を操作する |
| operate equipment | 装置を操作する |
| operate a vehicle | 車両を運転・運行する |
| operate a crane | クレーンを操作する |
| operate a computer | コンピューターを操作する |
| operate a business | 事業を運営する |
| operate a service | サービスを運営する |
| operate a factory | 工場を操業する |
| operate a network | ネットワークを運用する |
| operate a system | システムを運用する |
| operate effectively | 効果的に機能する |
| operate efficiently | 効率的に運営・作動する |
| operate safely | 安全に運転・作動する |
| operate independently | 独立して活動する |
| operate normally | 正常に作動する |
| operate under the law | 法律に基づいて活動する |
| operate under a name | ある名称で営業する |
| operate in several countries | 複数の国で事業を行う |
| operate on a global scale | 世界規模で事業を行う |
| operate at a loss | 赤字で営業する |
| operate at full capacity | フル稼働する |
| operate around the clock | 24時間稼働する |
| operate on a patient | 患者を手術する |
| operate on the heart | 心臓を手術する |
| be operated by ... | …によって運営される |
| manually operated | 手動式の |
| electrically operated | 電動式の |
| remotely operated | 遠隔操作式の |
| easy to operate | 操作しやすい |
| difficult to operate | 操作が難しい |
| operate within a framework | 枠組みの中で活動する |
| operate without a license | 無許可で営業する |

## 要点

機械・事業を目的語に取る `operate a machine/business` と、手術の `operate on a patient` を区別します。
