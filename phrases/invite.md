# invite — 頻出フレーズ

NGSL順位: 1028

| フレーズ・型 | 意味・使い方 |
|---|---|
| invite someone to ... | 人を…に招待する |
| invite someone to do ... | 人に…するよう招く |
| invite someone in | 人を中へ招き入れる |
| invite someone over | 人を家に招く |
| invite someone out | 人を外出・デートに誘う |
| invite a friend | 友人を招待する |
| invite guests | 客を招く |
| invite questions | 質問を受け付ける |
| invite comments | コメントを求める |
| invite applications | 応募を受け付ける |
| invite proposals | 提案を募集する |
| invite criticism | 批判を招く |
| invite trouble | 面倒を招く |
| invite discussion | 議論を促す |
| formally invite ... | …を正式に招待する |
| personally invite ... | …を個人的に招待する |
| warmly invite ... | …を心から招待する |
| be invited to ... | …に招待される |
| be invited to do ... | …するよう招かれる |
| feel invited | 招かれていると感じる |
| an invited guest | 招待客 |
| everyone is invited | 誰でも参加できます |
| you are invited | ご招待します |
| thanks for inviting me | 招待してくれてありがとう |
| invite someone for dinner | 人を夕食に招く |
| invite someone to a party | 人をパーティーに招く |
| invite someone to join ... | 人に…へ加わるよう誘う |
| invite someone to speak | 人に講演を依頼する |
| invite someone back | 人を再び招く／家へ誘う |
| invite someone along | 人を一緒に来るよう誘う |
| invite a response | 反応を促す |
| invite comparison with ... | …との比較を招く |

## 要点

場所・催しには `invite someone to ...`、行為には `invite someone to do ...` を使います。`invite trouble/criticism` は「招く」です。
