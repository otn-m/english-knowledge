# assume — 頻出フレーズ

NGSL順位: 870

| フレーズ・型 | 意味・使い方 |
|---|---|
| assume that ... | …だと仮定する／思い込む |
| assume someone is ... | 人が…だと思い込む |
| assume the worst | 最悪の事態を想定する |
| assume the best | 最善だと考える |
| naturally assume ... | 当然…だと思う |
| reasonably assume ... | 合理的に…と考える |
| safely assume ... | …と考えてまず間違いない |
| wrongly assume ... | 誤って…と思い込む |
| simply assume ... | 単純に…と決めつける |
| do not assume ... | …と決めつけないでください |
| it is reasonable to assume that ... | …と考えるのが妥当だ |
| we can assume that ... | …と仮定できる |
| let us assume that ... | …と仮定しよう |
| assume for a moment that ... | ひとまず…と仮定する |
| assume responsibility | 責任を引き受ける |
| assume full responsibility | 全責任を負う |
| assume responsibility for ... | …の責任を引き受ける |
| assume control | 支配・管理を引き継ぐ |
| assume control of ... | …の管理権を握る |
| assume office | 就任する |
| assume power | 権力を握る |
| assume command | 指揮を執る |
| assume leadership | 指導的立場を引き受ける |
| assume a role | 役割を担う |
| assume the role of ... | …の役割を担う |
| assume a position | 役職に就く／姿勢を取る |
| assume a new identity | 新しい身分を名乗る |
| assume a different form | 別の形を取る |
| assume greater importance | より大きな重要性を持つようになる |
| assume an air of confidence | 自信ありげな態度を取る |
| be assumed to be ... | …だと想定されている |
| commonly assumed | 一般に当然だと思われている |

## 要点

「仮定する」には `assume that ...`、「引き受ける」には `assume responsibility/control/a role` を使います。
