# connect — 頻出フレーズ

| フレーズ・型 | 意味・使い方 |
|---|---|

| connect to Wi-Fi | Wi-Fiに接続する |
| connect to a server | サーバーに接続する |
| connect a device | 機器を接続する |
| connect a cable | ケーブルを接続する |
| connect your phone to ... | 電話を…に接続する |
| connect people | 人々を結びつける |

| be connected with ... | …と関係がある |

| connect up ... | …を接続する |

## 要点

物理的・電子的に接続することと、人・考えを関連づけることを表します。機器には `connect A to B`、関係には `connect A with B` が一般的です。
