# negotiate — 頻出フレーズ

NGSL順位: 2002

| フレーズ・型 | 意味・使い方 |
|---|---|
| negotiate with someone | 人と交渉する |
| negotiate over something | 〜をめぐって交渉する |
| negotiate for something | 〜を求めて交渉する |
| negotiate a deal | 取引をまとめる |
| negotiate an agreement | 合意を交渉でまとめる |
| negotiate a contract | 契約を交渉する |
| negotiate a settlement | 和解を交渉する |
| negotiate a treaty | 条約を交渉する |
| negotiate a peace agreement | 和平合意を交渉する |
| negotiate terms | 条件を交渉する |
| negotiate a price | 価格を交渉する |
| negotiate a salary | 給与を交渉する |
| negotiate a loan | 融資条件を交渉する |
| negotiate directly | 直接交渉する |
| negotiate successfully | 交渉を成功させる |
| negotiate in good faith | 誠意を持って交渉する |
| be willing to negotiate | 交渉する意思がある |
| refuse to negotiate | 交渉を拒否する |
| agree to negotiate | 交渉に同意する |
| continue to negotiate | 交渉を続ける |
| attempt to negotiate | 交渉を試みる |
| negotiate on behalf of someone | 人を代表して交渉する |
| negotiate your way through something | 〜をうまく切り抜ける |
| negotiate a curve | カーブをうまく通る |
| negotiate a narrow road | 狭い道を通り抜ける |
| negotiate an obstacle | 障害を切り抜ける |
| negotiate stairs | 階段を慎重に上り下りする |
| negotiate the release of someone | 人の釈放を交渉する |
| negotiate a compromise | 妥協案をまとめる |
| negotiate from a position of strength | 優位な立場から交渉する |

## 要点

合意を目指して「交渉する」と、難しい場所・障害を「うまく通り抜ける」を表します。
