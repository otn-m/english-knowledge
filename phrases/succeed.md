# succeed — 頻出フレーズ

NGSL順位: 1586

| フレーズ・型 | 意味・使い方 |
|---|---|
| succeed in doing | ～することに成功する |
| succeed in business | 事業で成功する |
| succeed in life | 人生で成功する |
| succeed at school | 学校でよい成果を上げる |
| succeed at work | 仕事で成功する |
| succeed as ... | ～として成功する |
| succeed through hard work | 努力によって成功する |
| succeed despite ... | ～にもかかわらず成功する |
| succeed where others failed | 他の人が失敗したところで成功する |
| try to succeed | 成功しようとする |
| be determined to succeed | 成功する決意がある |
| manage to succeed | 何とか成功する |
| ultimately succeed | 最終的に成功する |
| eventually succeed | やがて成功する |
| finally succeed | ついに成功する |
| largely succeed | おおむね成功する |
| fail to succeed | 成功できない |
| help someone succeed | 人の成功を助ける |
| enable someone to succeed | 人が成功できるようにする |
| have what it takes to succeed | 成功に必要な資質がある |
| succeed someone as ... | 人の後任として～になる |
| succeed to the throne | 王位を継承する |
| be succeeded by ... | ～に後を継がれる |
| succeed in attracting ... | ～を引きつけることに成功する |

| succeed in reaching ... | ～に到達することに成功する |
| succeed in convincing ... | ～を説得することに成功する |
| if we are to succeed | 私たちが成功するためには |
| succeed or fail | 成功するか失敗するか |
| succeed beyond expectations | 予想以上に成功する |
| nothing succeeds like success | 成功ほど次の成功を呼ぶものはない |

## 要点

行為の成功は `succeed in doing` で、`succeed to do` とはしない。人の後任になる場合は `succeed someone as ...`。
