# spell — 頻出フレーズ

NGSL順位: 1972

| フレーズ・型 | 意味・使い方 |
|---|---|
| spell a word | 単語をつづる |
| spell your name | 名前のつづりを言う |
| spell something correctly | 〜を正しくつづる |
| spell something wrong | 〜を間違ってつづる |
| How do you spell ...? | …はどうつづりますか |
| Can you spell that? | それのつづりを言えますか |
| spell out a word | 単語を一字ずつつづる |
| spell out the details | 詳細を明確に説明する |
| spell out the consequences | 結果を明確に説明する |
| spell trouble | 問題を意味する |
| spell disaster | 災難につながる |
| spell danger | 危険を意味する |
| a magic spell | 魔法の呪文 |
| cast a spell | 魔法をかける |
| cast a spell on someone | 人に魔法をかける |
| break a spell | 魔法を解く |
| be under a spell | 魔法にかかっている |
| a powerful spell | 強力な呪文 |
| a dry spell | 日照り・不振の期間 |
| a cold spell | 寒波 |
| a hot spell | 暑い時期 |
| a wet spell | 雨続きの期間 |
| a brief spell | 短期間 |
| a long spell | 長期間 |
| a spell of bad weather | 悪天候の期間 |
| a spell in hospital | 入院期間 |
| a spell of unemployment | 失業期間 |
| dizzy spell | めまいの発作 |
| fainting spell | 失神発作 |
| have a spell of something | 〜の期間・発作を経験する |

## 要点

単語を「つづる」、結果を「意味する」、名詞では「呪文・一定期間・発作」を表します。
