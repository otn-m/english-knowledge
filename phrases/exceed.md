# exceed — 頻出フレーズ

NGSL順位: 2508

| フレーズ・型 | 意味・使い方 |
|---|---|
| exceed expectations | 期待を上回る |
| exceed a limit | 限度を超える |
| exceed the speed limit | 制限速度を超える |
| exceed the maximum | 最大値を超える |
| exceed the budget | 予算を超過する |
| exceed the target | 目標を上回る |
| exceed a quota | 割り当て量を超える |
| exceed capacity | 収容・処理能力を超える |
| exceed demand | 需要を上回る |
| exceed supply | 供給を上回る |
| exceed costs | 費用を上回る |
| exceed income | 所得を上回る |
| exceed $1 million | 100万ドルを超える |
| exceed 100 degrees | 100度を超える |
| exceed the national average | 全国平均を上回る |
| exceed previous levels | 以前の水準を上回る |
| far exceed ... | ～をはるかに上回る |
| greatly exceed ... | ～を大幅に上回る |
| significantly exceed ... | ～をかなり上回る |
| easily exceed ... | ～を軽く上回る |
| not exceed ... | ～を超えない |
| must not exceed ... | ～を超えてはならない |
| be expected to exceed ... | ～を超えると予想される |
| costs exceeded estimates | 費用が見積もりを上回った |
| benefits exceed risks | 利益がリスクを上回る |
| demand exceeds supply | 需要が供給を上回る |
| exceed someone's authority | 人の権限を越える |
| exceed your powers | 自分の権限を越える |
| exceed all bounds | あらゆる限度を超える |
| exceedingly difficult | 極めて難しい |

## 要点

数量・水準・権限が基準を「超える・上回る」を表す改まった語です。前置詞なしで目的語を直接取ります。
