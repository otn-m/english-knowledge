# locate — 頻出フレーズ

NGSL順位: 1450

| フレーズ・型 | 意味・使い方 |
|---|---|
| locate someone | 人の居場所を突き止める |
| locate something | ～の位置を突き止める |
| locate a missing person | 行方不明者を捜し当てる |
| locate the source | 発生源を特定する |
| locate the problem | 問題箇所を特定する |
| locate the cause | 原因を突き止める |
| locate a fault | 故障箇所を見つける |
| locate a file | ファイルを見つける |
| locate a device | 端末の位置を特定する |
| locate a business | 店・会社の場所を見つける |
| locate on a map | 地図上で位置を示す |
| easily locate ... | ～を簡単に見つける |
| quickly locate ... | ～をすぐに見つける |
| accurately locate ... | ～の位置を正確に特定する |
| be located in ... | ～に位置している |
| be located at ... | ～に所在する |
| be located near ... | ～の近くに位置する |
| be located next to ... | ～の隣に位置する |
| be located between A and B | AとBの間に位置する |
| be centrally located | 中心部に位置する |
| be conveniently located | 便利な場所にある |
| be ideally located | 理想的な場所にある |

| be located downtown | 中心街に位置する |
| be located overseas | 海外に置かれている |

| decide where to locate ... | ～をどこに置くか決める |
| help locate ... | ～を見つけるのを助ける |

| difficult to locate | 見つけにくい |

## 要点

能動形は「位置を突き止める」、受け身の `be located in/at ...` は「～に位置する」。後者は場所の案内で特に頻出。
