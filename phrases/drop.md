# drop — 頻出フレーズ

NGSL順位: 640

| フレーズ・型 | 意味・使い方 |
|---|---|
| drop ... | …を落とす |
| drop the ball | ボールを落とす、へまをする |
| drop your phone | 携帯電話を落とす |
| drop a glass | グラスを落とす |
| drop ... on the floor | …を床に落とす |
| drop ... into ... | …を…の中に落とす |
| drop by ... | …だけ低下する |
| drop to ... | …まで低下する |
| drop from A to B | AからBに低下する |
| prices dropped | 価格が下がった |
| temperatures drop | 気温が下がる |
| sales drop | 売上が落ちる |
| sharply drop | 急激に低下する |
| significantly drop | 大幅に低下する |
| suddenly drop | 急に落ちる |
| a sharp drop | 急落 |
| a significant drop | 大幅な低下 |
| a sudden drop | 突然の低下 |
| a drop in prices | 価格の下落 |
| a drop of 10 percent | 10パーセントの低下 |
| a drop of water | 一滴の水 |
| a drop of blood | 一滴の血 |
| eye drops | 目薬 |
| drop off ... | …を届ける |
| drop someone off | 人を車から降ろす、送り届ける |
| drop off | 減少する、眠りに落ちる |
| drop by | ちょっと立ち寄る |
| drop in | ふらりと立ち寄る |
| drop out | 脱落する、中退する |
| drop out of school | 学校を中退する |
| drop ... from ... | …を…から外す |
| drop the subject | その話題をやめる |
| drop a hint | ほのめかす |
| drop someone a line | 人に短い便りを送る |
| at the drop of a hat | すぐさま、ためらわずに |

## 要点

変化量は `drop by ...`、到達値は `drop to ...` です。`drop off/by/in/out` はそれぞれ意味が異なります。
