# nor — 頻出フレーズ

NGSL順位: 967

| フレーズ・型 | 意味・使い方 |
|---|---|
| neither A nor B | AでもBでもない |
| neither one nor the other | どちらでもない |
| neither here nor there | 重要でない／どちらともいえない |
| neither now nor later | 今も後でもない |
| neither good nor bad | よくも悪くもない |
| neither right nor wrong | 正しくも間違ってもいない |
| neither true nor false | 真でも偽でもない |
| neither more nor less | 多くも少なくもない |
| neither young nor old | 若くも年老いてもいない |
| neither fish nor fowl | どっちつかずのもの |
| neither rhyme nor reason | 筋道も理由もない |
| nor do I | 私もそうしない |
| nor am I | 私もそうではない |
| nor can I | 私にもできない |
| nor could I | 私にもできなかった |
| nor will I | 私もそうするつもりはない |
| nor would I | 私もそうしないだろう |
| nor should I | 私もそうすべきではない |
| nor have I | 私もしたことがない |
| nor did I | 私もしなかった |
| nor is it | それも…ではない |

| nor was it | それも…ではなかった |
| nor does this mean that ... | だからといって…という意味でもない |
| nor is there any reason to ... | …する理由もない |
| not A, nor B | Aではなく、Bでもない |
| no time nor money | 時間もお金もない |
| nor even ... | …さえもない |
| nor necessarily ... | 必ずしも…でもない |
| nor indeed ... | 実際…でもない |
| nor yet ... | かといってまだ…でもない |

## 要点

基本は `neither A nor B` です。前の否定内容に同意・追加するときは倒置して `nor do/can/have I` とします。
