# remove — 頻出フレーズ

NGSL順位: 1053

| フレーズ・型 | 意味・使い方 |
|---|---|
| remove something from ... | …から物を取り除く |
| remove a stain | しみを取る |
| remove dirt | 汚れを落とす |
| remove dust | ほこりを取る |
| remove your shoes | 靴を脱ぐ |
| remove your coat | コートを脱ぐ |
| remove the lid | ふたを外す |
| remove the cover | カバーを外す |
| remove a file | ファイルを削除する |
| remove an item | 項目を削除する |
| remove content | コンテンツを削除する |
| remove a restriction | 制限を撤廃する |
| remove a barrier | 障壁を取り除く |
| remove an obstacle | 障害を取り除く |
| remove a threat | 脅威を排除する |
| remove doubt | 疑いを取り除く |
| remove the need for ... | …の必要をなくす |
| completely remove ... | …を完全に取り除く |
| carefully remove ... | …を慎重に取り外す |
| easily removed | 簡単に取り外せる |
| difficult to remove | 取り除きにくい |
| remove someone from office | 人を公職から解任する |
| remove someone from power | 人を権力の座から追う |
| be removed from a position | 役職を解かれる |
| remove a tumor | 腫瘍を切除する |
| surgically remove ... | …を外科的に切除する |
| remove waste | 廃棄物を除去する |
| remove excess water | 余分な水分を取り除く |
| remove all traces of ... | …の痕跡をすべて消す |
| remove yourself from ... | …から身を引く |
| one step removed from ... | …から一段階隔たって |
| far removed from ... | …とかけ離れて |

## 要点

基本は `remove A from B` です。物理的な除去・衣服を脱ぐ・データ削除・解任などに広く使います。
