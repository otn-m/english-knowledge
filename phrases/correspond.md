# correspond — 頻出フレーズ

NGSL順位: 2399

| フレーズ・型 | 意味・使い方 |
|---|---|
| correspond to ... | ～に対応する |
| correspond with ... | ～と一致する・文通する |
| correspond closely to ... | ～と密接に対応する |
| correspond exactly to ... | ～と正確に一致する |
| correspond roughly to ... | ～におおよそ相当する |
| correspond directly to ... | ～に直接対応する |
| correspond broadly to ... | ～に大体対応する |
| correspond to reality | 現実と一致する |
| correspond to the facts | 事実と一致する |
| correspond to a category | 分類に対応する |
| correspond to a period | 時期に相当する |
| correspond to an increase | 増加に対応する |
| correspond with the data | データと一致する |
| correspond with the description | 説明と一致する |
| correspond with expectations | 予想と一致する |
| correspond with one another | 互いに対応する |
| fail to correspond to ... | ～と一致しない |
| appear to correspond to ... | ～に対応するように見える |
| seem to correspond with ... | ～と一致するように思える |
| the corresponding number | 対応する数字 |
| the corresponding period | 前年などの同じ期間 |
| the corresponding value | 対応する値 |
| the corresponding figure | 対応する数値 |
| the corresponding increase | それに対応する増加 |
| in the corresponding category | 対応する分類で |
| correspond by email | メールでやり取りする |
| correspond regularly | 定期的に文通する |
| correspond with a friend | 友人と文通する |
| a foreign correspondent | 海外特派員 |
| business correspondence | 業務上の通信・書簡 |

## 要点

`correspond to/with` で「対応・一致する」を表します。`correspond with a person` には「人と文通する」という意味もあります。
