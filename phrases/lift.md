# lift — 頻出フレーズ

NGSL順位: 1167

| フレーズ・型 | 意味・使い方 |
|---|---|
| lift something up | 物を持ち上げる |
| lift someone up | 人を抱き上げる・元気づける |
| lift something off ... | 物を…から持ち上げる |
| lift something out of ... | 物を…から持ち上げて出す |
| lift a box | 箱を持ち上げる |
| lift your head | 顔を上げる |
| lift your hand | 手を上げる |
| lift weights | ウエイトトレーニングをする |
| heavy lifting | 重量物を持ち上げる作業・大仕事 |
| lift a ban | 禁止を解除する |
| lift restrictions | 制限を解除する |
| lift sanctions | 制裁を解除する |
| lift a blockade | 封鎖を解除する |
| lift someone's spirits | 人を元気づける |
| lift the mood | 雰囲気を明るくする |
| the fog lifts | 霧が晴れる |
| the clouds lift | 雲が晴れる・気分が晴れる |
| lift off | 離陸する |
| get a lift | 車に乗せてもらう |
| give someone a lift | 人を車で送る |
| need a lift | 車で送ってもらう必要がある |
| a lift home | 家まで車で送ってもらうこと |
| take the lift | エレベーターに乗る（英） |
| a lift to the top floor | 最上階行きのエレベーター |
| a ski lift | スキーリフト |
| a face-lift | 美容整形・刷新 |

| a much-needed lift | 待ち望まれた励み・上昇 |

| lift someone out of poverty | 人を貧困から救い上げる |
| lift your eyes to ... | …へ目を上げる |

## 要点

物を持ち上げるほか、禁止の解除、気分の向上にも使います。英語の `lift` は米語の `elevator`、`give someone a lift` は車で送ることです。
