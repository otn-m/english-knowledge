NGSL順位: 2099

| フレーズ・型 | 意味・使い方 |
|---|---|
| assist someone | 人を手伝う |
| assist someone with something | 人の〜を手伝う |
| assist someone in doing something | 人が〜するのを助ける |
| assist someone to do something | 人が〜するのを助ける |
| assist with a task | 作業を手伝う |
| assist with an investigation | 捜査に協力する |
| assist with the development | 開発を支援する |
| assist in the process | その過程を助ける |

| assist in the search | 捜索を手伝う |
| assist in recovery | 回復を助ける |
| assist the police | 警察に協力する |
| assist customers | 顧客を手助けする |
| assist patients | 患者を介助する |
| assist staff | 職員を支援する |
| assist refugees | 難民を支援する |
| be happy to assist | 喜んでお手伝いする |
| be available to assist | 支援できる状態にある |

| provide an assist | アシストを記録する |

## 要点

やや改まった「手伝う・支援する」です。基本形は `assist someone with something` と `assist in doing` です。
