| フレーズ・型 | 意味・使い方 |
|---|---|

| regulate a market | 市場を規制する |
| regulate trade | 貿易を規制する |
| regulate business | 事業活動を規制する |
| regulate banks | 銀行を規制する |
| regulate financial institutions | 金融機関を規制する |
| regulate the use of ... | ～の使用を規制する |
| regulate access to ... | ～へのアクセスを規制する |
| regulate prices | 価格を規制する |
| regulate emissions | 排出量を規制する |
| regulate pollution | 汚染を規制する |

| regulate working conditions | 労働条件を規制する |
| strictly regulate | 厳格に規制する |
| heavily regulated | 厳しく規制された |
| poorly regulated | 規制が不十分な |
| be regulated by law | 法律で規制される |
| laws regulating ... | ～を規制する法律 |
| a regulated market | 規制市場 |

| self-regulation | 自己調整 |
| government regulation | 政府規制 |

## 要点

法律で活動を「規制する」と、身体機能・流れ・速度などを一定に「調節する」を表します。
