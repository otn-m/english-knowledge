# anxious — 頻出フレーズ

NGSL順位: 2666

| フレーズ・型 | 意味・使い方 |
|---|---|
| feel anxious | 不安を感じる |
| become anxious | 不安になる |
| get anxious | 不安になる |
| look anxious | 不安そうに見える |
| seem anxious | 不安そうである |
| sound anxious | 不安そうに聞こえる |
| increasingly anxious | ますます不安になって |
| extremely anxious | 極度に不安な |
| deeply anxious | 深く不安に思って |
| a little anxious | 少し不安な |
| anxious about ... | …を心配して |
| anxious about the future | 将来を心配して |
| anxious about money | お金のことを心配して |
| anxious about an exam | 試験を心配して |
| anxious about doing ... | …することを心配して |
| anxious for someone | 人のことを心配して |
| anxious that ... | …ではないかと心配して |
| anxious to do ... | …したくてたまらない |
| anxious to know ... | …を知りたくてたまらない |
| anxious to please | 喜ばせようと必死な |
| anxious to get started | 早く始めたがって |
| make someone anxious | 人を不安にさせる |
| leave someone anxious | 人を不安なままにする |
| anxious thoughts | 不安な考え |
| an anxious look | 不安そうな表情 |
| an anxious expression | 不安そうな表情 |
| an anxious moment | 不安な瞬間 |
| an anxious wait | 不安な気持ちでの待機 |
| an anxious parent | 心配している親 |
| anxious and uncertain | 不安で確信が持てない |

## 要点

`anxious about ...` は「…を心配して」、`anxious to do ...` は「…したくてたまらない」です。後者を単に「楽しみにして」と使うのを避ける話者もいます。
