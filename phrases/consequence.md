# consequence — 頻出フレーズ

NGSL順位: 1228

| フレーズ・型 | 意味・使い方 |
|---|---|
| a consequence of ... | …の結果 |
| as a consequence | その結果 |
| as a consequence of ... | …の結果として |
| a serious consequence | 深刻な結果 |
| a severe consequence | 重大な結果 |
| a major consequence | 大きな結果 |
| a significant consequence | 重要な結果 |
| an unintended consequence | 意図しない結果 |
| an unexpected consequence | 予期しない結果 |
| a long-term consequence | 長期的な影響 |
| a direct consequence | 直接的な結果 |
| an inevitable consequence | 避けられない結果 |

| a positive consequence | よい結果 |
| an economic consequence | 経済的影響 |
| a social consequence | 社会的影響 |
| a political consequence | 政治的影響 |
| a legal consequence | 法的結果 |
| an environmental consequence | 環境への影響 |
| consequences for ... | …への影響 |

| understand the consequences | 結果を理解する |

| bear the consequences | 結果を負う |
| pay the consequences | 報いを受ける |
| of little consequence | ほとんど重要でない |

## 要点

行動・出来事から生じる結果、特に重大な影響を表します。原因には `a consequence of ...`、結果を受ける場合は `face/bear the consequences` がよく使われます。
