# faithfully — 頻出フレーズ

NGSL順位: 2791

| フレーズ・型 | 意味・使い方 |
|---|---|
| faithfully serve | 忠実に仕える |
| serve someone faithfully | 人に忠実に仕える |
| faithfully follow ... | …を忠実に守る |
| faithfully follow instructions | 指示を忠実に守る |
| faithfully follow the rules | 規則を忠実に守る |
| faithfully obey ... | …に忠実に従う |
| faithfully carry out ... | …を忠実に実行する |
| faithfully perform your duties | 職務を忠実に果たす |
| faithfully fulfill a promise | 約束を忠実に果たす |
| faithfully keep a record | 記録を欠かさず付ける |
| faithfully attend ... | …に欠かさず出席する |
| faithfully support ... | …を忠実に支持する |
| faithfully reproduce ... | …を忠実に再現する |
| faithfully represent ... | …を忠実に表現・代表する |
| faithfully reflect ... | …を忠実に反映する |
| faithfully record ... | …を忠実に記録する |
| faithfully copy ... | …を忠実に写す |
| faithfully translate ... | …を忠実に翻訳する |
| faithfully adapt ... | …を忠実に翻案する |
| faithfully preserve ... | …を忠実に保存する |
| remain faithfully married | 貞節な結婚生活を保つ |
| remain faithfully committed | 忠実に尽くし続ける |
| faithfully for many years | 長年にわたり忠実に |
| work faithfully | 誠実に働く |
| promise faithfully to ... | 必ず…すると固く約束する |
| faithfully execute the law | 法律を忠実に執行する |
| faithfully discharge your duties | 職務を忠実に遂行する |
| faithfully observe a tradition | 伝統を忠実に守る |
| faithfully yours | 敬具、親しい手紙の結び |
| Yours faithfully, | 敬具、宛名不明の正式書簡の結び |

## 要点

人・義務・原作などに「忠実に・誠実に」を表します。英式の正式書簡では、宛名が個人名でない場合に `Yours faithfully,` を使います。
