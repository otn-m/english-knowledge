# prevent — 頻出フレーズ

NGSL順位: 1026

| フレーズ・型 | 意味・使い方 |
|---|---|
| prevent someone from doing ... | 人が…するのを妨げる |
| prevent something from happening | 物事が起こるのを防ぐ |
| prevent disease | 病気を予防する |
| prevent infection | 感染を防ぐ |
| prevent illness | 病気を予防する |
| prevent injury | けがを防ぐ |
| prevent accidents | 事故を防ぐ |
| prevent damage | 損害を防ぐ |
| prevent harm | 危害を防ぐ |
| prevent crime | 犯罪を防ぐ |
| prevent violence | 暴力を防ぐ |
| prevent conflict | 紛争を防ぐ |
| prevent war | 戦争を防ぐ |
| prevent a problem | 問題を防ぐ |

| prevent loss | 損失を防ぐ |
| prevent further damage | さらなる損害を防ぐ |

| take steps to prevent ... | …を防ぐための措置を取る |

## 要点

人や物事を妨げる基本形は `prevent A from doing ...` です。病気・事故・損害の予防にも広く使います。
