| フレーズ・型 | 意味・使い方 |
|---|---|

| hold someone responsible for ... | 人に…の責任を負わせる |
| make someone responsible for ... | 人を…の担当にする |
| directly responsible for ... | …に直接責任がある |
| primarily responsible for ... | …に主として責任がある |
| largely responsible for ... | …の主因である |
| partly responsible for ... | …に部分的な責任がある |
| personally responsible for ... | …に個人的責任がある |
| legally responsible for ... | …に法的責任がある |
| financially responsible for ... | …の費用に責任を負う |

| ultimately responsible for ... | …に最終責任がある |

| responsible behavior | 責任ある行動 |
| responsible leadership | 責任ある指導力 |
| responsible use of ... | …の責任ある利用 |

## 要点

原因・担当には `responsible for ...`、上司などへの責任関係には `responsible to someone` を使います。
