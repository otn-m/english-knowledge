# much — 頻出フレーズ

NGSL順位: 91

| フレーズ・型 | 意味・使い方 |
|---|---|
| how much ...? | どれくらいの…・いくらですか |
| how much is it? | いくらですか |
| too much | 多すぎる |
| too much time | 時間がかかりすぎる・多すぎる時間 |
| too much work | 多すぎる仕事 |
| so much | とても多くの・それほど多く |
| so much better | はるかによい |
| so much for ... | …はこれで終わり・…は期待外れだった |
| very much | とても |
| thank you very much | どうもありがとうございます |
| much more | はるかに多く・さらに |
| much less | はるかに少ない・まして…ない |
| much better | はるかによい |
| much worse | はるかに悪い |
| much easier | はるかに簡単な |
| much the same | ほとんど同じ |
| as much as ... | …と同じだけ・…もの |
| as much as possible | できるだけ多く |
| as much as I can | できる限り |
| not much | あまり多くない |
| not much of a ... | 大した…ではない |
| not so much A as B | AというよりむしろB |
| not much longer | もうあまり長くは |
| this much | これだけの量 |
| that much | それだけの量 |
| pretty much | ほとんど・だいたい |
| quite so much | それほどまで多く |
| much of ... | …の多く |
| much of the time | 多くの時間・しばしば |
| make much of ... | …を重視する・大げさに扱う |
| without much difficulty | さほど苦労せずに |
| there is not much point in ... | …してもあまり意味がない |

## 要点

不可算名詞の量を表し、肯定文では `a lot of` のほうが自然な場合が多くあります。比較級を強める `much better/more` も重要です。
