# settle — 頻出フレーズ

NGSL順位: 1303

| フレーズ・型 | 意味・使い方 |
|---|---|
| settle a dispute | 紛争を解決する |
| settle an argument | 口論を収める |
| settle a case | 訴訟・事件を和解で解決する |
| settle a claim | 請求を解決・精算する |
| settle a debt | 借金を清算する |
| settle a bill | 勘定を支払う |
| settle an account | 口座・勘定を精算する |
| settle a matter | 問題を解決する |
| settle a question | 問題に決着をつける |
| settle an issue | 問題を解決する |
| settle out of court | 裁判外で和解する |
| settle your differences | 意見の相違を解消する |
| settle in | 新しい場所になじむ |
| settle down | 落ち着く・定住する |
| settle into ... | …に慣れて落ち着く |
| settle into a routine | 日課になじむ |
| settle on ... | …に決める |
| settle on a date | 日付を決める |
| settle on a price | 価格を決める |
| settle for ... | 不満ながら…で妥協する |
| settle for less | より劣るもので妥協する |
| settle back | 楽な姿勢に戻る |
| settle permanently | 永住する |
| settle the land | 土地に入植する |
| the dust settles | 騒ぎが収まる |

| the weather settles | 天候が安定する |
| be finally settled | ようやく解決・定住する |
| settle an old score | 昔の恨みを晴らす |

| settle payment | 支払いを清算する |

## 要点

争い・支払いを解決すること、場所に定住すること、選択を決めることを表します。`settle for ...` は不本意な妥協です。
