# suspend — 頻出フレーズ

NGSL順位: 2754

| フレーズ・型 | 意味・使い方 |
|---|---|
| suspend operations | 操業を停止する |
| suspend production | 生産を停止する |
| suspend service | サービスを一時停止する |
| suspend flights | 航空便を運休する |
| suspend trading | 取引を停止する |
| suspend talks | 協議を中断する |
| suspend negotiations | 交渉を中断する |
| suspend payments | 支払いを停止する |
| suspend a program | プログラムを一時停止する |
| suspend a project | プロジェクトを一時停止する |
| suspend a policy | 政策の実施を一時停止する |
| suspend a rule | 規則の適用を一時停止する |
| temporarily suspend ... | …を一時的に停止する |
| suspend someone from school | 人を停学にする |
| suspend a student | 生徒を停学にする |
| suspend an employee | 従業員を停職にする |
| suspend a player | 選手を出場停止にする |
| suspend someone for two games | 人を2試合の出場停止にする |
| be suspended from duty | 職務停止になる |
| be suspended without pay | 無給の停職処分になる |
| suspend judgment | 判断を保留する |
| suspend disbelief | 不信感を一時的に脇へ置く |
| suspend a sentence | 刑の執行を猶予する |
| a suspended sentence | 執行猶予付き判決 |
| suspend something from the ceiling | 何かを天井からつるす |
| be suspended above ... | …の上につり下げられている |
| suspend particles in liquid | 粒子を液体中に浮遊させる |
| remain suspended | 浮遊・停止したままである |
| suspend your account | アカウントを停止する |
| have your license suspended | 免許停止処分を受ける |

## 要点

活動を「一時停止する」、人を「停職・停学にする」、物を「つるす・浮遊させる」を表します。通常、永久終了ではなく一時的な停止です。
