# request — 頻出フレーズ

NGSL順位: 1011

| フレーズ・型 | 意味・使い方 |
|---|---|
| make a request | 要求・依頼をする |
| submit a request | 依頼・申請を提出する |
| send a request | 依頼を送る |
| receive a request | 依頼を受け取る |
| accept a request | 依頼を受け入れる |
| approve a request | 申請を承認する |
| reject a request | 依頼・申請を却下する |
| deny a request | 要求を拒否する |
| refuse a request | 依頼を断る |
| respond to a request | 依頼に応じる |
| process a request | 依頼・申請を処理する |
| a formal request | 正式な依頼 |
| a written request | 書面による依頼 |
| a reasonable request | 妥当な要求 |
| an urgent request | 緊急の依頼 |
| a special request | 特別な要望 |
| a request for information | 情報提供の依頼 |
| a request for help | 援助の依頼 |
| a request to do ... | …するよう求めること |
| at someone's request | 人の要請で |
| on request | 要望に応じて |
| upon request | 要請があれば |
| by request | リクエストにより |
| request information | 情報を求める |
| request assistance | 援助を要請する |
| request permission | 許可を求める |
| request a copy | 写しを請求する |
| request that ... | …するよう要請する |
| request someone to do ... | 人に…するよう依頼する |
| be requested to do ... | …するよう求められる |
| as requested | 依頼されたとおり |
| request access to ... | …へのアクセスを申請する |

## 要点

名詞では `make/submit a request for ...`、動詞では `request that ...` と `request someone to do ...` を使います。
