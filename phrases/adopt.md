# adopt — 頻出フレーズ

NGSL順位: 1243

| フレーズ・型 | 意味・使い方 |
|---|---|
| adopt a child | 養子を迎える |
| adopt a baby | 赤ちゃんを養子にする |
| adopt a pet | ペットを引き取る |
| adopt a dog | 犬を引き取る |
| adopt a policy | 方針を採用する |
| adopt an approach | 方法・姿勢を採用する |
| adopt a strategy | 戦略を採用する |
| adopt a plan | 計画を採択する |
| adopt a method | 方法を採用する |
| adopt a system | 制度・方式を導入する |
| adopt a standard | 規格を採用する |
| adopt a law | 法律を採択する |
| adopt a rule | 規則を採用する |
| adopt measures | 対策を講じる |
| adopt a position | 立場を取る |
| adopt an attitude | 態度を取る |
| adopt a style | 様式を取り入れる |
| adopt a name | 名前を採用する |
| adopt a proposal | 提案を採択する |
| adopt a resolution | 決議を採択する |
| adopt a recommendation | 勧告を採択する |
| adopt new technology | 新技術を導入する |
| adopt best practices | 最良の実務慣行を採用する |
| formally adopt ... | …を正式に採択する |
| officially adopt ... | …を公式に採用する |
| widely adopt ... | …を広く採用する |
| decide to adopt ... | …を採用すると決める |
| choose to adopt ... | …を採用することを選ぶ |
| refuse to adopt ... | …の採用を拒む |
| be adopted by ... | …に採用・養子にされる |
| become widely adopted | 広く採用されるようになる |

## 要点

子ども・動物を家族として迎えることと、方針・方法を採用することを表します。制度上の決定には `adopt a law/resolution` が使われます。
