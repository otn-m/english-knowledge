# engage — 頻出フレーズ

NGSL順位: 1299

| フレーズ・型 | 意味・使い方 |
|---|---|
| engage in ... | …に従事する |
| engage with ... | …と関わる・対話する |
| engage an audience | 観客・読者を引き込む |
| engage customers | 顧客を引きつける |
| engage employees | 従業員の意欲を高める |
| engage students | 学生を授業に引き込む |
| engage the community | 地域社会と関わる |
| engage the public | 一般市民と関わる |
| engage the enemy | 敵と交戦する |
| actively engage in ... | …に積極的に参加する |
| fully engage with ... | …と十分に関わる |
| directly engage with ... | …と直接対話する |
| engage someone in conversation | 人を会話に引き込む |
| engage someone in debate | 人を議論に参加させる |
| engage someone in an activity | 人を活動に参加させる |
| be engaged in ... | …に従事している |
| be engaged to someone | 人と婚約している |
| get engaged | 婚約する |
| engage someone's attention | 人の注意を引く |
| engage someone's interest | 人の関心を引く |
| engage the services of ... | …のサービスを利用・雇用する |
| engage a lawyer | 弁護士を雇う |
| engage a consultant | コンサルタントを雇う |
| seek to engage ... | …と関わろうとする |
| help engage ... | …を引き込むのに役立つ |
| fail to engage ... | …の関心を引けない |
| the gears engage | 歯車がかみ合う |
| an engaging speaker | 人を引きつける話し手 |
| an engaging story | 魅力的な物語 |
| customer engagement | 顧客エンゲージメント |
| user engagement | 利用者の関与度 |

## 要点

活動への参加、人との関わり、注意を引くこと、雇用、婚約まで表します。活動には `engage in`、相手との対話には `engage with` を使います。
