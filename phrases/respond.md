# respond — 頻出フレーズ

NGSL順位: 1116

| フレーズ・型 | 意味・使い方 |
|---|---|
| respond to someone | 人に返答する |
| respond to a question | 質問に答える |
| respond to a request | 要請に応じる |
| respond to an email | メールに返信する |
| respond to a message | メッセージに返信する |
| respond to criticism | 批判に応答する |
| respond to a crisis | 危機に対応する |
| respond to an emergency | 緊急事態に対応する |
| respond to treatment | 治療に反応する |
| respond to change | 変化に対応する |
| respond that ... | …だと答える |
| respond quickly | 素早く対応する |
| respond immediately | 直ちに対応する |
| respond positively | 前向きに反応する |
| respond negatively | 否定的に反応する |
| respond appropriately | 適切に対応する |
| respond effectively | 効果的に対応する |
| fail to respond | 反応・返答しない |
| refuse to respond | 返答を拒む |
| be slow to respond | 反応が遅い |
| be quick to respond | 反応が速い |
| how do you respond to ...? | …にどう対応しますか |
| respond by doing ... | …することで対応する |
| respond with ... | …で応じる |
| respond in writing | 書面で回答する |
| respond within 24 hours | 24時間以内に回答する |
| respond well to ... | …によく反応する |
| respond directly to ... | …に直接答える |
| respond on behalf of ... | …を代表して回答する |
| respond to the needs of ... | …のニーズに応える |
| an emergency response | 緊急対応 |
| first responders | 緊急対応要員 |

## 要点

相手・対象には必ず `respond to ...` を使います。反応の内容は `respond with/by doing ...` で示します。
