# access — 頻出フレーズ

NGSL順位: 802

| フレーズ・型 | 意味・使い方 |
|---|---|
| have access to ... | …を利用できる |
| gain access to ... | …を利用できるようになる |
| get access to ... | …へのアクセスを得る |
| provide access to ... | …を利用可能にする |
| allow access to ... | …へのアクセスを許可する |
| improve access to ... | …を利用しやすくする |
| increase access to ... | …を利用できる機会を増やす |
| limit access to ... | …へのアクセスを制限する |
| restrict access to ... | …へのアクセスを制限する |
| deny access to ... | …へのアクセスを拒む |
| block access to ... | …へのアクセスを遮断する |
| control access to ... | …へのアクセスを管理する |
| need access to ... | …を利用する必要がある |
| easy access to ... | …への容易なアクセス |
| direct access to ... | …への直接アクセス |
| free access to ... | …の無料・自由な利用 |
| public access | 一般公開・利用 |
| internet access | インターネット接続 |
| online access | オンラインアクセス |
| remote access | リモートアクセス |
| equal access | 平等な利用機会 |
| access to information | 情報へのアクセス |
| access to education | 教育を受ける機会 |
| access to health care | 医療を受ける機会 |
| access to services | サービスの利用 |
| access to resources | 資源の利用 |
| access code | アクセスコード |
| access point | アクセスポイント、接続点 |
| access road | 進入道路 |
| wheelchair access | 車いすでの利用 |
| unauthorized access | 不正アクセス |
| access a file | ファイルにアクセスする |
| access data | データにアクセスする |
| access a website | ウェブサイトにアクセスする |
| easily accessible | 容易に利用・到達できる |

## 要点

名詞は `access to ...`、動詞は前置詞なしで `access a file/website` とします。`access to education/health care` も重要です。
