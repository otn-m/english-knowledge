# pull — 頻出フレーズ

NGSL順位: 799

| フレーズ・型 | 意味・使い方 |
|---|---|
| pull ... | …を引く |
| pull a door open | ドアを引いて開ける |
| pull a handle | 取っ手を引く |
| pull a rope | ロープを引く |
| pull someone's arm | 人の腕を引く |
| pull ... toward you | …を自分の方へ引く |
| pull ... out of ... | …を…から引き出す |
| pull ... away from ... | …を…から引き離す |
| pull ... apart | …を引き離す |
| pull ... tight | …をぴんと張る |
| pull hard | 強く引く |
| push and pull | 押したり引いたりする |
| pull a muscle | 筋肉を痛める |
| pull a tooth | 歯を抜く |
| pull the trigger | 引き金を引く |
| pull the plug | 中止する、生命維持装置を外す |
| pull strings | コネを使う |
| pull someone's leg | 人をからかう |
| pull yourself together | 気を取り直す |
| pull your weight | 自分の役割を果たす |
| pull off ... | …を見事にやり遂げる |
| pull out | 撤退する、車を出す |
| pull out of ... | …から撤退する |
| pull over | 車を路肩に寄せる |
| pull up | 車を止める、引き上げる |
| pull down ... | …を引き下げる、取り壊す |
| pull through | 危機・病気を切り抜ける |
| pull back | 後退する、引き戻す |
| pull ahead | 前に出る |
| pull together | 協力する |
| a strong pull | 強い引力 |
| feel a pull toward ... | …に引かれる気持ちを感じる |
| a pull factor | 人を引きつける要因 |
| pull a face | しかめ面をする |
| pull a crowd | 群衆を引き寄せる |

## 要点

基本の「引く」に加え、`pull out/over/through/together` など重要な句動詞が多数あります。
