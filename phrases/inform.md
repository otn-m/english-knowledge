# inform — 頻出フレーズ

NGSL順位: 1070

| フレーズ・型 | 意味・使い方 |
|---|---|
| inform someone of ... | 人に…を知らせる |
| inform someone about ... | 人に…について知らせる |
| inform someone that ... | 人に…だと知らせる |
| inform the public | 国民・市民に知らせる |
| inform customers | 顧客に知らせる |
| inform the police | 警察に通報する |
| inform your doctor | 医師に知らせる |
| formally inform ... | …に正式に知らせる |
| officially inform ... | …に公式に知らせる |
| immediately inform ... | …に直ちに知らせる |
| fail to inform ... | …に知らせない |
| be informed of ... | …を知らされる |
| be informed about ... | …について知らされる |
| be informed that ... | …だと知らされる |
| keep someone informed | 人に随時情報を伝える |
| keep yourself informed | 常に情報を得ておく |
| please be informed that ... | …であることをお知らせします |
| as previously informed | 以前お知らせしたとおり |
| inform a decision | 判断の材料となる |
| inform policy | 政策形成に情報を与える |
| inform practice | 実践の指針となる |
| research informs ... | 研究が…に情報・知見を与える |
| inform the debate | 議論に知見を与える |
| well-informed | 情報に詳しい |
| an informed decision | 情報に基づく判断 |
| an informed choice | 十分な情報に基づく選択 |
| informed consent | インフォームドコンセント |
| inform against someone | 人を密告する |
| inform on someone | 人を密告する |
| information to inform ... | …の判断材料となる情報 |
| inform future planning | 将来の計画に情報を与える |
| inform someone in writing | 人に書面で通知する |

## 要点

人には `inform someone of/about/that ...` を使います。`inform a decision/policy` は「判断・政策の材料となる」です。
