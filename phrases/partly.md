# partly — 頻出フレーズ

NGSL順位: 1916

| フレーズ・型 | 意味・使い方 |
|---|---|
| partly because ... | 一つには…だから |
| partly due to something | 一部は〜が原因で |
| partly as a result of something | 一部は〜の結果として |
| partly for this reason | 一つにはこの理由で |
| partly responsible | 一部責任がある |
| partly to blame | 一部責任がある |
| partly explained by something | 一部は〜で説明できる |
| partly caused by something | 一部は〜によって引き起こされた |
| partly based on something | 一部は〜に基づく |
| partly dependent on something | 一部は〜に依存する |
| partly funded by something | 一部は〜から資金提供される |
| partly owned by something | 一部は〜が所有する |
| partly controlled by something | 一部は〜が管理する |
| partly covered | 一部覆われた |
| partly cloudy | 晴れ時々曇り・部分的に曇った |
| partly open | 半ば開いた |
| partly closed | 一部閉鎖された |
| partly hidden | 一部隠れた |
| partly visible | 一部見える |
| partly completed | 一部完成した |
| partly successful | 部分的に成功した |
| partly true | 部分的に正しい |
| partly correct | 部分的に正しい |
| partly wrong | 一部間違っている |
| partly agree | 部分的に同意する |
| partly understand | 部分的に理解する |
| partly reflect something | 一部〜を反映する |
| partly offset something | 〜を一部相殺する |
| only partly | 一部だけ |
| at least partly | 少なくとも部分的には |

## 要点

全体ではなく「一部は・部分的に」を表します。原因を複数示す `partly because/due to` が頻出です。
