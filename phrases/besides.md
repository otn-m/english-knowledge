# besides — 頻出フレーズ

NGSL順位: 1725

| フレーズ・型 | 意味・使い方 |
|---|---|
| besides that | そのうえ・それ以外に |
| besides this | このほかに |
| besides which | そのうえ |
| besides being ... | …であることに加えて |
| besides doing something | 〜することに加えて |
| besides someone | 人に加えて・人以外に |
| besides something | 〜に加えて・〜以外に |
| besides me | 私以外に・私に加えて |
| besides you | あなた以外に・あなたに加えて |
| besides work | 仕事以外に |
| besides school | 学校以外に |
| besides English | 英語以外に |
| besides the fact that ... | …という事実に加えて |
| besides these reasons | これらの理由に加えて |
| besides all else | 何よりも・ほかのすべてに加えて |
| What else is there besides ...? | 〜以外に何がありますか |
| Who else besides ...? | 〜以外に誰がいますか |
| no one besides ... | 〜以外には誰もいない |
| nothing besides ... | 〜以外には何もない |
| few people besides ... | 〜以外にはほとんど人がいない |
| everyone besides ... | 〜以外の全員 |
| everything besides ... | 〜以外のすべて |
| and besides, ... | それに… |
| But besides that, ... | しかしそれ以外に… |
| Besides, ... | そのうえ… |
| Besides, it doesn't matter. | そのうえ、それは重要ではない |
| Besides, there's no time. | それに、時間がない |
| besides all that | それらすべてに加えて |
| besides other things | ほかのことに加えて |
| besides many others | ほかの多くのもの・人に加えて |

## 要点

前置詞では「〜に加えて・〜以外に」、文頭の副詞では「そのうえ」を表します。`beside`（〜のそばに）と区別します。
