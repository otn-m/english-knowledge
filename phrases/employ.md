# employ — 頻出フレーズ

NGSL順位: 1294

| フレーズ・型 | 意味・使い方 |
|---|---|
| employ staff | 職員を雇う |
| employ workers | 労働者を雇う |
| employ local people | 地元の人々を雇う |
| employ someone to do ... | …するために人を雇う |
| a company employs ... | 会社が…を雇用している |
| directly employ ... | …を直接雇用する |
| currently employ ... | 現在…を雇用している |
| employ full-time staff | 常勤職員を雇う |
| employ part-time staff | 非常勤職員を雇う |
| be employed by ... | …に雇用されている |
| be employed as ... | …として雇われている |
| be employed in ... | …の分野で働いている |
| be employed on ... | …の仕事に従事している |
| be fully employed | 完全雇用されている |
| be gainfully employed | 収入を得る仕事に就いている |
| employ a method | 方法を用いる |
| employ a strategy | 戦略を用いる |
| employ a technique | 技法を用いる |
| employ a tactic | 戦術を用いる |
| employ a system | 方式を採用する |
| employ technology | 技術を活用する |
| employ force | 武力・力を用いる |
| employ the services of ... | …のサービス・専門技能を利用する |
| employ various means | さまざまな手段を用いる |
| employ the same approach | 同じ方法を採用する |
| employ effectively | 効果的に活用する |
| widely employed | 広く用いられている |
| commonly employed | 一般に用いられている |
| employ more people | より多くの人を雇う |
| employ over 100 workers | 100人を超える労働者を雇う |
| employ yourself in doing ... | …に従事する |

## 要点

人を雇うことと、方法・技術を用いることを表します。受動形では職場に `employed by`、職種に `employed as` を使います。
