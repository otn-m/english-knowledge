# entry — 頻出フレーズ

NGSL順位: 1655

| フレーズ・型 | 意味・使い方 |
|---|---|
| gain entry | 入場・侵入を果たす |
| allow entry | 入場を許可する |
| deny entry | 入場を拒否する |
| refuse entry | 入場を拒む |
| prevent entry | 侵入を防ぐ |
| force entry | 強引に侵入する |
| seek entry | 入場・加入を求める |
| entry into ... | ～への入場・参入 |
| entry to ... | ～への入場 |
| on entry | 入場時に |
| an entry point | 入口／参入点 |
| an entry route | 侵入経路 |
| an entry visa | 入国ビザ |
| an entry permit | 入場・入国許可証 |
| entry requirements | 入場・入学要件 |
| an entry fee | 入場料 |
| free entry | 入場無料 |
| no entry | 進入禁止 |
| a competition entry | コンテスト応募作品 |
| submit an entry | 応募作品を提出する |
| a winning entry | 入賞作品 |
| an entry form | 申込用紙 |
| an entry deadline | 応募締切 |
| a diary entry | 日記の一項目 |
| a journal entry | 日誌・仕訳の一項目 |
| a dictionary entry | 辞書の見出し |
| a data entry | データ入力項目 |
| make an entry | 記入する |
| delete an entry | 項目を削除する |
| an entry-level job | 初級職 |
| market entry | 市場参入 |

## 要点

入場・参入と、一覧や文書の一項目を表す。`entry into/to ...`, `entry requirements/fee`, `dictionary entry` が基本。
