# recognition — 頻出フレーズ

NGSL順位: 2013

| フレーズ・型 | 意味・使い方 |
|---|---|
| gain recognition | 評価・認知を得る |
| receive recognition | 評価を受ける |
| earn recognition | 評価を勝ち取る |
| achieve recognition | 認知・評価を得る |
| seek recognition | 承認を求める |
| deserve recognition | 評価に値する |
| give someone recognition | 人を評価する |
| win international recognition | 国際的評価を得る |
| widespread recognition | 広範な認知 |
| public recognition | 公の評価 |
| international recognition | 国際的承認 |
| official recognition | 公式承認 |
| formal recognition | 正式承認 |
| legal recognition | 法的承認 |
| full recognition | 完全な承認 |
| growing recognition | 高まりつつある認識 |
| recognition of a problem | 問題の認識 |
| recognition of rights | 権利の承認 |
| in recognition of something | 〜を認めて・功績をたたえて |
| beyond recognition | 見分けがつかないほど |
| instant recognition | 一目で分かること |
| visual recognition | 視覚認識 |
| facial recognition | 顔認識 |
| speech recognition | 音声認識 |
| pattern recognition | パターン認識 |
| name recognition | 名前の認知度 |
| brand recognition | ブランド認知 |
| recognition award | 功労賞 |
| a lack of recognition | 評価不足 |
| recognition and reward | 評価と報酬 |

## 要点

人・物を「見分けること」、功績への「評価」、国家・権利などの「承認」を表します。
