# here — 頻出フレーズ

NGSL順位: 98

| フレーズ・型 | 意味・使い方 |
|---|---|

| here and there | あちこちに |
| right here | まさにここに |
| over here | こちらに |
| down here | ここ下方に |
| up here | ここ上方に |
| from here | ここから |
| near here | この近くに |
| around here | この辺りに |
| somewhere here | このどこかに |
| here at home | ここ国内・自宅で |
| here in Japan | ここ日本で |
| here today | 今日ここに |
| be here | ここにいる |
| come here | ここへ来る |
| get here | ここに着く |
| stay here | ここに滞在する |
| live here | ここに住む |
| work here | ここで働く |

| leave here | ここを出る |

| click here | ここをクリック |

| here are | ここに～がある（複数） |

| Here you go. | はい、どうぞ／その調子 |
| Here we are. | 着きました／さあ |
| Here it is. | ここにあります |
| Here comes ... | ～が来ました |
| What are you doing here? | ここで何をしているのですか |
| How did you get here? | どうやってここへ来ましたか |
| Where do we go from here? | ここからどう進めますか |
| neither here nor there | 問題と無関係で |

## 要点

提示の `Here is/are ...` や `Here comes ...` では、名詞主語が後ろに置かれることがある。
