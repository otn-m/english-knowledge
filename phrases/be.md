# be — 頻出フレーズ

NGSL順位: 2

`be` の活用形（`am / is / are / was / were / been / being`）にもそのまま応用できる。単なる文法例ではなく、ひとかたまりで覚える価値が高い表現を優先した。

| フレーズ・型 | 意味・使い方 |
|---|---|
| be able to do | ～することができる |
| be about to do | まさに～しようとしている |
| be allowed to do | ～することを許されている |
| be due to do | ～する予定である |
| be expected to do | ～することを期待・予想されている |
| be likely to do | ～する可能性が高い |
| be meant to do | ～することになっている／～する意図である |
| be supposed to do | ～することになっている／～すべきである |
| be willing to do | 進んで～する |
| be ready to do | ～する準備ができている |
| be going to do | ～するつもりである／～しそうである |
| be used to doing | ～することに慣れている |
| be interested in | ～に興味がある |
| be involved in | ～に関わっている |
| be good at | ～が得意である |
| be afraid of | ～を恐れている |
| be aware of | ～を認識している |
| be proud of | ～を誇りに思う |
| be responsible for | ～に責任がある／～の原因である |
| be known for | ～で知られている |
| be based on | ～に基づいている |
| be related to | ～に関連している |
| be different from | ～と異なる |
| be similar to | ～に似ている |
| be in charge of | ～を担当している |
| be in trouble | 困っている／問題を抱えている |
| be in touch with | ～と連絡を取り合っている |
| be on time | 時間どおりである |
| be right back | すぐ戻る |
| be worth doing | ～する価値がある |
| be no use doing | ～しても無駄である |
| be up to someone | ～次第である |
| be there for someone | 必要なときに（人）を支える |
| to be honest | 正直に言うと |
| to be fair | 公平に言えば |
| let it be | そのままにしておく／成り行きに任せる |

## 要点

- `used to do` は「以前は～した」、`be used to doing` は「～することに慣れている」。
- `be supposed to` は規則・予定・一般的期待に非常によく使われる。
- `be worth` の後ろは通常 `doing`。`to do` にはしない。
