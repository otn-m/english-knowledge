# reflect — 頻出フレーズ

| フレーズ・型 | 意味・使い方 |
|---|---|

| reflect heat | 熱を反射する |
| be reflected in a mirror | 鏡に映る |
| reflect the sun's rays | 太陽光線を反射する |
| reflect reality | 現実を反映する |
| reflect changes | 変化を反映する |
| reflect public opinion | 世論を反映する |
| reflect the views of ... | …の見解を反映する |
| reflect the needs of ... | …のニーズを反映する |
| reflect the importance of ... | …の重要性を示す |
| reflect the fact that ... | …という事実を反映する |

| results reflect performance | 結果が実績を反映する |
| reflect on ... | …を振り返って考える |
| reflect on the past | 過去を振り返る |

## 要点

「反映・反射する」は他動詞の `reflect ...`、「振り返って考える」は `reflect on ...` を使います。
