# click — 頻出フレーズ

NGSL順位: 2514

| フレーズ・型 | 意味・使い方 |
|---|---|
| click a button | ボタンをクリックする |
| click a link | リンクをクリックする |
| click an icon | アイコンをクリックする |
| click a tab | タブをクリックする |
| click the image | 画像をクリックする |
| click the mouse | マウスをクリックする |
| click here | ここをクリック |
| click on the link | リンクをクリックする |
| right-click | 右クリックする |
| double-click | ダブルクリックする |
| click and drag | クリックしてドラッグする |
| one click away | ワンクリックで利用できる |
| with a single click | 1回のクリックで |
| at the click of a button | ボタン一つで |
| a mouse click | マウスのクリック |
| a clicking sound | カチカチという音 |
| hear a click | カチッという音を聞く |
| the door clicked shut | ドアがカチッと閉まった |
| click into place | カチッとはまる |
| click your fingers | 指を鳴らす（主に英国） |
| click your tongue | 舌打ちする |
| things suddenly clicked | 突然すべてが理解できた |
| it finally clicked | ようやく腑に落ちた |
| click with someone | 人と意気投合する |
| we clicked immediately | 私たちはすぐ意気投合した |
| the team began to click | チームがうまくかみ合い始めた |
| click through to ... | クリックして～へ進む |
| a click-through rate | クリック率 |
| click on and off | カチッとオン・オフする |
| a click of the camera | カメラのカシャッという音 |

## 要点

機器の「カチッという音」と、マウスなどを「クリックする」を表します。`click with someone` は意気投合することです。
