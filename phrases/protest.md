# protest — 頻出フレーズ

NGSL順位: 1708

| フレーズ・型 | 意味・使い方 |
|---|---|
| protest against something | 〜に抗議する |
| protest about something | 〜について抗議する |
| protest a decision | 決定に抗議する |
| protest a policy | 政策に抗議する |
| protest peacefully | 平和的に抗議する |
| take to the streets in protest | 抗議のため街頭に出る |
| gather to protest | 抗議のために集まる |
| march in protest | 抗議行進をする |
| a public protest | 公の抗議 |
| a peaceful protest | 平和的な抗議活動 |
| a mass protest | 大規模な抗議活動 |
| a violent protest | 暴力的な抗議活動 |
| a student protest | 学生の抗議運動 |
| an anti-government protest | 反政府抗議活動 |
| a street protest | 街頭抗議 |
| a protest march | 抗議行進 |
| a protest movement | 抗議運動 |
| a protest rally | 抗議集会 |
| a protest vote | 抗議票 |
| organize a protest | 抗議活動を組織する |
| stage a protest | 抗議活動を行う |
| hold a protest | 抗議集会を開く |

| protests erupt | 抗議活動が勃発する |
| protests spread | 抗議活動が広がる |
| in protest at something | 〜に抗議して |
| under protest | 不本意ながら・異議を唱えつつ |
| without protest | 抵抗・異議なく |

## 要点

名詞・動詞ともに「抗議」を表します。動詞は `protest against`、名詞は `in protest at/against` が代表的です。
