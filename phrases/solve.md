# solve — 頻出フレーズ

NGSL順位: 1221

| フレーズ・型 | 意味・使い方 |
|---|---|
| solve a problem | 問題を解決する |
| solve the problem of ... | …という問題を解決する |
| solve a puzzle | パズルを解く |
| solve a mystery | 謎を解く |
| solve a crime | 犯罪事件を解決する |
| solve a case | 事件を解決する |
| solve an equation | 方程式を解く |
| solve a dispute | 紛争を解決する |
| solve a crisis | 危機を解決する |
| solve an issue | 問題を解決する |
| solve for x | xについて方程式を解く |
| solve ... by doing ... | …することで…を解決する |
| solve ... with ... | …を使って…を解決する |
| try to solve ... | …を解決しようとする |
| help solve ... | …の解決に役立つ |
| manage to solve ... | 何とか…を解決する |
| fail to solve ... | …を解決できない |
| quickly solve ... | …を素早く解決する |
| easily solve ... | …を簡単に解決する |
| fully solve ... | …を完全に解決する |
| partially solve ... | …を部分的に解決する |
| permanently solve ... | …を恒久的に解決する |
| solve ... once and for all | …をきっぱり解決する |
| be difficult to solve | 解決するのが難しい |
| be easy to solve | 解決するのが簡単である |
| cannot be solved | 解決できない |
| be solved by ... | …によって解決される |
| work together to solve ... | 協力して…を解決する |
| solve problems creatively | 問題を創造的に解決する |
| a problem-solving approach | 問題解決型の方法 |
| solve it yourself | 自分でそれを解決する |

## 要点

問題・謎・方程式など、答えや解決策を見つける語です。`solve a problem` は「問題そのもの」、`answer a question` は「質問」に使います。
