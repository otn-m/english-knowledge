# require — 頻出フレーズ

NGSL順位: 402

| フレーズ・型 | 意味・使い方 |
|---|---|
| require time | 時間を要する |
| require effort | 努力を要する |
| require attention | 注意を必要とする |
| require care | 注意・世話を必要とする |
| require skill | 技能を必要とする |
| require experience | 経験を必要とする |
| require knowledge | 知識を必要とする |
| require support | 支援を必要とする |
| require treatment | 治療を必要とする |
| require approval | 承認を必要とする |
| require permission | 許可を必要とする |
| require payment | 支払いを必要とする |
| require further study | さらなる研究を必要とする |
| require immediate action | 即時の対応を必要とする |
| require someone to do ... | 人に～するよう求める |
| be required to do ... | ～することを義務づけられる |
| require that ... | ～することを要求する |
| legally require ... | 法的に～を義務づける |
| generally require ... | 一般に～を必要とする |
| no longer require ... | もはや～を必要としない |
| may require ... | ～を必要とする場合がある |
| additional work required | 追加作業が必要 |
| as required | 必要に応じて |
| if required | 必要なら |
| where required | 必要な場合に |
| the required level | 必要水準 |
| required information | 必須情報 |
| required documents | 必要書類 |
| meet the required standard | 必要な基準を満たす |
| require a decision | 決定を必要とする |
| require a change | 変更を必要とする |
| require regular maintenance | 定期保守を必要とする |
| require access to ... | ～へのアクセスを必要とする |
| require doing ... | ～される必要がある（主に英） |
| require careful planning | 慎重な計画を必要とする |

## 要点

`require someone to do` と受動の `be required to do` が基本。`need` より改まった語。
