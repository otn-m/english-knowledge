# pain — 頻出フレーズ

NGSL順位: 1150

| フレーズ・型 | 意味・使い方 |
|---|---|
| feel pain | 痛みを感じる |
| experience pain | 痛みを経験する |
| suffer pain | 痛みに苦しむ |
| be in pain | 痛みがある・苦しんでいる |
| cause pain | 痛みを引き起こす |
| relieve pain | 痛みを和らげる |
| ease the pain | 痛みを軽くする |
| reduce pain | 痛みを減らす |
| manage pain | 痛みを管理する |
| treat pain | 痛みを治療する |
| severe pain | 激しい痛み |
| chronic pain | 慢性的な痛み |
| acute pain | 急性の痛み |
| sharp pain | 鋭い痛み |
| dull pain | 鈍い痛み |
| constant pain | 絶え間ない痛み |
| physical pain | 身体的な痛み |
| emotional pain | 心の痛み |
| back pain | 腰・背中の痛み |
| chest pain | 胸の痛み |
| neck pain | 首の痛み |
| joint pain | 関節痛 |
| pain relief | 鎮痛・痛みの緩和 |
| pain management | 疼痛管理 |
| pain medication | 鎮痛薬 |
| a pain threshold | 痛みに耐えられる限界 |
| a pain in the neck | 面倒な人・物事 |
| no pain, no gain | 苦労なくして得るものなし |
| growing pains | 成長に伴う問題・成長痛 |
| take pains to do ... | …するために骨を折る |
| pain and suffering | 心身の苦痛 |
| a pain-free life | 痛みのない生活 |

## 要点

症状には `be in pain`、緩和には `relieve/ease the pain` が基本です。`a pain in the neck` と `take pains to do` は頻出の慣用表現です。
