# firstly — 頻出フレーズ

NGSL順位: 2665

| フレーズ・型 | 意味・使い方 |
|---|---|
| Firstly, ... | 第一に… |
| Firstly, we need to ... | まず私たちは…する必要がある |
| Firstly, let me explain ... | まず…を説明させてください |
| Firstly, consider ... | まず…を検討してください |
| Firstly, it is important to ... | 第一に…することが重要だ |
| Firstly, I would like to ... | まず…したいと思います |
| Firstly, there is ... | 第一に…がある |
| Firstly, the evidence shows ... | 第一に、証拠は…を示している |
| firstly and secondly | 第一に、第二に |
| firstly, secondly, and finally | 第一に、第二に、最後に |
| firstly because ... | 第一には…だから |
| Firstly, thank you for ... | まず…に感謝します |
| Firstly, ask yourself ... | まず自問してください |
| Firstly, make sure that ... | まず…を確認してください |
| Firstly, check whether ... | まず…かどうかを確認してください |
| Firstly, decide what ... | まず何を…するか決めてください |
| Firstly, identify ... | まず…を特定してください |
| Firstly, choose ... | まず…を選んでください |
| Firstly, remove ... | まず…を取り除いてください |
| Firstly, add ... | まず…を加えてください |
| Firstly, note that ... | まず…に注意してください |
| Firstly, remember that ... | まず…を覚えておいてください |
| Firstly, understand that ... | まず…を理解してください |
| Firstly, this means ... | 第一に、これは…を意味する |
| Firstly, this allows ... | 第一に、これによって…が可能になる |
| Firstly, the cost is ... | 第一に、費用は…である |
| Firstly, the problem is ... | 第一に、問題は…である |
| Firstly, why ...? | 第一に、なぜ…なのか |
| Firstly, how ...? | 第一に、どのように…するのか |
| Firstly, what ...? | 第一に、何が…なのか |

## 要点

論点や手順の「第一に」を表します。主に英語で使われ、米語では `first` がより自然なことが多く、列挙は同じ形式でそろえます。
