# spread — 頻出フレーズ

NGSL順位: 1197

| フレーズ・型 | 意味・使い方 |
|---|---|
| spread across ... | …全体に広がる |
| spread through ... | …を通じて広がる |
| spread throughout ... | …の至る所に広がる |
| spread to ... | …へ広がる |
| spread from A to B | AからBへ広がる |
| spread rapidly | 急速に広がる |
| spread quickly | 素早く広がる |
| spread widely | 広範囲に広がる |
| spread around the world | 世界中に広がる |
| spread the disease | 病気を広める |
| prevent the spread of disease | 病気の拡大を防ぐ |
| stop the spread of ... | …の拡大を止める |
| control the spread of ... | …の拡大を抑える |
| limit the spread of ... | …の拡大を制限する |
| the virus spreads | ウイルスが広がる |
| the fire spreads | 火が燃え広がる |
| spread the news | ニュースを広める |
| spread a rumor | うわさを広める |
| spread information | 情報を広める |
| spread an idea | 考えを広める |
| spread the word | 情報・評判を広める |
| spread butter on bread | パンにバターを塗る |
| spread a cloth over ... | …に布を広げる |
| spread your arms | 両腕を広げる |
| spread your wings | 翼を広げる・活動範囲を広げる |
| spread out | 広がる・間隔を空ける |
| spread ... out on the table | …をテーブルに広げる |
| a wide spread | 大きな差・広がり |
| the spread between ... | …間の差 |
| spread the risk | リスクを分散する |
| a food spread | パンなどに塗る食品 |

## 要点

病気・火・情報が「広がる／広める」と、物を「広げる・塗る」を表します。拡大防止では `prevent/stop the spread of ...` が定型です。
