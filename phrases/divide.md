# divide — 頻出フレーズ

NGSL順位: 1316

| フレーズ・型 | 意味・使い方 |
|---|---|
| divide ... into ... | …を…に分ける |
| divide ... between ... | …を二者間で分ける |
| divide ... among ... | …を三者以上で分ける |
| divide A by B | AをBで割る |
| divide A from B | AとBを隔てる |
| divide equally | 等分する |
| divide evenly | 均等に分ける |
| divide into groups | グループに分ける |
| divide into parts | 部分に分ける |
| divide the work | 仕事を分担する |
| divide responsibilities | 責任を分担する |
| divide your time between ... | …の間で時間を分ける |
| divide your attention | 注意を分散する |
| divide a number | 数を割る |
| divide by zero | ゼロで割る |
| a line divides ... | 線が…を分ける |
| an issue divides people | 問題が人々を分断する |
| be divided on ... | …について意見が分かれている |
| be divided over ... | …をめぐって対立している |
| be deeply divided | 深く分裂している |
| be sharply divided | 意見が真っ二つに分かれている |
| be politically divided | 政治的に分断されている |
| divide up ... | …を分け合う |
| divide and conquer | 分割統治する |
| a social divide | 社会的分断 |
| the digital divide | 情報格差 |
| a growing divide | 拡大する格差 |
| bridge the divide | 分断を埋める |
| cross the divide | 分断・境界を越える |
| widen the divide | 格差・分断を広げる |
| narrow the divide | 格差・分断を縮める |

## 要点

物を分割することと、人・社会を分断することを表します。二者は `between`、三者以上は `among`、割り算は `divide A by B` です。
