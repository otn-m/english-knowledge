# commit — 頻出フレーズ

| フレーズ・型 | 意味・使い方 |
|---|---|

| commit an error | 誤りを犯す |
| commit a serious act | 重大な行為をする |
| commit adultery | 不貞を働く |
| commit to ... | …に責任を持って取り組む |
| commit to doing ... | …することを約束する |
| commit yourself to ... | …に専心する |

| fully commit to ... | …に全面的に取り組む |
| commit resources | 資源を投入する |
| commit funds | 資金を投入する |
| commit time to ... | …に時間を割く |
| commit money to ... | …に資金を投じる |
| commit troops | 軍隊を投入する |
| refuse to commit | 確約を避ける |
| fail to commit to ... | …への確約をしない |
| commit something to memory | 何かを暗記する |
| commit something to paper | 何かを書き留める |

## 要点

犯罪を犯す、資源を投入する、将来の行動を確約する意味があります。約束は `commit to + 名詞・doing` を使います。
