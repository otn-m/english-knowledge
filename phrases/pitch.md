# pitch — 頻出フレーズ

NGSL順位: 2057

| フレーズ・型 | 意味・使い方 |
|---|---|
| make a pitch | 売り込みをする |
| deliver a pitch | 売り込みの説明をする |
| a sales pitch | セールストーク |
| an elevator pitch | 短時間の売り込み説明 |
| a marketing pitch | マーケティング上の売り込み |
| a business pitch | 事業提案 |
| a pitch to investors | 投資家への提案 |
| pitch an idea | アイデアを売り込む |
| pitch a proposal | 提案を売り込む |
| pitch a product | 商品を売り込む |
| pitch to a client | 顧客に提案する |
| pitch for business | 仕事を獲得しようと売り込む |
| throw a pitch | 投球する |
| make the first pitch | 始球式の球を投げる |
| a fast pitch | 速い投球 |
| a wild pitch | 暴投 |
| pitch a perfect game | 完全試合を達成する |
| a football pitch | サッカー場 |
| take the pitch | ピッチに立つ |
| leave the pitch | ピッチを去る |
| invade the pitch | ピッチに乱入する |
| the pitch of a sound | 音の高さ |
| a high pitch | 高い音程 |
| a low pitch | 低い音程 |
| change pitch | 音程を変える |
| perfect pitch | 絶対音感 |
| pitch a tent | テントを張る |
| pitch camp | 野営する |
| at fever pitch | 興奮が最高潮で |
| pitch-black | 真っ暗な |

## 要点

「投球」「競技場」「音の高さ」「売り込み」など意味が広い語です。動詞の `pitch an idea` と `pitch a tent` も重要です。
