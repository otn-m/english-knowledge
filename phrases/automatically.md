# automatically — 頻出フレーズ

NGSL順位: 2521

| フレーズ・型 | 意味・使い方 |
|---|---|
| automatically update | 自動的に更新する |
| automatically save | 自動保存する |
| automatically install | 自動的にインストールする |
| automatically download | 自動的にダウンロードする |
| automatically upload | 自動的にアップロードする |
| automatically connect | 自動接続する |
| automatically sync | 自動同期する |
| automatically start | 自動的に開始する |
| automatically stop | 自動的に停止する |
| automatically turn on | 自動的に電源が入る |
| automatically turn off | 自動的に電源が切れる |
| automatically open | 自動的に開く |
| automatically close | 自動的に閉じる |
| automatically generate | 自動生成する |
| automatically calculate | 自動計算する |
| automatically detect | 自動検出する |
| automatically select | 自動選択する |
| automatically adjust | 自動調整する |
| automatically renew | 自動更新する |
| automatically delete | 自動削除する |
| automatically apply | 自動適用する |
| automatically log in | 自動ログインする |
| be automatically added | 自動的に追加される |
| be automatically enrolled | 自動的に登録される |
| be automatically eligible | 自動的に資格を得る |
| automatically assume ... | 反射的に～だと思い込む |
| react automatically | 無意識に反応する |
| happen automatically | 自動的に起こる |
| not automatically mean ... | 必ずしも～を意味しない |
| almost automatically | ほとんど無意識に |

## 要点

機械やシステムが「自動的に」動く場合と、人が「無意識に・反射的に」行動する場合に使います。
