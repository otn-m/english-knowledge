# altogether — 頻出フレーズ

NGSL順位: 2678

| フレーズ・型 | 意味・使い方 |
|---|---|
| altogether different | まったく異なる |
| altogether new | まったく新しい |
| altogether separate | 完全に別の |
| altogether impossible | まったく不可能な |
| altogether unnecessary | まったく不要な |
| altogether unacceptable | まったく受け入れられない |
| altogether surprising | まったく驚くべき |
| altogether clear | 完全に明らかな |
| altogether certain | 完全に確かな |
| altogether convincing | 完全に説得力のある |
| not altogether clear | 完全には明らかでない |
| not altogether true | まったく正しいわけではない |
| not altogether surprising | まったく意外というわけではない |
| not altogether happy | 心から満足しているわけではない |
| not altogether successful | 完全に成功したわけではない |
| not altogether convinced | 完全には納得していない |
| avoid something altogether | 何かを完全に避ける |
| stop something altogether | 何かを完全にやめる |
| disappear altogether | 完全に姿を消す |
| eliminate something altogether | 何かを完全に取り除く |
| abandon something altogether | 何かを完全に放棄する |

| leave altogether | 完全に去る |
| taken altogether | 全体として見れば |
| altogether, there were ... | 全部で…あった |
| cost $100 altogether | 全部で100ドルかかる |
| ten people altogether | 全部で10人 |
| an altogether better approach | 全体としてはるかに優れた方法 |
| another matter altogether | まったく別の問題 |
| a different story altogether | まったく別の話 |

## 要点

「完全に・まったく」と「全部で・全体として」を表します。`not altogether ...` は部分否定で「完全に…というわけではない」です。
