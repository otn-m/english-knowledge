# restore — 頻出フレーズ

NGSL順位: 2100

| フレーズ・型 | 意味・使い方 |
|---|---|
| restore order | 秩序を回復する |
| restore peace | 平和を回復する |
| restore stability | 安定を取り戻す |
| restore confidence | 信頼を回復する |
| restore trust | 信頼を取り戻す |
| restore power | 電力を復旧する |
| restore service | サービスを復旧する |
| restore access | 利用可能な状態に戻す |
| restore communications | 通信を復旧する |
| restore relations | 関係を修復する |
| restore democracy | 民主主義を回復する |
| restore freedom | 自由を取り戻す |
| restore balance | 均衡を取り戻す |
| restore health | 健康を回復させる |
| restore sight | 視力を回復させる |
| restore something to its original state | 〜を元の状態に戻す |
| restore a building | 建物を修復する |
| restore a painting | 絵画を修復する |
| fully restore something | 〜を完全に復元する |
| carefully restore something | 〜を慎重に修復する |
| restore a file | ファイルを復元する |
| restore data | データを復元する |
| restore a backup | バックアップから復元する |
| restore factory settings | 工場出荷時設定に戻す |
| restore a system | システムを復元する |
| restore deleted items | 削除した項目を復元する |
| restore someone's reputation | 人の評判を回復する |
| restore someone to power | 人を権力の座に戻す |
| restore something to someone | 〜を人に返還する |
| restore lost confidence | 失われた信頼を回復する |

## 要点

状態・機能を「回復する」、建物・作品・データを「修復・復元する」、地位や所有物を「戻す」を表します。
