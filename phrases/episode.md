# episode — 頻出フレーズ

| フレーズ・型 | 意味・使い方 |
|---|---|
| an episode of a show | 番組の一話 |
| the first episode | 第1話 |
| the final episode | 最終話 |
| the latest episode | 最新話 |
| the next episode | 次回 |
| a new episode | 新しい回 |
| a previous episode | 前回のエピソード |
| a special episode | 特別編 |
| a pilot episode | パイロット版 |
| a bonus episode | 特別追加回 |
| a two-part episode | 前後編の回 |
| watch an episode | 一話を見る |
| miss an episode | 一話を見逃す |
| stream an episode | 一話を配信で見る |
| record an episode | 番組の一回を収録する |
| film an episode | 一話を撮影する |
| air an episode | 一話を放送する |
| release an episode | 一話を公開する |
| an episode airs | 一話が放送される |
| an episode features someone | その回に人が登場する |
| a podcast episode | ポッドキャストの一回 |
| a television episode | テレビ番組の一話 |
| a memorable episode | 忘れがたい出来事 |
| a brief episode | 短い出来事・発作 |

| a violent episode | 暴力的な出来事 |
| a depressive episode | うつ病エピソード |

| an episode of illness | 一時的な病気・発作 |
| an episode in history | 歴史上の一幕 |

## 要点

番組の「一話」が最も身近な用法です。病気の一時的な「発作」や、歴史・人生の「一幕」にも使います。
