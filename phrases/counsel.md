# counsel — 頻出フレーズ

NGSL順位: 2407

| フレーズ・型 | 意味・使い方 |
|---|---|
| seek counsel | 助言を求める |
| take counsel | 相談する |
| give counsel | 助言する |
| offer counsel | 助言を提供する |
| wise counsel | 賢明な助言 |
| legal counsel | 法律顧問・弁護士 |
| independent counsel | 独立した法律顧問 |
| outside counsel | 外部弁護士 |
| in-house counsel | 社内弁護士 |
| defense counsel | 弁護人 |
| counsel for the defense | 被告側弁護士 |
| counsel for the prosecution | 検察側の法律担当者 |
| counsel for the company | 会社側の弁護士 |
| chief legal counsel | 最高法務責任者・主任法律顧問 |
| consult with counsel | 弁護士と相談する |
| retain legal counsel | 弁護士を雇う |
| be represented by counsel | 弁護士に代理される |
| the right to counsel | 弁護人を依頼する権利 |
| counsel someone to do something | 人に～するよう助言する |
| counsel caution | 慎重さを勧める |
| counsel patience | 忍耐を勧める |
| counsel against doing ... | ～しないよう助言する |
| counsel a patient | 患者にカウンセリングを行う |
| counsel young people | 若者に助言する |
| marriage counseling | 結婚カウンセリング |
| grief counseling | 悲嘆カウンセリング |
| career counseling | 進路・職業相談 |
| receive counseling | カウンセリングを受ける |
| a counseling service | 相談サービス |
| a school counselor | スクールカウンセラー |

## 要点

名詞では改まった「助言」または集合的に「弁護士」、動詞では助言・カウンセリングを行うことを表します。
