# attendance — 頻出フレーズ

NGSL順位: 2751

| フレーズ・型 | 意味・使い方 |
|---|---|
| regular attendance | 定期的な出席 |
| good attendance | 良好な出席状況 |
| poor attendance | 出席状況が悪いこと |
| perfect attendance | 無欠席 |
| high attendance | 高い出席率 |
| low attendance | 低い出席率 |
| average attendance | 平均入場者数 |
| daily attendance | 1日の出席・入場者数 |
| school attendance | 学校への出席 |
| class attendance | 授業への出席 |
| student attendance | 生徒の出席 |
| audience attendance | 観客の入場者数 |
| event attendance | イベント参加者数 |
| attendance figures | 出席・入場者数 |
| attendance records | 出席記録 |
| an attendance sheet | 出席表 |
| an attendance policy | 出席方針 |
| an attendance requirement | 出席要件 |
| an attendance rate | 出席率 |
| attendance at a meeting | 会議への出席 |
| attendance at school | 学校への出席 |
| in attendance | 出席して |
| be in attendance | 出席している |
| take attendance | 出欠を取る |
| record attendance | 出席を記録する |
| monitor attendance | 出席状況を監視する |
| improve attendance | 出席率を改善する |
| boost attendance | 参加者数を増やす |
| require attendance | 出席を義務付ける |
| attendance is mandatory | 出席は必須である |

## 要点

「出席」と、イベントなどの「入場者数・参加者数」を表します。`take attendance` は出欠を取り、`in attendance` は出席している状態です。
