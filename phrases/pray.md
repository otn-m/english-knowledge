# pray — 頻出フレーズ

NGSL順位: 2639

| フレーズ・型 | 意味・使い方 |
|---|---|
| pray to God | 神に祈る |
| pray for someone | 人のために祈る |

| pray for rain | 雨を祈る |
| pray for guidance | 導きを祈り求める |

| pray with someone | 人と一緒に祈る |

| pray tell | どうか教えてください、いったい |

## 要点

神に「祈る」、結果を強く「願う」を表します。人や物事のためには `pray for ...`、願う内容には `pray that ...` を使います。
