# fear — 頻出フレーズ

NGSL順位: 793

| フレーズ・型 | 意味・使い方 |
|---|---|
| fear ... | …を恐れる |
| fear death | 死を恐れる |
| fear the worst | 最悪の事態を恐れる |
| fear that ... | …ではないかと恐れる |
| fear for someone's safety | 人の安全を心配する |
| greatly fear ... | …を大いに恐れる |
| a fear of ... | …への恐怖 |
| a fear of failure | 失敗への恐怖 |
| a fear of flying | 飛行への恐怖 |
| a fear of change | 変化への恐怖 |
| a deep fear | 深い恐怖 |
| a real fear | 現実的な恐れ |
| a common fear | よくある恐れ |
| a constant fear | 絶え間ない恐怖 |
| a growing fear | 高まる懸念 |
| public fear | 世間の恐怖 |
| express fear | 恐れを表明する |
| feel fear | 恐怖を感じる |
| experience fear | 恐怖を経験する |
| overcome your fear | 恐怖を克服する |
| face your fears | 自分の恐怖に向き合う |
| control your fear | 恐怖を抑える |
| hide your fear | 恐怖を隠す |
| cause fear | 恐怖を引き起こす |
| spread fear | 恐怖を広める |
| live in fear | 恐怖の中で暮らす |

| for fear of ... | …を恐れて |

| without fear | 恐れずに |
| have no fear | 恐れることはない |

| false fears | 根拠のない恐れ |

## 要点

動詞は `fear .../that ...`、名詞は `a fear of ...` です。目的を避ける理由には `for fear of/that ...` を使います。
