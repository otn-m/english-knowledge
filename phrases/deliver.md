# deliver — 頻出フレーズ

NGSL順位: 1064

| フレーズ・型 | 意味・使い方 |
|---|---|
| deliver a package | 荷物を配達する |
| deliver a letter | 手紙を配達する |
| deliver food | 食事を配達する |
| deliver goods | 商品を配送する |
| deliver something to ... | 物を…へ届ける |
| be delivered by ... | …によって配達される |
| deliver on time | 時間どおりに配達・実行する |
| deliver a speech | 演説を行う |
| deliver a lecture | 講義を行う |
| deliver a presentation | プレゼンを行う |
| deliver a message | メッセージを伝える |
| deliver the news | 知らせを伝える |
| deliver a warning | 警告を伝える |
| deliver a report | 報告を行う |
| deliver results | 成果を出す |
| deliver value | 価値を提供する |
| deliver quality | 品質を提供する |
| deliver a service | サービスを提供する |
| deliver on a promise | 約束を果たす |
| fail to deliver | 成果を出せない |
| consistently deliver ... | …を安定して提供する |
| deliver a blow | 打撃を与える |
| deliver a verdict | 評決を下す |
| deliver a baby | 赤ちゃんを取り上げる |
| deliver a child | 子どもを出産させる |
| safely deliver a baby | 赤ちゃんを安全に取り上げる |
| deliver power to ... | …へ電力を供給する |
| deliver water to ... | …へ水を供給する |
| deliver directly to your door | 自宅へ直接届ける |
| deliver against targets | 目標に沿った成果を出す |
| ready to deliver | 配達・成果提供の準備ができて |
| deliver the final product | 最終製品を納品する |

## 要点

配達のほか、演説・成果・サービスを「届ける」にも使います。約束には `deliver on a promise` が頻出です。
