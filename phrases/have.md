# have — 頻出フレーズ

NGSL順位: 8

所有の意味だけでなく、義務、経験、飲食、会話での定型表現など、`have` が実際によく使われるまとまりを選んだ。`has / had / having` に変化するものも含む。

| フレーズ・型 | 意味・使い方 |
|---|---|
| have to do                      | ～しなければならない         |
| have got to do                  | ～しなければならない（主に口語）   |
| have got                        | 持っている（主にイギリス英語・口語） |
| have been to                    | ～へ行ったことがある         |
| have yet to do                  | まだ～していない           |
| have a look                     | 見てみる               |
| have a look at                  | ～を見てみる             |
| have a good time                | 楽しい時間を過ごす          |
| have fun                        | 楽しむ                |
| have breakfast / lunch / dinner | 朝食／昼食／夕食をとる        |
| have a drink                    | 飲み物・酒を飲む           |
| have a rest                     | 休憩する               |
| have a break                    | 休憩をとる              |
| have a shower / bath            | シャワーを浴びる／風呂に入る     |
| have a seat                     | 座る                 |
| have a chat                     | おしゃべりする            |
| have a talk                     | 話し合う               |
| have a word with someone        | （人）と少し話す           |
| have a meeting                  | 会議をする              |
| have an appointment             | 予約・約束がある           |
| have a problem with             | ～に問題がある            |
| have difficulty doing           | ～するのが難しい           |
| have trouble doing              | ～するのに苦労する          |
| have no idea                    | まったく分からない          |
| have a chance to do             | ～する機会がある           |
| have an opportunity to do       | ～する機会がある（やや改まった表現） |
| have a feeling that ...         | ～という気がする           |
| have a point                    | 一理ある               |
| have an effect on               | ～に影響を与える           |
| have access to                  | ～を利用・閲覧できる         |
| have experience with            | ～の経験がある            |
| have something in common        | 共通点がある             |
| have nothing to do with         | ～とは無関係である          |
| have ... in mind                | ～を考えている            |
| have second thoughts            | 考え直す／迷いが生じる        |
| have had enough                 | もううんざりだ／もう十分だ      |
| have a lot on one's plate       | やるべきことを多く抱えている     |
| have one's hands full           | 手いっぱいである           |
| have a say in                   | ～について発言権がある        |
| have a go                       | やってみる（主にイギリス英語）    |
| have a good day                 | 良い一日を              |

## 要点

- `have to` の否定 `do not have to` は「～する必要はない」。「～してはいけない」の `must not` とは異なる。
- 食事・休憩・会話などでは `do` や `take` ではなく `have` を使う組み合わせが多い。
- 経験の `have been to` は「行って戻ってきた」。現在そこへ行っている場合は `have gone to`。
