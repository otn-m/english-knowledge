# will — 頻出フレーズ

NGSL順位: 28

| フレーズ・型 | 意味・使い方 |
|---|---|
| will be | ～になる／～であるだろう |
| will do | ～するつもりだ／それでよい |
| will have | ～を持つことになる |
| will need to do | ～する必要が生じる |
| will have to do | ～しなければならなくなる |
| will be able to do | ～できるようになる |
| will probably | おそらく～だろう |
| will definitely | 間違いなく～だろう |
| will soon | まもなく～する |
| will never | 決して～しないだろう |
| will always | いつでも～する／ずっと～だろう |
| I will | 私がします |
| I will be there. | そこへ行きます |
| I will let you know. | 分かったら知らせます |
| I will get back to you. | 後で返事します |
| I will do my best. | 最善を尽くします |
| I will see what I can do. | できることを考えます |
| I will keep that in mind. | 覚えておきます |
| I will take care of it. | 私が対応します |
| I will think about it. | 考えておきます |
| Will do. | 了解です／そうします |
| Will you ...? | ～してくれますか |

| How long will it take? | どのくらいかかりますか |
| When will ...? | いつ～しますか |
| What will happen? | 何が起こりますか |
| That will be fine. | それで大丈夫です |
| That will work. | それでうまくいきます |
| It will depend on ... | ～次第です |
| Time will tell. | 時がたてば分かる |
| Where there is a will, there is a way. | 意志あるところに道は開ける |

## 要点

`will` は単なる未来だけでなく、その場の決定、意志、申し出、予測にも使う。
