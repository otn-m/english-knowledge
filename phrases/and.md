# and — 頻出フレーズ

NGSL順位: 3

`and` は語をつなぐだけでなく、会話の定型表現、反復、対になる概念に頻出する。日常会話と一般的な文章で特によく現れるまとまりを選んだ。

| フレーズ・型 | 意味・使い方 |
|---|---|
| A and B | AとB |
| both A and B | AとBの両方 |
| between A and B | AとBの間 |
| A and B alike | AもBも同様に |
| and so on | ～など |
| and so forth | ～など（`and so on` よりやや硬い） |
| and then | それから／その場合 |
| and yet | それにもかかわらず |
| more and more | ますます／ますます多くの |
| better and better | ますます良く |
| again and again | 何度も |
| over and over again | 何度も繰り返して |
| now and then | ときどき |
| here and there | あちこちに |
| back and forth | 行ったり来たり／やり取りして |
| up and down | 上下に／行ったり来たり |
| on and off | 断続的に／ついたり消えたり |
| pros and cons | 賛否／長所と短所 |
| trial and error | 試行錯誤 |
| cause and effect | 原因と結果 |
| supply and demand | 需要と供給 |
| health and safety | 安全衛生 |
| research and development | 研究開発 |
| law and order | 法と秩序／治安 |
| peace and quiet | 静けさと平穏 |
| black and white | 白黒の／善悪が明確な |
| safe and sound | 無事に |
| alive and well | 健在で／今なお盛んで |
| all well and good | それはそれで結構だが |
| by and large | 概して |
| first and foremost | 何よりもまず |
| wait and see | 成り行きを見る |
| come and see | 見に来る |
| go and get | 取りに行く |
| try and do | ～しようとする（口語。標準的な `try to do` も重要） |

## 要点

- `Come and see` や `go and get` の `and` は、実質的に目的を表し、会話で非常によく使われる。
- `more and more + 形容詞` と `more and more + 複数名詞` の両方が可能。
- 対になる語は語順がほぼ固定される。通常 `cons and pros` や `effect and cause` とは言わない。
