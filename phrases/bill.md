# bill — 頻出フレーズ

NGSL順位: 888

| フレーズ・型 | 意味・使い方 |
|---|---|
| pay a bill | 請求書を支払う |
| get a bill | 請求書を受け取る |
| receive a bill | 請求書を受け取る |
| send a bill | 請求書を送る |
| settle a bill | 勘定を精算する |
| split the bill | 割り勘にする |
| foot the bill | 費用を負担する |
| pick up the bill | 勘定を支払う |
| an unpaid bill | 未払いの請求書 |
| a large bill | 高額な請求書 |
| a monthly bill | 毎月の請求書 |
| an electricity bill | 電気料金の請求書 |
| a gas bill | ガス料金の請求書 |
| a phone bill | 電話料金の請求書 |
| a medical bill | 医療費の請求書 |
| a restaurant bill | 飲食店の勘定 |
| the total bill | 請求総額 |
| a ten-dollar bill | 10ドル紙幣 |
| a dollar bill | 1ドル紙幣 |
| a counterfeit bill | 偽札 |
| introduce a bill | 法案を提出する |
| pass a bill | 法案を可決する |
| approve a bill | 法案を承認する |
| reject a bill | 法案を否決する |
| sign a bill into law | 法案に署名して法律にする |
| a spending bill | 歳出法案 |
| a tax bill | 税法案／税金の請求 |
| a reform bill | 改革法案 |
| the bill becomes law | 法案が法律になる |
| fit the bill | 条件・目的にぴったり合う |
| top the bill | 興行で主役を務める |
| bill someone for ... | 人に…の代金を請求する |

## 要点

請求書には `pay/split/settle the bill`、法案には `introduce/pass/sign a bill` を使います。`fit the bill` は「条件にぴったり合う」です。
