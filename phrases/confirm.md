# confirm — 頻出フレーズ

NGSL順位: 1206

| フレーズ・型 | 意味・使い方 |
|---|---|
| confirm that ... | …であることを確認する |
| please confirm ... | …をご確認ください |
| can confirm that ... | …であると確認できる |
| confirm receipt of ... | …の受領を確認する |
| confirm a booking | 予約を確認する |
| confirm a reservation | 予約を確定・確認する |
| confirm an order | 注文を確認する |
| confirm an appointment | 約束・予約を確認する |
| confirm the date | 日付を確認する |
| confirm the time | 時刻を確認する |
| confirm your attendance | 出席を確認する |
| confirm your identity | 本人確認をする |
| confirm the details | 詳細を確認する |
| confirm the information | 情報を確認する |
| confirm the result | 結果を確認する |
| confirm a finding | 調査結果を裏づける |
| confirm a report | 報道・報告を確認する |
| confirm a suspicion | 疑いが正しいと確認する |
| confirm someone's fears | 人の懸念が現実だと確認する |
| confirm a death | 死亡を確認する |
| confirm whether ... | …かどうか確認する |
| confirm with someone | 人に確認を取る |
| confirm in writing | 書面で確認する |
| confirm by email | メールで確認する |
| be confirmed by ... | …によって確認される |
| be confirmed as ... | …であると確認される |
| evidence confirms ... | 証拠が…を裏づける |
| a test confirms ... | 検査で…が確認される |
| refuse to confirm ... | …の確認を拒む |
| be unable to confirm ... | …を確認できない |
| confirm availability | 空き・利用可能性を確認する |

## 要点

情報が正しいと確かめることと、予約などを確定することを表します。節を続ける `confirm that/whether ...` と実務の `confirm receipt/booking` が重要です。
