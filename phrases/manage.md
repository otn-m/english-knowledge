# manage — 頻出フレーズ

NGSL順位: 625

| フレーズ・型 | 意味・使い方 |
|---|---|
| manage ... | …を管理する |
| manage a business | 事業を経営する |
| manage a company | 会社を経営する |
| manage a team | チームを管理する |
| manage a project | プロジェクトを管理する |
| manage staff | 職員を管理する |
| manage people | 人を管理する |
| manage money | お金を管理する |
| manage your time | 時間を管理する |
| manage resources | 資源を管理する |
| manage risk | リスクを管理する |
| manage change | 変化を管理する |
| manage stress | ストレスをうまく処理する |
| manage symptoms | 症状を管理する |
| manage data | データを管理する |
| manage the situation | 状況に対処する |
| manage the process | プロセスを管理する |
| effectively manage ... | …を効果的に管理する |
| carefully manage ... | …を慎重に管理する |
| be difficult to manage | 管理・対処が難しい |
| manage to do ... | 何とか…する |
| manage to finish | 何とか終える |
| manage to get ... | 何とか…を手に入れる |
| manage to find ... | 何とか…を見つける |
| manage to avoid ... | 何とか…を避ける |
| somehow manage to ... | どうにか…する |
| barely manage to ... | かろうじて…する |
| fail to manage ... | …をうまく管理できない |
| can manage | 何とかできる |
| manage without ... | …なしで何とかやる |
| manage on ... | …の収入・量で何とか暮らす |
| how did you manage? | どうやってやり遂げたの |
| I can manage on my own | 一人で何とかできます |
| be well managed | 適切に管理されている |
| poorly managed | 管理が不十分な |

## 要点

`manage ...` は「管理する」、`manage to do ...` は「何とか…する」です。後者に動名詞は使いません。
