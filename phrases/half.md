NGSL順位: 365

| フレーズ・型 | 意味・使い方 |
|---|---|
| half of ... | …の半分 |
| half of us | 私たちの半数 |
| half of them | それら・彼らの半分 |
| half the time | 半分の時間・しばしば |
| half the price | 半額 |
| half the size | 半分の大きさ |
| half an hour | 30分 |
| half a day | 半日 |
| half a mile | 0.5マイル |
| half a million | 50万 |
| one and a half | 1.5 |
| two and a half hours | 2時間半 |
| in half | 半分に |
| cut ... in half | …を半分に切る |
| divide ... in half | …を半分に分ける |
| break ... in half | …を半分に折る・割る |
| by half | 半分だけ・大幅に |
| reduce ... by half | …を半減させる |
| more than half | 半分を超える |
| less than half | 半分未満 |
| nearly half | ほぼ半分 |
| about half | 約半分 |
| the first half | 前半 |
| the second half | 後半 |
| the other half | 残りの半分 |
| half full | 半分入っている |
| half empty | 半分空である |
| half asleep | 半分眠った状態で |
| not half bad | なかなかよい |
| do something by halves | 中途半端に行う |

## 要点

`half of the ...` と `half the ...` はどちらも使えます。時間では `half an hour`、分割では `cut/divide ... in half` が基本です。
