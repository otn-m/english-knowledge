# isolate — 頻出フレーズ

NGSL順位: 2080

| フレーズ・型 | 意味・使い方 |
|---|---|
| isolate a patient | 患者を隔離する |
| isolate an infected person | 感染者を隔離する |
| isolate yourself | 自主隔離する、孤立する |
| isolate yourself from others | 他人から自分を隔てる |
| be isolated from society | 社会から孤立している |
| become socially isolated | 社会的に孤立する |
| feel isolated | 孤立していると感じる |
| geographically isolated | 地理的に孤立した |
| politically isolated | 政治的に孤立した |
| socially isolated | 社会的に孤立した |
| culturally isolated | 文化的に孤立した |
| completely isolated | 完全に孤立した |
| relatively isolated | 比較的孤立した |
| isolate a problem | 問題を切り分ける |
| isolate the cause | 原因を特定する |
| isolate a factor | 要因を分離する |
| isolate a variable | 変数を分離する |
| isolate the effects | 影響を切り分ける |
| isolate a gene | 遺伝子を分離する |
| isolate a virus | ウイルスを分離する |
| isolate a chemical compound | 化合物を分離する |
| isolate a sound | 音を分離する |
| isolate a signal | 信号を分離する |
| isolate a building | 建物を隔離する |
| isolate a country | 国を孤立させる |
| seek to isolate someone | 人を孤立させようとする |
| isolate something from heat | 〜を熱から遮断する |
| isolate something from vibration | 〜を振動から切り離す |
| an isolated incident | 単発の事件 |
| an isolated community | 孤立した共同体 |

## 要点

人や場所を「隔離・孤立させる」と、原因・物質・信号などを「切り分ける・分離する」を表します。
