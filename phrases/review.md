# review — 頻出フレーズ

NGSL順位: 730

| フレーズ・型 | 意味・使い方 |
|---|---|
| review ... | …を見直す、検討する |
| review a document | 文書を確認する |
| review a report | 報告書を検討する |
| review a case | 事例・事件を再検討する |
| review a decision | 決定を再検討する |
| review a policy | 方針を見直す |
| review a contract | 契約を確認する |
| review the evidence | 証拠を再検討する |
| review your work | 自分の作業を見直す |
| review your notes | ノートを復習する |
| regularly review ... | …を定期的に見直す |
| carefully review ... | …を慎重に検討する |
| be reviewed by ... | …によって審査される |
| a full review | 全面的な見直し |
| a detailed review | 詳細な検討 |
| a careful review | 慎重な検討 |
| a regular review | 定期的な見直し |
| an annual review | 年次評価・見直し |
| an independent review | 独立した審査 |
| a judicial review | 司法審査 |
| a performance review | 人事評価 |
| a policy review | 政策見直し |
| a literature review | 文献レビュー |
| a book review | 書評 |
| a film review | 映画評 |
| a product review | 製品レビュー |
| a positive review | 好意的な評価 |
| a negative review | 否定的な評価 |
| write a review | レビューを書く |
| read a review | レビューを読む |
| conduct a review | 見直し・審査を行う |
| carry out a review | 見直しを実施する |
| under review | 検討中で |
| subject to review | 見直しの対象となる |
| a review of ... | …の見直し・論評 |

## 要点

動詞では文書・方針を `review`、名詞では `conduct a review`、評価記事は `book/film/product review` です。
