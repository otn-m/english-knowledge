| フレーズ・型 | 意味・使い方 |
|---|---|
| relate to ... | …に関係する |
| be related to ... | …と関係している |
| relate ... to ... | …を…と関連づける |
| relate directly to ... | …に直接関係する |
| relate closely to ... | …に密接に関係する |
| relate strongly to ... | …に強く関係する |
| relate specifically to ... | 特に…に関係する |
| relate mainly to ... | 主に…に関係する |
| relate back to ... | …にさかのぼって関係する |
| relate well to someone | 人とうまく関わる |
| relate to people | 人々に共感・親近感を持つ |
| relate to someone's experience | 人の経験に共感する |
| relate to a character | 登場人物に共感する |
| can relate to ... | …に共感できる |
| be easy to relate to | 共感しやすい |

| relate an experience | 経験を語る |
| relate what happened | 起きたことを語る |

| relate the facts | 事実を述べる |

## 要点

関係には `relate to ...`、二つを関連づけるには `relate A to B`、共感には `can relate to ...` を使います。
