# explain — 頻出フレーズ

NGSL順位: 489

| フレーズ・型 | 意味・使い方 |
|---|---|
| explain a problem | 問題を説明する |
| explain a situation | 状況を説明する |
| explain a process | 過程を説明する |
| explain a concept | 概念を説明する |
| explain the difference | 違いを説明する |
| explain the meaning | 意味を説明する |
| explain the reason | 理由を説明する |
| explain the rules | 規則を説明する |
| explain in detail | 詳しく説明する |
| explain clearly | 明確に説明する |
| explain briefly | 手短に説明する |
| fully explain | 十分に説明する |
| help explain ... | ～の説明に役立つ |
| try to explain | 説明しようとする |
| be difficult to explain | 説明しにくい |
| explain something to someone | ～を人に説明する |
| explain to someone that ... | 人に～だと説明する |
| explain how ... | どのように～か説明する |
| explain why ... | なぜ～か説明する |
| explain what ... | 何が～か説明する |
| explain that ... | ～だと説明する |
| explain oneself | 自分の言動を釈明する |
| explain away ... | ～をうまく説明して片づける |
| explain the role of ... | ～の役割を説明する |
| explain the effect of ... | ～の影響を説明する |
| explain the purpose of ... | ～の目的を説明する |
| explain one's decision | 自分の決定を説明する |
| explain one's actions | 自分の行動を説明する |
| explain the results | 結果を説明する |
| explain the findings | 調査結果を説明する |
| this may explain why ... | これでなぜ～か説明できるかもしれない |
| that explains it | それで分かりました |
| let me explain | 説明させてください |
| can you explain ...? | ～を説明してもらえますか |
| there's no explaining ... | ～は説明のしようがない |

## 要点

対象は直接目的語、人には `to` を使い、`explain something to someone` とする。`explain me` とは言わない。
