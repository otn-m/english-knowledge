# prepare — 頻出フレーズ

NGSL順位: 604

| フレーズ・型 | 意味・使い方 |
|---|---|
| prepare for ... | …に備える |
| prepare for an exam | 試験に備える |
| prepare for a meeting | 会議の準備をする |
| prepare for the future | 将来に備える |
| prepare for the worst | 最悪の事態に備える |
| prepare to do ... | …する準備をする |
| prepare to leave | 出発する準備をする |
| prepare to meet ... | …に会う準備をする |
| be prepared to do ... | …する覚悟・用意がある |
| be prepared for ... | …に備えている |
| well prepared | 十分に準備できている |
| fully prepared | 完全に準備できている |
| poorly prepared | 準備不足の |
| prepare yourself | 心構えをする |
| prepare yourself for ... | …に向けて心構えをする |
| prepare a meal | 食事を用意する |
| prepare food | 食べ物を用意する |
| prepare dinner | 夕食を用意する |
| prepare a report | 報告書を作成する |
| prepare a document | 文書を作成する |
| prepare a statement | 声明を用意する |
| prepare a presentation | プレゼンを準備する |
| prepare a lesson | 授業を準備する |
| prepare a plan | 計画を作成する |
| prepare a budget | 予算を作成する |
| prepare the ground for ... | …の下地を整える |
| prepare in advance | 前もって準備する |
| prepare carefully | 入念に準備する |
| help prepare ... | …の準備を手伝う |
| take time to prepare | 時間をかけて準備する |
| prepare ... in advance | …を前もって用意する |
| prepare ... for use | …を使用できるよう準備する |
| freshly prepared | 作りたての |
| prepare a patient for surgery | 患者に手術の準備をさせる |
| prepare the way for ... | …への道を開く |

## 要点

名詞には `prepare for ...`、動作には `prepare to do ...` を使います。`be prepared to do ...` は「覚悟がある」の意味にもなります。
