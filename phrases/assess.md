# assess — 頻出フレーズ

NGSL順位: 1499

| フレーズ・型 | 意味・使い方 |
|---|---|
| assess the situation | 状況を評価する |
| assess the risk | リスクを評価する |
| assess the impact | 影響を評価する |
| assess the damage | 被害を評価する |
| assess the effect | 効果・影響を評価する |
| assess the need for ... | ～の必要性を評価する |
| assess the value of ... | ～の価値を評価する |
| assess the quality | 品質を評価する |
| assess performance | 業績・能力を評価する |
| assess progress | 進捗を評価する |
| assess the evidence | 証拠を評価する |
| assess the results | 結果を評価する |
| assess the costs | 費用を見積もる |
| assess someone's ability | 人の能力を評価する |
| assess someone's condition | 人の状態を診断・評価する |
| assess a patient | 患者を診察・評価する |
| assess a candidate | 候補者を評価する |
| accurately assess ... | ～を正確に評価する |
| carefully assess ... | ～を慎重に評価する |
| fully assess ... | ～を十分に評価する |
| independently assess ... | ～を独立して評価する |
| objectively assess ... | ～を客観的に評価する |
| difficult to assess | 評価するのが難しい |
| impossible to assess | 評価不能である |
| be assessed by ... | ～によって評価される |
| assess whether ... | ～かどうかを評価する |
| assess how ... | どの程度・どのように～かを評価する |
| assess what ... | 何が～かを評価する |
| assess against criteria | 基準に照らして評価する |
| assess at ... | ～の価格・水準と査定する |
| assess the likelihood of ... | ～の可能性を評価する |

## 要点

`assess` は情報を調べて価値・危険・状態を判断する改まった語。`assess the situation/risk/impact` が最も再利用しやすい。
