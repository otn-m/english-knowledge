# otherwise — 頻出フレーズ

NGSL順位: 1056

| フレーズ・型 | 意味・使い方 |
|---|---|
| unless otherwise stated | 別段の記載がない限り |
| unless otherwise noted | 特に注記がない限り |
| unless otherwise specified | 特に指定がない限り |
| unless otherwise agreed | 別途合意しない限り |
| unless otherwise indicated | 別に示されない限り |
| unless otherwise required | 別途必要とされない限り |
| until otherwise notified | 別途通知があるまで |
| think otherwise | そうではないと考える |
| believe otherwise | そうではないと信じる |
| prove otherwise | そうでないことを証明する |
| suggest otherwise | そうでないことを示唆する |
| indicate otherwise | そうでないことを示す |
| say otherwise | そうではないと言う |

| convince someone otherwise | 人にそうではないと納得させる |

| and otherwise | そのほかの面でも |

| not otherwise specified | 特に指定のない |

## 要点

`otherwise` は「そうでなければ」「それ以外は」「別の方法で」を表します。契約文の `unless otherwise ...` が特に頻出します。
