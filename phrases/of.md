# of — 頻出フレーズ

NGSL順位: 4

数量、部分、所属、原因などを表す最重要のまとまりを中心に選んだ。`of` は弱く発音されることが多いため、個々の単語ではなくチャンクで覚えるのが効果的。

| フレーズ・型 | 意味・使い方 |
|---|---|
| a lot of | たくさんの |
| lots of | たくさんの（やや口語的） |
| plenty of | 十分な／たくさんの |
| a bit of | 少しの |
| a couple of | 2つの／2、3の |
| a number of | いくつもの（複数扱い） |
| the number of | ～の数（単数扱い） |
| an amount of | ある量の |
| one of | ～のうちの1つ・1人 |
| some of | ～の一部 |
| most of | ～の大部分 |
| all of | ～のすべて |
| both of | ～の両方 |
| none of | ～のどれも…ない |
| part of | ～の一部 |
| the rest of | ～の残り |
| kind of | 一種の／ちょっと（ぼかし表現） |
| sort of | 一種の／ちょっと（ぼかし表現） |
| of course | もちろん |

## 要点

- `a number of + 複数名詞 + 複数動詞`、`the number of + 複数名詞 + 単数動詞`。
- `most people` のような一般論では `of` を使わず、`most of the people` のように範囲を限定するときに使う。
- `because of` の後ろは名詞相当の表現。文を続ける場合は通常 `because` を使う。
