# except — 頻出フレーズ

NGSL順位: 841

| フレーズ・型 | 意味・使い方 |
|---|---|
| everyone except ... | …を除く全員 |
| everything except ... | …以外のすべて |
| anywhere except ... | …以外ならどこでも |
| nothing except ... | …以外は何もない |
| no one except ... | …以外は誰もいない |
| all except ... | …を除くすべて |
| everyone except one person | 1人を除く全員 |
| except for ... | …を除けば／…以外は |
| except on Sundays | 日曜日を除いて |

## 要点

単純な除外には `except ...`、文全体への補足的な例外には `except for ...` がよく使われます。`except that ...` は節を続けます。
