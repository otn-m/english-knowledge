# examine — 頻出フレーズ

NGSL順位: 1104

| フレーズ・型 | 意味・使い方 |
|---|---|
| examine a patient | 患者を診察する |
| examine a wound | 傷を調べる |
| examine the evidence | 証拠を検討する |
| examine the facts | 事実を検討する |
| examine the data | データを調べる |
| examine the results | 結果を検討する |
| examine the issue | 問題を検討する |
| examine the problem | 問題を詳しく調べる |
| examine the relationship | 関係を検討する |
| examine the effects of ... | …の影響を調べる |
| examine the possibility | 可能性を検討する |
| examine a document | 文書を調べる |
| examine a sample | 試料を調べる |
| examine an object | 物体を調べる |
| examine the scene | 現場を調査する |
| carefully examine ... | …を注意深く調べる |
| closely examine ... | …を綿密に調べる |
| thoroughly examine ... | …を徹底的に調べる |
| critically examine ... | …を批判的に検討する |
| systematically examine ... | …を体系的に調べる |
| visually examine ... | …を目視で検査する |
| be examined by a doctor | 医師の診察を受ける |
| examine under a microscope | 顕微鏡で調べる |

| examine why ... | なぜ…かを検討する |
| examine whether ... | …かどうかを検討する |
| examine the role of ... | …の役割を検討する |
| examine the case for ... | …を支持する論拠を検討する |
| examine both sides | 両面を検討する |

## 要点

`examine` は患者を診察する、物を検査する、問題や証拠を詳しく検討する場合に使います。
