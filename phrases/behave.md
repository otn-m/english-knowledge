# behave — 頻出フレーズ

| フレーズ・型 | 意味・使い方 |
|---|---|
| behave well | 行儀よく振る舞う |
| behave badly | 行儀悪く振る舞う |
| behave properly | 適切に振る舞う |
| behave appropriately | ふさわしく振る舞う |
| behave responsibly | 責任を持って行動する |
| behave professionally | プロらしく振る舞う |
| behave normally | 普通に振る舞う |
| behave differently | 異なる振る舞いをする |
