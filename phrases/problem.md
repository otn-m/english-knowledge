# problem — 頻出フレーズ

| フレーズ・型 | 意味・使い方 |
|---|---|
| a big problem | 大きな問題 |
| a serious problem | 深刻な問題 |
| a major problem | 主要な問題 |
| a common problem | よくある問題 |
| a difficult problem | 難しい問題 |
| a small problem | 小さな問題 |
| the main problem | 主な問題 |
| the real problem | 本当の問題 |
| the only problem | 唯一の問題 |
| a potential problem | 潜在的な問題 |
| a technical problem | 技術的な問題 |
| a health problem | 健康上の問題 |
| a social problem | 社会問題 |
| a global problem | 世界的問題 |
| cause a problem | 問題を引き起こす |
| create a problem | 問題を生む |

| identify a problem | 問題を特定する |

| a solution to a problem | 問題の解決策 |

| no problem | 問題ありません |
| What's the problem? | 何が問題ですか |
| That's the problem. | そこが問題です |

| The problem is that ... | 問題は～ということです |
| not my problem | 私の問題ではない |

## 要点

「問題の解決策」は `solution to a problem`。`solution of` ではなく `to` が基本。
