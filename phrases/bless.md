# bless — 頻出フレーズ

NGSL順位: 2601

| フレーズ・型 | 意味・使い方 |
|---|---|
| God bless you. | 神のご加護がありますように、くしゃみへの返答 |
| Bless you! | お大事に、ありがとう |
| God bless America. | アメリカに神のご加護を |
| God bless us all. | 私たち皆に神のご加護を |
| May God bless you. | 神のご加護がありますように |
| bless the Lord | 主をたたえる |
| bless this house | この家に恵みを授ける |
| bless this food | この食事に感謝し祝福する |
| bless a marriage | 結婚を祝福する |
| bless the couple | 夫婦を祝福する |
| be blessed with ... | …に恵まれている |
| be blessed with good health | 健康に恵まれている |
| be blessed with children | 子どもに恵まれている |
| be blessed with talent | 才能に恵まれている |
| be blessed with beauty | 美しさに恵まれている |
| feel blessed | 恵まれていると感じる |
| truly blessed | 本当に恵まれて |
| incredibly blessed | 信じられないほど恵まれて |
| count your blessings | 自分の恵まれている点に感謝する |
| a blessing in disguise | 災いに見えて実は幸運なこと |
| give your blessing | 賛成・祝福を与える |
| ask for someone's blessing | 人の承認・祝福を求める |
| have someone's blessing | 人の承認を得ている |
| with someone's blessing | 人の承認を得て |
| a mixed blessing | 良い面と悪い面があるもの |
| a real blessing | 本当にありがたいもの |
| What a blessing! | なんとありがたいことだろう |
| bless his heart | 彼は本当に気の毒・けなげだ |
| bless her heart | 彼女は本当に気の毒・けなげだ |
| bless my soul | これは驚いた |

## 要点

「祝福する・恵みを授ける」が中心です。`Bless you!` はくしゃみへの定型応答で、`be blessed with ...` は「…に恵まれている」を表します。
