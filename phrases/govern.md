| フレーズ・型 | 意味・使い方 |
|---|---|

| govern a state | 州・国家を統治する |
| govern a province | 州・省を統治する |

| govern effectively | 効果的に統治する |
| govern democratically | 民主的に統治する |
| be governed by law | 法によって統治される |
| be governed by a council | 評議会によって運営される |
| govern yourself | 自分を律する |

| rules governing ... | ～を規定する規則 |

## 要点

国や組織を「統治・運営する」と、規則や原則が行動・制度を「規定する」を表します。受動形 `be governed by` が頻出します。
