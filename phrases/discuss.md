# discuss — 頻出フレーズ

NGSL順位: 605

| フレーズ・型 | 意味・使い方 |
|---|---|
| discuss ... | …について話し合う |
| discuss the issue | 問題を話し合う |
| discuss the problem | 問題を検討する |
| discuss the matter | その件を話し合う |
| discuss the situation | 状況について話し合う |
| discuss the details | 詳細を話し合う |
| discuss the results | 結果を検討する |
| discuss the findings | 調査結果を検討する |
| discuss the future | 将来について話し合う |
| discuss plans | 計画を話し合う |
| discuss options | 選択肢を話し合う |
| discuss ways to do ... | …する方法を話し合う |
| discuss whether ... | …かどうか話し合う |
| discuss how to do ... | …する方法を話し合う |
| discuss what to do | 何をすべきか話し合う |
| discuss ... with someone | …について人と話し合う |
| discuss ... in detail | …を詳しく話し合う |
| discuss ... further | …をさらに話し合う |
| openly discuss ... | …を率直に話し合う |
| briefly discuss ... | …を簡単に論じる |
| widely discussed | 広く議論されている |
| be discussed at a meeting | 会議で話し合われる |
| be discussed below | 以下で論じられる |
| as discussed above | 上で論じたように |
| refuse to discuss ... | …について話すことを拒む |
| agree to discuss ... | …を話し合うことに同意する |
| meet to discuss ... | …を話し合うために会う |
| a chance to discuss ... | …を話し合う機会 |
| issues discussed | 議論された問題 |
| topics to discuss | 話し合う話題 |
| discuss a book | 本について論じる |
| discuss a case | 事例を検討する |
| discuss possible solutions | 可能な解決策を話し合う |
| discuss the need for ... | …の必要性を論じる |
| discuss the role of ... | …の役割を論じる |

## 要点

`discuss` は他動詞なので、`discuss about ...` ではなく `discuss ...` とします。相手は `with someone` で示します。
