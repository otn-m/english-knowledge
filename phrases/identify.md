# identify — 頻出フレーズ

NGSL順位: 805

| フレーズ・型 | 意味・使い方 |
|---|---|
| identify someone | 人の身元を確認する |
| identify a person | 人物を特定する |
| identify a suspect | 容疑者を特定する |
| identify a victim | 被害者の身元を確認する |
| identify a body | 遺体の身元を確認する |
| identify a problem | 問題を特定する |
| identify a cause | 原因を特定する |
| identify a need | ニーズを特定する |
| identify a risk | リスクを特定する |
| identify a factor | 要因を特定する |
| identify a pattern | パターンを特定する |
| identify a trend | 傾向を特定する |
| identify an opportunity | 機会を見いだす |
| identify a solution | 解決策を見いだす |
| identify the source | 情報源・発生源を特定する |
| identify the difference | 違いを特定する |
| correctly identify ... | …を正しく特定する |
| clearly identify ... | …を明確に特定する |
| accurately identify ... | …を正確に特定する |
| quickly identify ... | …を素早く特定する |
| be difficult to identify | 特定が難しい |
| be easy to identify | 特定しやすい |
| be identified by ... | …によって特定される |
| identify ... as ... | …を…と特定・認定する |
| be identified as ... | …と特定される |
| identify with someone | 人に共感する |
| identify with a character | 登場人物に共感する |
| identify yourself | 身元を明かす |
| identify yourself as ... | 自分を…と名乗る |
| identify closely with ... | …に強く共感・一体化する |
| identify key areas | 重要分野を特定する |
| identify ways to do ... | …する方法を見いだす |
| identify and address ... | …を特定して対処する |
| fail to identify ... | …を特定できない |
| help identify ... | …の特定を助ける |

## 要点

対象の特定には `identify .../as ...`、共感には `identify with ...`、自己紹介・身元確認には `identify yourself` を使います。
