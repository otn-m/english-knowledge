# count — 頻出フレーズ

NGSL順位: 1022

| フレーズ・型 | 意味・使い方 |
|---|---|
| count from one to ten | 1から10まで数える |
| count the number of ... | …の数を数える |
| count how many ... | …がいくつあるか数える |
| count your money | お金を数える |
| count the votes | 票を数える |
| count the days | 日数を数える／心待ちにする |
| count on someone | 人を頼りにする |
| count on something | 物事を当てにする |
| count on someone to do ... | 人が…すると頼りにする |
| you can count on me | 私を頼りにしてよい |
| do not count on it | それを当てにしないで |
| count as ... | …と見なされる |
| count toward ... | …に算入される |
| every vote counts | 一票一票が重要である |
| every second counts | 一秒一秒が重要である |
| make something count | 物事を有意義なものにする |
| count for nothing | 何の価値もない |
| count for a lot | 大いに重要である |
| count against someone | 人に不利に働く |
| count someone in | 人を仲間・人数に入れる |
| count someone out | 人を除外する |
| count down | 秒読みする |
| count up | 合計する |
| lose count | 数が分からなくなる |
| keep count | 数を記録し続ける |
| take a count | 数を数える |
| a head count | 人数確認 |
| a blood cell count | 血球数 |
| on all counts | あらゆる点で |
| on the count of three | 3つ数えたら |
| at the last count | 最後に数えた時点で |
| too many to count | 数え切れないほど多い |

## 要点

数えるほか、`count on ...` で「頼る」、`count as ...` で「…と見なす」、`every ... counts` で重要性を表します。
