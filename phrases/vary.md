# vary — 頻出フレーズ

NGSL順位: 1359

| フレーズ・型 | 意味・使い方 |
|---|---|
| vary from ... to ... | ～から…までさまざまである |
| vary between ... and ... | ～と…の間で変動する |
| vary according to ... | ～に応じて異なる |
| vary depending on ... | ～によって異なる |
| vary by ... | ～によって異なる／～の幅で変わる |
| vary with ... | ～に伴って変化する |
| vary in size | 大きさがさまざまである |
| vary in length | 長さがさまざまである |
| vary in quality | 品質にばらつきがある |
| vary in price | 価格が異なる |
| vary in color | 色がさまざまである |
| vary in degree | 程度が異なる |
| vary in intensity | 強度が異なる |
| vary considerably | かなり異なる |
| vary greatly | 大きく異なる |
| vary widely | 幅広く異なる |
| vary significantly | 大幅に異なる |
| vary slightly | わずかに異なる |
| vary somewhat | 多少異なる |
| vary over time | 時間とともに変化する |
| vary from person to person | 人によって異なる |
| vary from place to place | 場所によって異なる |
| vary from country to country | 国によって異なる |
| vary from case to case | 場合によって異なる |
| results may vary | 結果には個人差がある |
| prices vary | 価格はさまざまである |
| conditions vary | 条件は異なる |
| opinions vary | 意見はさまざまである |
| vary the pace | ペースに変化をつける |
| vary the diet | 食事に変化をつける |
| vary the amount | 量を変える |

## 要点

「異なる」では `vary from ... to ...` と `vary depending on ...` が中心。「変化をつける」という他動詞用法では `vary the pace/amount` のように使う。
