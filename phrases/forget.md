# forget — 頻出フレーズ

NGSL順位: 651

| フレーズ・型 | 意味・使い方 |
|---|---|
| forget ... | …を忘れる |
| forget a name | 名前を忘れる |
| forget an address | 住所を忘れる |
| forget a password | パスワードを忘れる |
| forget your keys | 鍵を忘れる |
| forget your phone | 携帯電話を置き忘れる |
| forget the details | 詳細を忘れる |
| forget what happened | 起きたことを忘れる |
| forget where ... | …がどこか忘れる |
| forget that ... | …ということを忘れる |
| forget to do ... | …するのを忘れる |
| forget to call | 電話するのを忘れる |
| forget to bring ... | …を持ってくるのを忘れる |
| forget to mention ... | …に言及するのを忘れる |
| forget doing ... | …したことを忘れる |
| never forget ... | …を決して忘れない |
| completely forget ... | …をすっかり忘れる |
| almost forget ... | …を忘れかける |
| tend to forget ... | …を忘れがちである |
| try to forget ... | …を忘れようとする |
| want to forget ... | …を忘れたい |
| be easy to forget | 忘れやすい |
| be hard to forget | 忘れにくい |
| don't forget ... | …を忘れないで |
| don't forget to do ... | …するのを忘れないで |
| forget about ... | …のことを忘れる、気にしない |
| forget all about ... | …のことをすっかり忘れる |
| forget it | もういい、気にしないで |
| let's not forget ... | …を忘れてはいけない |
| forgive and forget | 水に流す |
| forget the past | 過去を忘れる |
| forget yourself | 我を忘れる、礼儀を失う |
| a day I'll never forget | 決して忘れない日 |
| easily forgotten | 忘れられやすい |
| long forgotten | とっくに忘れられた |

## 要点

`forget to do ...` は「するのを忘れる」、`forget doing ...` は「したことを忘れる」です。
