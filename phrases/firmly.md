# firmly — 頻出フレーズ

NGSL順位: 2635

| フレーズ・型 | 意味・使い方 |
|---|---|
| firmly believe | 固く信じる |
| firmly believe that ... | …だと固く信じる |
| firmly support | 強く支持する |
| firmly oppose | 断固として反対する |
| firmly reject | きっぱり拒絶する |
| firmly deny | きっぱり否定する |
| firmly insist | 断固として主張する |
| firmly state | はっきり述べる |
| firmly establish | しっかり確立する |
| firmly rooted in ... | …に深く根差している |
| firmly based on ... | …にしっかり基づいている |
| firmly committed to ... | …に固く取り組んでいる |

| firmly attached | しっかり取り付けられた |

## 要点

物理的に「しっかりと」、態度として「断固として」を表します。意見には `firmly believe/support/oppose` がよく使われます。
