# associate — 頻出フレーズ

NGSL順位: 857

| フレーズ・型 | 意味・使い方 |
|---|---|
| associate A with B | AをBと結びつけて考える |
| be associated with ... | …と関連している |
| closely associated with ... | …と密接に関連している |
| strongly associated with ... | …と強く関連している |

| often associated with ... | …としばしば関連づけられる |

| associate a name with a face | 名前と顔を結びつける |
| associate the smell with home | その匂いから家を連想する |

## 要点

動詞の基本は `associate A with B` と受け身の `be associated with ...` です。名詞では仕事上の仲間、形容詞では `associate professor` などに使います。
