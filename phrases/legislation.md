# legislation — 頻出フレーズ

| フレーズ・型 | 意味・使い方 |
|---|---|
| introduce legislation | 法案を提出する |
| propose legislation | 法案を提案する |
| draft legislation | 法案を起草する |
| pass legislation | 法律を成立させる |
| enact legislation | 法律を制定する |
| approve legislation | 法案を承認する |
| adopt legislation | 法律を採択する |
| reject legislation | 法案を否決する |
| block legislation | 法案成立を阻止する |
| amend legislation | 法律を改正する |
| repeal legislation | 法律を廃止する |
| enforce legislation | 法律を施行する |
| implement legislation | 法律を実施する |
| comply with legislation | 法律を順守する |
| legislation requires ... | 法律は…を義務づけている |
| legislation allows ... | 法律は…を認めている |
| existing legislation | 現行法 |

| new legislation | 新しい法律 |

| state legislation | 州法 |
| environmental legislation | 環境法制 |
| employment legislation | 雇用法制 |

| safety legislation | 安全法制 |

| changes in legislation | 法律の変更 |

## 要点

集合的な不可算名詞で「法律・法制」を表します。一つを数えるときは `a piece of legislation` を使います。
