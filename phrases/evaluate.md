# evaluate — 頻出フレーズ

NGSL順位: 2139

| フレーズ・型 | 意味・使い方 |
|---|---|
| evaluate performance | 成績・業績を評価する |
| evaluate progress | 進捗を評価する |
| evaluate results | 結果を評価する |
| evaluate effectiveness | 有効性を評価する |
| evaluate the impact | 影響を評価する |
| evaluate the risk | リスクを評価する |
| evaluate the evidence | 証拠を評価する |
| evaluate the data | データを評価する |
| evaluate the quality | 品質を評価する |
| evaluate the costs | 費用を評価する |
| evaluate the benefits | 利点を評価する |
| evaluate an option | 選択肢を検討・評価する |
| evaluate a proposal | 提案を評価する |
| evaluate a program | プログラムを評価する |
| evaluate a candidate | 候補者を評価する |
| evaluate a patient | 患者を診察・評価する |
| evaluate a claim | 主張を検討する |
| carefully evaluate something | 〜を慎重に評価する |
| critically evaluate something | 〜を批判的に評価する |
| objectively evaluate something | 〜を客観的に評価する |
| independently evaluate something | 〜を独立して評価する |
| fully evaluate something | 〜を十分に評価する |
| difficult to evaluate | 評価しにくい |
| methods used to evaluate something | 〜の評価に使う方法 |
| evaluate whether ... | 〜かどうかを評価する |
| evaluate how well ... | どれほど良好かを評価する |
| be evaluated against criteria | 基準に照らして評価される |
| be evaluated on performance | 成績に基づき評価される |
| evaluate and compare options | 選択肢を評価・比較する |
| continually evaluate something | 〜を継続的に評価する |

## 要点

情報を検討して価値・質・効果などを「評価する」です。`evaluate whether/how ...` もよく使われます。
