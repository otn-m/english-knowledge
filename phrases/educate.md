# educate — 頻出フレーズ

NGSL順位: 1993

| フレーズ・型 | 意味・使い方 |
|---|---|
| educate a child | 子どもを教育する |
| educate students | 学生を教育する |
| educate the public | 一般の人々を啓発する |
| educate consumers | 消費者を啓発する |
| educate voters | 有権者に情報を与える |
| educate patients | 患者を教育する |
| educate people about something | 人々に〜について教える |
| educate someone on something | 人に〜について教える |
| educate someone to do something | 人を教育して〜できるようにする |
| educate yourself | 独学する・知識を得る |
| educate yourself about something | 〜について自分で学ぶ |
| help educate someone | 人の教育を助ける |
| seek to educate | 教育・啓発しようとする |
| aim to educate | 教育することを目的とする |
| inform and educate | 情報を与え教育する |
| educate and entertain | 教育し楽しませる |
| be educated at a school | 学校で教育を受ける |
| be educated in a subject | ある分野の教育を受ける |
| be highly educated | 高い教育を受けている |
| be well educated | 十分な教育を受けている |
| a privately educated person | 私立学校出身者 |
| educate the next generation | 次世代を教育する |
| educate for citizenship | 市民性を育む教育をする |
| educate through experience | 経験を通じて教育する |
| educate by example | 模範を示して教育する |
| educate people about risk | 人々にリスクを教える |
| educate people about health | 人々に健康知識を伝える |
| educate people about safety | 人々に安全を教える |
| educate a workforce | 労働力を教育・訓練する |
| educate the whole person | 全人的に教育する |

## 要点

学校で「教育する」だけでなく、一般の人に知識を伝えて「啓発する」意味があります。
