# colleague — 頻出フレーズ

NGSL順位: 1251

| フレーズ・型 | 意味・使い方 |
|---|---|
| a work colleague | 職場の同僚 |
| a close colleague | 親しい同僚 |
| a former colleague | 元同僚 |
| a senior colleague | 上位・年長の同僚 |
| a junior colleague | 後輩の同僚 |
| a fellow colleague | 同僚 |
| a professional colleague | 同業の仲間 |
| an academic colleague | 大学・研究上の同僚 |
| a trusted colleague | 信頼する同僚 |
| a respected colleague | 尊敬される同僚 |
| a colleague at work | 職場の同僚 |
| a colleague from ... | …から来た・…所属の同僚 |
| a colleague in the department | 部署内の同僚 |
| ask a colleague | 同僚に尋ねる |
| tell a colleague | 同僚に伝える |
| help a colleague | 同僚を助ける |
| support a colleague | 同僚を支援する |
| meet a colleague | 同僚に会う |
| discuss ... with a colleague | 同僚と…について話し合う |
| invite a colleague | 同僚を招待する |
| introduce a colleague | 同僚を紹介する |
| work with colleagues | 同僚と働く |
| talk to your colleagues | 同僚に話す |
| colleagues and friends | 同僚や友人 |
| on behalf of my colleagues | 同僚を代表して |
| among colleagues | 同僚の間で |
| a relationship with colleagues | 同僚との関係 |
| a colleague said that ... | 同僚が…と言った |
| colleagues around the world | 世界各地の同僚 |
| an immediate colleague | 同じチームなどの身近な同僚 |
| say goodbye to a colleague | 同僚に別れを告げる |

## 要点

同じ職場・専門分野で働く人を表します。単なる職場仲間には `a work colleague`、同業者には `a professional colleague` が使えます。
