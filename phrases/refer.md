# refer — 頻出フレーズ

NGSL順位: 866

| フレーズ・型 | 意味・使い方 |
|---|---|
| refer to ... | …に言及する／…を指す／…を参照する |
| refer to someone as ... | 人を…と呼ぶ |
| refer to something as ... | 物を…と呼ぶ |
| be referred to as ... | …と呼ばれる |
| refer briefly to ... | …に簡単に言及する |
| refer specifically to ... | …を具体的に指す |
| refer directly to ... | …に直接言及する |
| refer back to ... | …を再び参照する |
| refer to the previous section | 前の節を参照する |
| refer to the table | 表を参照する |
| refer to the instructions | 説明書を参照する |
| refer to the manual | マニュアルを参照する |
| refer to your notes | 自分のメモを参照する |
| refer to the original source | 原典を参照する |
| what does this refer to? | これは何を指していますか |

| refer someone to a service | 人をサービス窓口に紹介する |

| refer to something in passing | 物事に軽く触れる |

## 要点

`refer to ...` には「言及する・指す・参照する」の3つの主要な意味があります。人を専門家へ紹介する場合は `refer someone to ...` です。
