# aware — 頻出フレーズ

NGSL順位: 1039

| フレーズ・型 | 意味・使い方 |
|---|---|
| be aware of ... | …を認識している |
| be aware that ... | …だと認識している |
| become aware of ... | …に気づく |
| make someone aware of ... | 人に…を認識させる |
| remain aware of ... | …を意識し続ける |
| fully aware | 十分に認識して |
| well aware | よく分かって |
| clearly aware | 明確に認識して |
| increasingly aware | ますます認識して |
| painfully aware | 痛いほど認識して |
| acutely aware | 強く認識して |
| generally aware | おおむね認識して |
| vaguely aware | ぼんやり気づいて |
| not aware of ... | …を知らない |
| unaware of ... | …に気づいていない |
| be aware of the risks | リスクを認識している |
| be aware of the problem | 問題を認識している |
| be aware of your surroundings | 周囲の状況に注意している |
| be aware of the difference | 違いを認識している |
| be aware of your rights | 自分の権利を知っている |
| be aware of cultural differences | 文化の違いを意識している |

| aware of the need to ... | …する必要性を認識している |

## 要点

名詞には `aware of ...`、節には `aware that ...` を使います。`as far as I am aware` は「私の知る限り」です。
