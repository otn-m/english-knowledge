# impose — 頻出フレーズ

NGSL順位: 1723

| フレーズ・型 | 意味・使い方 |
|---|---|
| impose a ban | 禁止措置を課す |
| impose a fine | 罰金を科す |
| impose a penalty | 罰則を科す |
| impose a sentence | 刑を言い渡す |
| impose a tax | 税を課す |
| impose tariffs | 関税を課す |
| impose sanctions | 制裁を科す |
| impose restrictions | 制限を課す |
| impose controls | 統制を課す |
| impose conditions | 条件を課す |
| impose requirements | 要件を課す |
| impose rules | 規則を押しつける |
| impose limits | 制限を設ける |
| impose a deadline | 締切を設定する |
| impose discipline | 規律を強いる |
| impose order | 秩序を強いる |
| impose your will | 自分の意志を押しつける |
| impose your views on someone | 自分の考えを人に押しつける |
| impose something on someone | 人に〜を課す・押しつける |
| impose a burden on someone | 人に負担を課す |
| impose costs on someone | 人に費用を負担させる |
| impose pressure on someone | 人に圧力をかける |

| be imposed by law | 法律によって課される |
| newly imposed restrictions | 新たに課された制限 |
| externally imposed | 外部から課された |

| Sorry to impose. | ご面倒をかけてすみません |
| impose on someone's kindness | 人の親切につけ込む |

## 要点

罰金・税・制限などを「課す」と、考えや負担を「押しつける」が中心です。基本形は `impose A on B` です。
