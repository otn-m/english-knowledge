# demand — 頻出フレーズ

NGSL順位: 570

| フレーズ・型 | 意味・使い方 |
|---|---|
| demand ... | …を要求する |
| demand that ... | …するよう強く要求する |
| demand to know ... | …を知ろうと強く求める |
| demand an explanation | 説明を要求する |
| demand an apology | 謝罪を要求する |
| demand action | 行動を要求する |
| demand payment | 支払いを要求する |
| demand a refund | 返金を要求する |
| demand change | 変化を要求する |
| demand equal rights | 平等な権利を要求する |
| be demanded by ... | …によって要求される |
| demand for ... | …への需要 |
| high demand | 高い需要 |
| strong demand | 強い需要 |
| growing demand | 増大する需要 |
| increasing demand | 増加する需要 |
| rising demand | 上昇する需要 |
| low demand | 低い需要 |
| consumer demand | 消費者需要 |
| market demand | 市場需要 |
| meet demand | 需要を満たす |
| satisfy demand | 需要を満たす |
| respond to demand | 需要に応える |
| create demand | 需要を生み出す |
| increase demand | 需要を増やす |
| reduce demand | 需要を減らす |
| demand exceeds supply | 需要が供給を上回る |
| supply and demand | 需要と供給 |
| in demand | 需要がある、人気がある |
| be in high demand | 需要が非常に高い |
| on demand | 要求に応じて、オンデマンドで |
| make demands on ... | …に要求を突きつける、負担をかける |
| meet someone's demands | 人の要求に応じる |
| a demand for change | 変革を求める声 |
| the demands of the job | 仕事上の要求・負担 |

## 要点

動詞の `demand that ...`、需要を表す `demand for ...`、定型の `supply and demand` と `in demand` が中心です。
