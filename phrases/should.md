# should — 頻出フレーズ

NGSL順位: 89

| フレーズ・型 | 意味・使い方 |
|---|---|
| should be | ～であるべき／～のはず |
| should have | ～を持つべき／～したはず |
| should do | ～すべき |
| should not do | ～すべきでない |
| should be able to do | ～できるはず |
| should probably | おそらく～すべき |
| should definitely | 必ず～すべき |
| should always | 常に～すべき |
| should never | 決して～すべきでない |
| should still | それでも～すべき／まだ～のはず |
| should already | すでに～しているはず |
| should have done | ～すべきだった |
| should not have done | ～すべきではなかった |
| should have been | ～だったはず／～であるべきだった |
| I should think ... | ～だと思います |
| I should hope so. | 当然そうであってほしい |
| I should have known. | 分かっているべきだった |
| You should try ... | ～を試すとよい |
| You should see a doctor. | 医者に診てもらうべきです |
| What should I do? | どうすればよいですか |
| Where should I go? | どこへ行けばよいですか |
| When should I ...? | いつ～すべきですか |
| How should I ...? | どう～すべきですか |
| Why should I ...? | なぜ私が～すべきですか |
| Should I ...? | ～したほうがよいですか |
| Should we ...? | ～しましょうか |
| Shouldn't we ...? | ～したほうがよくないですか |
| It should be fine. | 大丈夫なはずです |
| That should work. | それでうまくいくはずです |
| as it should be | 本来あるべきとおりに |
| so it should | そうあるべきだ |
| if you should need ... | 万一～が必要なら |
| Should you have any questions, ... | ご質問があれば～ |

## 要点

`should` は助言だけでなく、根拠のある予想「～のはず」にもよく使う。
