# contact — 頻出フレーズ

NGSL順位: 600

| フレーズ・型 | 意味・使い方 |
|---|---|
| contact someone | 人に連絡する |
| contact us | 当社・私たちに連絡する |
| contact the police | 警察に連絡する |
| contact customer service | カスタマーサービスに連絡する |
| contact ... by phone | …に電話で連絡する |
| contact ... by email | …にメールで連絡する |
| contact ... directly | …に直接連絡する |
| contact ... immediately | …に直ちに連絡する |
| contact ... for details | 詳細について…に連絡する |
| contact information | 連絡先情報 |
| contact details | 連絡先 |
| a contact number | 連絡先電話番号 |
| a contact address | 連絡先住所 |
| a contact person | 担当者 |
| an emergency contact | 緊急連絡先 |
| eye contact | アイコンタクト |
| direct contact | 直接の接触 |
| close contact | 濃厚接触、密接な接触 |
| physical contact | 身体的接触 |
| personal contact | 個人的な接触 |
| regular contact | 定期的な連絡 |
| human contact | 人との触れ合い |
| have contact with ... | …と接触・連絡がある |
| make contact with ... | …と連絡を取る、接触する |
| establish contact with ... | …との連絡を確立する |
| keep in contact with ... | …と連絡を保つ |
| stay in contact with ... | …と連絡を取り続ける |
| get in contact with ... | …と連絡を取る |
| be in contact with ... | …と連絡を取っている |
| lose contact with ... | …と連絡が途絶える |
| come into contact with ... | …に接触する |
| avoid contact with ... | …との接触を避ける |
| put someone in contact with ... | 人を…に取り次ぐ |
| contact lens | コンタクトレンズ |
| point of contact | 窓口、接点 |

## 要点

動詞 `contact someone` には `with` を付けません。名詞では `contact information` と `keep/stay in contact with ...` が頻出です。
