# expect — 頻出フレーズ

NGSL順位: 314

| フレーズ・型 | 意味・使い方 |
|---|---|
| expect to do ... | ～するつもり・見込みである |
| expect someone to do ... | 人が～すると予想する |
| expect something to happen | 何かが起こると予想する |
| expect that ... | ～だと予想する |
| expect a result | 結果を予想する |
| expect a response | 返答を期待する |

| expect the best | 最善を期待する |
| expect the worst | 最悪を予想する |
| fully expect | 十分に予想している |
| reasonably expect | 合理的に予想する |
| generally expect | 一般に予想する |

| worse than expected | 予想以上に悪い |

| later than expected | 予想より遅く |
| more than expected | 予想以上に |

## 要点

`expect to do` は自分がする見込み、`expect someone to do` は人がすることを予想・期待する形。
