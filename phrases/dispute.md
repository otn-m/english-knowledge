# dispute — 頻出フレーズ

NGSL順位: 2029

| フレーズ・型 | 意味・使い方 |
|---|---|
| a dispute over something | 〜をめぐる争い |
| a dispute between A and B | AとBの間の争い |
| a dispute with someone | 人との争い |
| a legal dispute | 法的紛争 |
| a political dispute | 政治的対立 |
| a territorial dispute | 領土紛争 |
| a trade dispute | 貿易紛争 |
| a labor dispute | 労働争議 |
| a pay dispute | 賃金をめぐる争議 |
| a contract dispute | 契約上の紛争 |
| a family dispute | 家族間の争い |
| a long-running dispute | 長年続く争い |
| an ongoing dispute | 継続中の争い |
| a bitter dispute | 激しい争い |
| settle a dispute | 争いを解決する |
| resolve a dispute | 紛争を解決する |
| mediate a dispute | 紛争を調停する |
| avoid a dispute | 争いを避ける |
| become involved in a dispute | 争いに巻き込まれる |
| be in dispute | 争われている、係争中である |
| remain in dispute | 係争中のままである |
| beyond dispute | 議論の余地なく |
| open to dispute | 議論の余地がある |
| under dispute | 係争中で |
| dispute a claim | 主張に異議を唱える |
| dispute a decision | 決定に異議を唱える |
| dispute the facts | 事実関係を争う |
| dispute the results | 結果に異議を唱える |
| no one disputes that ... | 〜であることは誰も否定しない |
| hotly dispute something | 〜を激しく争う |

## 要点

名詞では「争い・紛争」、動詞では主張や事実を「否定する・異議を唱える」という意味です。
