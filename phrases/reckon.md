# reckon — 頻出フレーズ

NGSL順位: 2701

| フレーズ・型 | 意味・使い方 |
|---|---|
| I reckon ... | …だと思う |
| Do you reckon ...? | …だと思いますか |
| What do you reckon? | どう思いますか |
| Who do you reckon ...? | 誰が…だと思いますか |
| How much do you reckon ...? | どれくらい…だと思いますか |
| I reckon so. | そうだと思う |
| I reckon not. | そうではないと思う |
| I reckon you're right. | あなたが正しいと思う |
| I reckon we should ... | 私たちは…すべきだと思う |
| I reckon it'll be fine. | 大丈夫だと思う |
| reckon that ... | …だと思う・見積もる |
| be reckoned to be ... | …だと考えられている |
| be reckoned among ... | …の一つに数えられる |
| be reckoned as ... | …と見なされる |
| be widely reckoned to ... | …だと広く考えられている |
| reckon on doing ... | …することを当てにする |
| reckon on someone | 人を当てにする |
| reckon with ... | …を考慮に入れる |
| a force to be reckoned with | 無視できない強力な存在 |
| reckon without ... | …を考慮に入れない |
| reckon the cost | 費用を計算する |
| reckon the distance | 距離を見積もる |
| reckon the total | 合計を計算する |
| reckon something at ... | 何かを…と見積もる |
| by my reckoning | 私の計算・考えでは |
| dead reckoning | 推測航法 |
| the final reckoning | 最終的な清算 |
| a day of reckoning | 報いを受ける日 |
| reckon up the bill | 勘定を合計する |
| reckon someone to be ... | 人を…だと考える |

## 要点

英・豪などの口語では `think` に近い「…と思う」、ほかに「計算する・見なす」を表します。`a force to be reckoned with` は頻出の慣用句です。
