# compare — 頻出フレーズ

NGSL順位: 614

| フレーズ・型 | 意味・使い方 |
|---|---|
| compare A with B | AとBを比較する |
| compare A to B | AをBになぞらえる、AとBを比較する |
| compare prices | 価格を比較する |
| compare results | 結果を比較する |
| compare data | データを比較する |
| compare rates | 率を比較する |
| compare options | 選択肢を比較する |
| compare products | 製品を比較する |
| compare performance | 性能を比較する |
| compare the two | その二つを比較する |
| compare different ... | 異なる…を比較する |
| directly compare ... | …を直接比較する |
| carefully compare ... | …を慎重に比較する |
| compare favorably with ... | …と比べて遜色がない |
| compare poorly with ... | …と比べて見劣りする |
| be compared with ... | …と比較される |
| be compared to ... | …になぞらえられる、…と比較される |
| cannot be compared | 比較できない |
| how does ... compare? | …は比較するとどうですか |
| compare well with ... | …と比べて優れている |
| compare notes | 情報・意見を交換する |
| compare and contrast A and B | AとBの類似点と相違点を比較する |
| compared with ... | …と比較すると |
| compared to ... | …と比較すると |
| when compared with ... | …と比較したとき |
| as compared with ... | …と比べて |
| compare side by side | 並べて比較する |
| beyond compare | 比類のない |
| nothing compares to ... | …に勝るものはない |
| compare like with like | 同種のもの同士を比較する |
| compare the cost of A and B | AとBの費用を比較する |
| compare ... across groups | 集団間で…を比較する |
| compare ... over time | 時間の経過に沿って…を比較する |
| compare yourself with others | 自分を他人と比べる |
| compare findings with previous studies | 結果を先行研究と比較する |

## 要点

一般的な比較には `compare A with B`、類似になぞらえる場合には `compare A to B` が典型です。
