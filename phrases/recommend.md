| フレーズ・型 | 意味・使い方 |
|---|---|

| recommend that ... | …するよう勧める |

| highly recommend ... | …を強く勧める |
| strongly recommend ... | …を強く推奨する |
| personally recommend ... | 個人的に…を勧める |
| definitely recommend ... | …をぜひ勧める |
| recommend a book | 本を勧める |

## 要点

行為には `recommend doing ...`、節には `recommend that ...` を使い、通常 `recommend to do` とはしません。
