# tend — 頻出フレーズ

NGSL順位: 843

| フレーズ・型 | 意味・使い方 |
|---|---|
| tend to do ... | …する傾向がある |
| tend not to do ... | …しない傾向がある |
| people tend to ... | 人は…する傾向がある |
| children tend to ... | 子どもは…しがちである |
| prices tend to rise | 価格は上がる傾向がある |
| costs tend to be high | 費用は高い傾向がある |
| results tend to vary | 結果はばらつく傾向がある |
| things tend to change | 物事は変わりがちである |
| tend to agree | 同意する傾向がある／どちらかといえば同意する |
| tend to believe ... | …だと考える傾向がある |
| tend to think ... | …だと思いがちである |
| tend to forget ... | …を忘れがちである |
| tend to avoid ... | …を避ける傾向がある |
| tend to focus on ... | …に注目しがちである |
| tend to rely on ... | …に頼りがちである |
| tend to prefer ... | …を好む傾向がある |
| tend to occur | 起こる傾向がある |
| tend to happen | 起こりがちである |
| tend to increase | 増える傾向がある |
| tend to decrease | 減る傾向がある |
| tend to be larger | より大きい傾向がある |
| tend to be associated with ... | …と関連する傾向がある |
| tend toward ... | …の方向に向かう傾向がある |

| tend a garden | 庭の手入れをする |
| tend the plants | 植物の世話をする |
| tend the fire | 火の番をする |
| tend the wounded | 負傷者を手当てする |
| tend to a patient | 患者の世話をする |
| tend to someone's needs | 人の必要に応じて世話をする |
| tend to business | 用事・仕事に取りかかる |

## 要点

最重要の型は `tend to do ...`（…しがちだ）です。世話をする意味では `tend a garden` と `tend to a patient` の両方があります。
