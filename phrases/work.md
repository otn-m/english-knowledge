# work — 頻出フレーズ

| フレーズ・型 | 意味・使い方 |
|---|---|
| go to work | 仕事へ行く |
| be at work | 仕事中で／作用して |
| get to work | 仕事に取りかかる |
| start work | 仕事を始める |
| finish work | 仕事を終える |
| leave work | 退勤する |
| work hard | 一生懸命働く |
| work full-time | フルタイムで働く |
| work part-time | パートタイムで働く |
| work from home | 在宅勤務する |
| work together | 協力して取り組む |
| work alone | 一人で作業する |
| work well | うまく機能する |
| work properly | 正常に機能する |
| work for | ～に勤める／～のために働く |
| work at | ～で働く／～に取り組む |
| work in | ～の分野・場所で働く |
| work on | ～に取り組む |
| work with | ～と働く／～を扱う |
| work as | ～として働く |
| work out | 運動する／解決する／うまくいく |
| work through | ～を順に処理する |
| work toward | ～を目指して取り組む |
| work around | ～を回避する |
| make it work | 何とかうまくいかせる |
| hard work | 大変な仕事／努力 |
| good work | 良い仕事／よくできました |
| at work on | ～に取り組んで |

| line of work | 職種 |
| place of work | 職場 |
| work experience | 職務経験／就業体験 |
| work-life balance | 仕事と生活の調和 |
| work in progress | 進行中の作業 |

| It doesn't work. | それは機能しません |

## 要点

一般的な「仕事」は不可算の `work`。職・職位は可算の `job`。
