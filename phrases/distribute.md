# distribute — 頻出フレーズ

NGSL順位: 1980

| フレーズ・型 | 意味・使い方 |
|---|---|
| distribute food | 食料を配る |
| distribute water | 水を配る |
| distribute aid | 援助物資を配る |
| distribute supplies | 物資を配給する |
| distribute leaflets | チラシを配る |
| distribute flyers | ビラを配る |
| distribute copies | コピーを配る |
| distribute information | 情報を配布する |
| distribute a product | 製品を流通させる |
| distribute goods | 商品を流通させる |
| distribute films | 映画を配給する |
| distribute software | ソフトウェアを配布する |
| distribute funds | 資金を分配する |
| distribute income | 所得を分配する |
| distribute profits | 利益を分配する |
| distribute resources | 資源を配分する |
| distribute power | 権力を分散する |
| distribute something to someone | 〜を人に配る |
| distribute something among people | 〜を人々の間で分配する |
| distribute something across a region | 〜を地域全体に分散させる |
| distribute equally | 均等に分配する |
| distribute fairly | 公平に分配する |
| distribute widely | 広く配布する |
| evenly distribute something | 〜を均等に分散させる |
| be widely distributed | 広く分布している |
| be evenly distributed | 均等に分布している |
| be distributed free of charge | 無料配布される |
| distribute online | オンラインで配布する |
| distribute through stores | 店舗を通じて流通させる |
| distribute around the world | 世界中に流通させる |

## 要点

物・資金を「配る・分配する」、製品を「流通させる」、物が「分布する」を表します。
