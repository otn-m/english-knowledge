# submit — 頻出フレーズ

NGSL順位: 2070

| フレーズ・型 | 意味・使い方 |
|---|---|
| submit an application | 申請書を提出する |
| submit a form | 書類を提出する |
| submit a report | 報告書を提出する |
| submit a proposal | 提案書を提出する |
| submit a request | 要請を提出する |
| submit a claim | 請求を提出する |
| submit a complaint | 苦情を申し立てる |
| submit an assignment | 課題を提出する |
| submit an essay | 小論文を提出する |
| submit a paper | 論文を投稿する |
| submit evidence | 証拠を提出する |
| submit comments | 意見を提出する |
| submit your details | 個人情報を送信する |
| submit your résumé | 履歴書を提出する |
| submit something online | 〜をオンラインで提出する |
| submit something electronically | 〜を電子的に提出する |
| submit something in writing | 〜を書面で提出する |
| submit by the deadline | 締め切りまでに提出する |
| submit for approval | 承認を得るために提出する |
| submit for publication | 掲載のために投稿する |
| submit to a journal | 学術誌に投稿する |
| submit to the court | 裁判所に提出する |
| be required to submit something | 〜の提出を求められる |
| fail to submit something | 〜を提出し損なう |
| click Submit | 「送信」をクリックする |
| submit yourself to something | 〜に従う |
| submit to authority | 権威に服従する |
| submit to treatment | 治療を受け入れる |
| refuse to submit | 服従を拒む |
| I submit that ... | 〜であると申し上げる |

## 要点

書類やデータを「提出・送信する」が中心です。`submit to ...` では権威・処置などに「服従する、身を委ねる」です。
