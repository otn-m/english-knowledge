# with — 頻出フレーズ

NGSL順位: 18

人との関係、道具、付帯、対象を表す基本用法と、`with` を要求する頻出の動詞・形容詞の組み合わせを選んだ。

| フレーズ・型 | 意味・使い方 |
|---|---|
| agree with | （人・意見）に同意する／体質に合う |
| deal with | ～に対処する／～を扱う |
| help with | ～を手伝う |
| start with | ～から始める |
| begin with | ～から始める |
| end with | ～で終わる |
| come with | ～が付いてくる |
| go with | ～に合う／～を選ぶ |
| meet with | ～と会う／～を受ける |
| talk with | ～と話す |
| work with | ～と一緒に働く／～を扱う |
| live with | ～と暮らす／～を受け入れて生きる |
| stay with | ～の家に泊まる／～を続ける |
| share ... with | ～を…と共有する |
| compare A with B | AをBと比較する |
| provide someone with | （人）に～を提供する |
| fill ... with | ～を…で満たす |
| cover ... with | ～を…で覆う |
| replace A with B | AをBに取り替える |
| be familiar with | ～をよく知っている |

| come up with | ～を思いつく |
| put up with | ～を我慢する |
| keep up with | ～に遅れずについていく |

| get in touch with | ～と連絡を取る |
| fall in love with | ～に恋をする |
| have something to do with | ～と何らかの関係がある |
| together with | ～と一緒に／～に加えて |
| along with | ～と一緒に／～に加えて |
| with regard to | ～に関して |

| with the help of | ～の助けを借りて |
| with a view to doing | ～する目的で |
| with that said | そうは言っても |

## 要点

- `agree with a person/an opinion`、`agree on a topic/decision`、`agree to a proposal` の組み合わせを区別する。
- `provide someone with something` は `provide something for someone` とも言える。
- `with a view to` の `to` は前置詞なので、後ろは `doing`。
