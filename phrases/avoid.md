| フレーズ・型 | 意味・使い方 |
|---|---|

| avoid using ... | …を使うのを避ける |
| avoid making the same mistake | 同じ間違いを繰り返さないようにする |
| avoid getting involved | 関わるのを避ける |
| avoid eye contact | 目を合わせない |
| avoid conflict | 衝突を避ける |
| avoid confrontation | 対立を避ける |
| avoid confusion | 混乱を避ける |
| avoid delays | 遅れを避ける |
| avoid unnecessary costs | 不必要な費用を避ける |
| avoid risk | リスクを避ける |
| avoid danger | 危険を避ける |

| avoid problems | 問題を避ける |
| avoid trouble | 面倒を避ける |
| avoid responsibility | 責任を逃れる |
| avoid the issue | 問題を避けて通る |
| avoid the question | 質問に答えるのを避ける |
| avoid certain foods | 特定の食品を避ける |

## 要点

`avoid` の後は不定詞ではなく、名詞か動名詞を置きます。基本形は `avoid doing ...` です。
