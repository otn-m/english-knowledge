# traffic — 頻出フレーズ

NGSL順位: 1225

| フレーズ・型 | 意味・使い方 |
|---|---|
| heavy traffic | 交通量が多い状態 |
| light traffic | 交通量が少ない状態 |
| busy traffic | 混雑した交通 |
| morning traffic | 朝の交通 |
| rush-hour traffic | ラッシュ時の交通 |
| road traffic | 道路交通 |
| air traffic | 航空交通 |
| internet traffic | インターネット通信量 |
| web traffic | ウェブサイトへのアクセス量 |
| data traffic | データ通信量 |
| a traffic jam | 交通渋滞 |
| traffic lights | 信号機 |
| a traffic sign | 道路標識 |
| traffic rules | 交通規則 |
| traffic flow | 交通の流れ |
| traffic volume | 交通量 |
| a traffic accident | 交通事故 |
| traffic congestion | 交通渋滞 |
| traffic control | 交通整理・管制 |
| traffic management | 交通管理 |
| a traffic police officer | 交通警察官 |
| be stuck in traffic | 渋滞にはまっている |
| be caught in traffic | 渋滞に巻き込まれる |
| sit in traffic | 渋滞した車内で待つ |
| avoid traffic | 渋滞を避ける |
| direct traffic | 交通整理をする |
| reduce traffic | 交通量を減らす |
| increase traffic to a website | ウェブサイトへのアクセスを増やす |
| traffic slows down | 交通の流れが遅くなる |
| traffic comes to a standstill | 交通が完全に止まる |
| drive through heavy traffic | 激しい交通の中を運転する |

## 要点

道路・航空の交通だけでなく、インターネット上のデータ量や訪問数も表します。渋滞には `be stuck/caught in traffic` が頻出です。
