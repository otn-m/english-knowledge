# deal — 頻出フレーズ

NGSL順位: 321

| フレーズ・型 | 意味・使い方 |
|---|---|
| deal with ... | ～に対処する／～を扱う |
| deal with a problem | 問題に対処する |
| deal with the situation | 状況に対処する |
| deal with stress | ストレスに対処する |
| deal with customers | 顧客に対応する |
| be difficult to deal with | 対応しにくい |
| learn to deal with ... | ～に対処する方法を学ぶ |
| a good deal | 良い取引／かなり |
| a great deal | かなり多く |
| a great deal of ... | 非常に多くの～ |
| a big deal | 大事なこと |
| no big deal | 大したことではない |
| a fair deal | 公正な取引 |
| a better deal | より有利な条件 |
| the best deal | 最も有利な取引 |
| a business deal | 商取引 |
| a trade deal | 貿易協定 |
| a peace deal | 和平合意 |
| a package deal | 一括取引 |
| make a deal | 取引・合意をする |
| reach a deal | 合意に達する |
| sign a deal | 契約に署名する |
| close a deal | 取引を成立させる |
| negotiate a deal | 取引を交渉する |
| accept a deal | 取引条件を受け入れる |
| reject a deal | 取引を拒否する |
| offer a deal | 取引を提案する |
| get a good deal | お買い得な取引を得る |
| strike a deal | 合意を取り付ける |
| cut a deal | 取引をまとめる |
| It's a deal. | それで決まりです |
| Deal? | それでいいですか |
| deal in ... | ～を商う |
| deal out ... | ～を配る |
| raw deal | 不当な扱い |

## 要点

対処は `deal with`、合意は `make/reach a deal`。「量が多い」は `a great deal of`。
