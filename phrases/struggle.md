# struggle — 頻出フレーズ

NGSL順位: 1171

| フレーズ・型 | 意味・使い方 |
|---|---|
| struggle to do ... | …しようと苦労する |
| struggle with ... | …に苦労する・…と闘う |
| struggle against ... | …に抵抗して闘う |
| struggle for ... | …を求めて闘う |
| struggle through ... | 苦労して…を切り抜ける |
| struggle to survive | 生き残ろうともがく |
| struggle to cope | 対処しようと苦労する |
| struggle to understand | 理解するのに苦労する |
| struggle to find ... | …を見つけるのに苦労する |
| struggle to make ends meet | 収支を合わせるのに苦労する |
| struggle with depression | うつに苦しむ |
| struggle with addiction | 依存症に苦しむ |
| struggle with a problem | 問題に苦闘する |
| struggle for freedom | 自由を求める闘い |
| struggle for power | 権力闘争 |
| struggle for control | 支配権をめぐる争い |
| a long struggle | 長い闘い |
| a difficult struggle | 困難な闘い |
| an ongoing struggle | 続いている闘い |
| a daily struggle | 日々の苦労 |
| an uphill struggle | 困難な闘い |
| a power struggle | 権力争い |
| a political struggle | 政治闘争 |
| an armed struggle | 武装闘争 |
| an internal struggle | 内面的な葛藤 |
| a life-and-death struggle | 生死をかけた闘い |
| face a struggle | 困難な闘いに直面する |
| continue the struggle | 闘いを続ける |
| win the struggle | 闘いに勝つ |
| give up the struggle | 闘いを諦める |
| a struggle between A and B | AとBの間の争い |

## 要点

動詞では `struggle to do` と `struggle with ...`、名詞では目標を示す `a struggle for ...` が基本です。日常的な苦労にも社会的な闘争にも使えます。
