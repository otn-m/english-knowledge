# mention — 頻出フレーズ

NGSL順位: 564

|---|---|
| mention ... | …について触れる、…の名を挙げる |
| mention that ... | …だと述べる |
| mention doing ... | …したことに触れる |
| mention ... to someone | …を人に話す |
| mention someone's name | 人の名前を挙げる |
| mention ... briefly | …に簡単に触れる |
| mention ... in passing | …にそれとなく触れる |
| mention ... specifically | …に具体的に言及する |
| mention ... earlier | 先ほど…に触れる |
| mention ... above | 上で…に言及する |
| mention ... below | 下で…に言及する |
| as mentioned above | 上述のとおり |

| be worth mentioning | 言及する価値がある |
| fail to mention ... | …を言い忘れる、…に触れない |
| forget to mention ... | …を言い忘れる |
| neglect to mention ... | …に触れない |
| not mention ... | …には触れない |
| don't mention it | どういたしまして、気にしないで |

| get a mention | 名前を挙げてもらう、取り上げられる |
| special mention | 特別な言及、特別賞 |
| honorable mention | 選外佳作、特別表彰 |

| no one mentioned ... | 誰も…には触れなかった |

## 要点

動詞では `mention that ...` と `mention ... to someone` が基本です。`mention about ...` とは通常言いません。
