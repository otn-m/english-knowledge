# hardly — 頻出フレーズ

NGSL順位: 1340

| フレーズ・型 | 意味・使い方 |
|---|---|
| hardly ever | めったに…ない |
| hardly any ... | ほとんど…ない |
| hardly anyone | ほとんど誰も…ない |
| hardly anything | ほとんど何も…ない |
| hardly anywhere | ほとんどどこにも…ない |
| hardly enough | とても十分とはいえない |
| hardly likely | まずありそうにない |
| hardly surprising | ほとんど驚くことではない |
| hardly know ... | …をほとんど知らない |
| hardly notice ... | …にほとんど気づかない |
| hardly see ... | …がほとんど見えない |
| hardly hear ... | …がほとんど聞こえない |
| hardly believe ... | …がとても信じられない |
| hardly imagine ... | …をほとんど想像できない |
| can hardly wait | 待ちきれない |
| can hardly breathe | ほとんど息ができない |

| hardly matters | ほとんど重要ではない |
| hardly changed | ほとんど変わっていない |
| hardly working | ほとんど機能・仕事をしていない |
| hardly have time to ... | …する時間がほとんどない |
| hardly more than ... | …をわずかに超える程度 |

## 要点

「ほとんど…ない」を表す準否定語で、後ろに追加の `not` は不要です。`hardly ever/any/anyone` と `can hardly wait` が頻出です。
