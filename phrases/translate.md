# translate — 頻出フレーズ

NGSL順位: 2310

| フレーズ・型 | 意味・使い方 |
|---|---|
| translate A into B | AをB（別の言語）に翻訳する |
| translate from A into B | A語からB語へ翻訳する |
| translate a book | 本を翻訳する |
| translate a document | 文書を翻訳する |
| translate a text | 文章を翻訳する |
| translate a sentence | 文を翻訳する |
| translate a word | 単語を訳す |
| translate a passage | 一節を翻訳する |
| translate a website | ウェブサイトを翻訳する |
| translate a message | メッセージを翻訳する |
| translate an article | 記事を翻訳する |
| translate a novel | 小説を翻訳する |
| translate a poem | 詩を翻訳する |
| translate the Bible | 聖書を翻訳する |
| translate literally | 直訳する |
| translate freely | 意訳する |
| translate accurately | 正確に翻訳する |
| translate automatically | 自動翻訳する |
| be translated into English | 英語に翻訳される |
| be translated into several languages | 複数の言語に翻訳される |
| difficult to translate | 翻訳するのが難しい |
| easy to translate | 翻訳しやすい |
| roughly translated as ... | おおよそ～と訳される |
| loosely translated as ... | 意訳すれば～となる |
| translate well | うまく翻訳できる・訳してもよさが伝わる |
| translate badly | 翻訳するとよさが失われる・訳がまずい |
| translate ideas into action | 考えを行動に移す |
| translate theory into practice | 理論を実践に移す |
| translate into results | 結果につながる |
| translate into higher prices | 価格上昇という結果になる |

## 要点

言語間の「翻訳」に加え、考え・理論などを行動や結果へ「具体化する」という意味でもよく使います。
