# determine — 頻出フレーズ

NGSL順位: 708

| フレーズ・型 | 意味・使い方 |
|---|---|
| determine ... | …を決定・判定する |
| determine the cause | 原因を特定する |
| determine the effect | 影響を判定する |
| determine the outcome | 結果を決める |
| determine the value | 値を求める |
| determine the size | 大きさを決定する |
| determine the level | 水準を決定する |
| determine the amount | 量を決定する |
| determine the extent of ... | …の程度を明らかにする |
| determine the nature of ... | …の性質を明らかにする |
| determine whether ... | …かどうかを判断する |
| determine if ... | …かどうかを判断する |
| determine how ... | どのように…かを判断する |
| determine why ... | なぜ…かを突き止める |
| determine what ... | 何が…かを判断する |
| determine that ... | …であると判断する |
| help determine ... | …の決定に役立つ |
| accurately determine ... | …を正確に判定する |
| independently determine ... | …を独自に決定する |
| be difficult to determine | 判断が難しい |
| be impossible to determine | 判断できない |
| be determined by ... | …によって決まる |
| be largely determined by ... | 主に…によって決まる |
| factors that determine ... | …を決める要因 |
| determine your future | 自分の将来を決める |
| determine eligibility | 資格の有無を判定する |
| determine responsibility | 責任の所在を判断する |
| determine a winner | 勝者を決める |
| determine a course of action | 行動方針を決める |
| be determined to do ... | …しようと固く決意している |
| remain determined | 決意を保つ |
| a determined effort | 断固とした努力 |
| determine in advance | あらかじめ決める |
| determine the facts | 事実を確認する |
| determine the best way to ... | …する最善の方法を決める |

## 要点

事実の判定には `determine whether/cause/value`、結果を左右する場合は `be determined by ...`、決意には `be determined to do ...` を使います。
