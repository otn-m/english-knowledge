# protect — 頻出フレーズ

NGSL順位: 903

| フレーズ・型 | 意味・使い方 |
|---|---|
| protect someone from ... | 人を…から守る |
| protect something against ... | 物を…から保護する |
| protect yourself | 自分の身を守る |
| protect your family | 家族を守る |
| protect children | 子どもを守る |
| protect the public | 市民を守る |
| protect human rights | 人権を守る |
| protect privacy | プライバシーを守る |
| protect personal information | 個人情報を守る |
| protect your interests | 自分の利益を守る |
| protect your reputation | 評判を守る |
| protect your property | 財産を守る |
| protect the environment | 環境を守る |
| protect wildlife | 野生生物を守る |
| protect endangered species | 絶滅危惧種を保護する |
| protect jobs | 雇用を守る |
| protect the economy | 経済を守る |
| protect against disease | 病気を防ぐ |
| protect against infection | 感染を防ぐ |
| protect against damage | 損傷を防ぐ |
| protect against the sun | 日光から守る |
| protect from harm | 危害から守る |
| protect from attack | 攻撃から守る |

| fully protect ... | …を完全に保護する |
| adequately protect ... | …を十分に保護する |

| password-protect a file | ファイルをパスワードで保護する |
| wear protective clothing | 防護服を着る |

## 要点

基本形は `protect A from/against B` です。人・権利・情報・環境など、守る対象を直接目的語に置きます。
