# unless — 頻出フレーズ

NGSL順位: 1005

| フレーズ・型 | 意味・使い方 |
|---|---|
| unless otherwise stated | 別段の記載がない限り |
| unless otherwise noted | 特に注記がない限り |
| unless otherwise specified | 特に指定がない限り |

| unless otherwise indicated | 別に示されない限り |
| unless necessary | 必要でない限り |
| unless required | 求められない限り |
| unless requested | 要請されない限り |
| unless permitted by law | 法律で認められない限り |

| unless we act now | 今行動しない限り |

| unless it rains | 雨が降らない限り |

## 要点

`unless` は「if ... not」に相当します。未来の条件でも、`unless` 節の中では通常現在形を使います。
