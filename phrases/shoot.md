# shoot — 頻出フレーズ

NGSL順位: 1003

| フレーズ・型 | 意味・使い方 |
|---|---|
| shoot a gun | 銃を撃つ |
| shoot at ... | …を狙って撃つ |
| shoot someone in the leg | 人の脚を撃つ |
| shoot and kill someone | 人を撃ち殺す |
| shoot to kill | 殺す意図で撃つ |
| shoot into the air | 空に向けて撃つ |
| police shoot ... | 警察が…を撃つ |
| be shot dead | 撃たれて死亡する |
| shoot an arrow | 矢を放つ |
| shoot a basketball | バスケットボールをシュートする |
| shoot a goal | ゴールを狙ってシュートする |
| shoot a film | 映画を撮影する |
| shoot a scene | 場面を撮影する |
| shoot a video | 動画を撮影する |
| shoot a photo | 写真を撮る |
| shoot on location | ロケ撮影する |
| a photo shoot | 写真撮影 |
| a fashion shoot | ファッション撮影 |
| a film shoot | 映画撮影 |
| shoot up | 急上昇する／銃を乱射する |
| shoot down | 撃ち落とす／案を却下する |
| shoot out | 飛び出す／撃ち合う |
| shoot through the roof | 急騰する |
| shoot a glance at ... | …をちらりと見る |
| shoot someone a look | 人に視線を投げかける |
| shoot a question at someone | 人に質問を浴びせる |
| shoot from the hip | よく考えずに発言・行動する |
| shoot yourself in the foot | 自分で自分の首を絞める |
| shoot the breeze | 雑談する |
| shoot for the moon | 大きな目標を目指す |
| shoot straight | 正直に話す |
| new shoots | 新芽 |

## 要点

銃撃・スポーツ・撮影の3用法があります。方向は `shoot at ...`、比喩では `shoot up/down` が頻出します。
