# argue — 頻出フレーズ

NGSL順位: 740

| フレーズ・型 | 意味・使い方 |
|---|---|
| argue with someone | 人と言い争う |
| argue about ... | …について言い争う |
| argue over ... | …をめぐって言い争う |
| argue with each other | 互いに言い争う |
| start to argue | 言い争い始める |
| continue to argue | 言い争い続ける |
| constantly argue | いつも言い争う |
| argue back | 口答えする |
| argue for ... | …に賛成する論拠を述べる |
| argue against ... | …に反対する論拠を述べる |
| argue in favor of ... | …に賛成だと論じる |
| argue that ... | …だと主張する |
| argue the case for ... | …を支持する論拠を述べる |
| argue a point | ある点について論じる |
| argue your case | 自分の主張を論じる |
| strongly argue that ... | …だと強く主張する |
| convincingly argue that ... | …だと説得力をもって論じる |
| successfully argue that ... | …だと論じて認めさせる |

| some argue that ... | …と主張する人もいる |
| one could argue that ... | …とも言える |
| difficult to argue with ... | …には反論しにくい |
| argue from evidence | 証拠に基づいて論じる |
| argue on the basis of ... | …に基づいて論じる |
| argue both sides | 両方の立場を論じる |
| argue endlessly | 延々と言い争う |
| argue heatedly | 激しく言い争う |

| argue someone into doing ... | 人を説得して…させる |

| argue persuasively | 説得力をもって論じる |

## 要点

口論は `argue with someone about ...`、主張は `argue that ...`、賛否の論拠は `argue for/against ...` です。
