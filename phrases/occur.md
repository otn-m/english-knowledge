# occur — 頻出フレーズ

NGSL順位: 718

| フレーズ・型 | 意味・使い方 |
|---|---|

| occur if ... | もし…なら起こる |

| occur repeatedly | 繰り返し起こる |

| occur simultaneously | 同時に起こる |

| where ... occurs | …が起こる場所で |

## 要点

`occur` は自動詞で、場所・時には `occur in/during ...` を使います。「考えが浮かぶ」は `It occurs to someone that ...` です。
