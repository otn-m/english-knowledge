# such — 頻出フレーズ

NGSL順位: 100

| フレーズ・型 | 意味・使い方 |
|---|---|
| such a good idea | そんなに良い考え |
| such a long time | そんなに長い時間 |
| such a big problem | そんなに大きな問題 |
| such an important issue | それほど重要な問題 |
| such people | そのような人々 |
| such things | そのようなもの・こと |
| such cases | そのような事例 |
| such situations | そのような状況 |
| such behavior | そのような行動 |
| such information | そのような情報 |
| such as | ～のような |
| such as A and B | AやBのような |
| and such | ～など |
| as such | それ自体として／従って |
| no such thing | そのようなものはない |
| no such person | そのような人はいない |
| nothing of the sort / no such | そのようなものではない |
| any such | そのようないかなる～ |
| in such a way | そのような方法で |
| in such cases | そのような場合には |
| under such circumstances | そのような状況下で |
| one such example | そのような例の一つ |
| one such case | そのような事例の一つ |
| many such cases | そのような多くの事例 |
| some such | 何かそのような |
| such a shame | 本当に残念なこと |
| such a pity | 本当に残念なこと |
| such a relief | 本当にほっとすること |
| such a surprise | 本当に驚き |
| such a mess | ひどい散らかり・混乱 |
| such a lot of | 非常に多くの（主にイギリス英語） |
| such ... that | とても～なので… |
| not such a bad idea | それほど悪い考えではない |
| of such importance | それほど重要で |
| There is no such thing as ... | ～などというものはない |

## 要点

`such + (a/an) + 形容詞 + 名詞`、`so + 形容詞・副詞`。`such a good book` と `so good a book`。
