|---|---|

| exhibit signs of something | 〜の兆候を示す |
| exhibit behavior | 行動を示す |
| exhibit characteristics | 特徴を示す |
| exhibit a pattern | パターンを示す |
| exhibit a tendency | 傾向を示す |
| exhibit great skill | 優れた技能を示す |

| be exhibited at a museum | 博物館で展示される |

| a museum exhibit | 博物館の展示品 |

| a new exhibit | 新しい展示 |

## 要点

動詞では特徴を「示す」、作品を「展示する」、名詞では「展示品・証拠物」を表します。
