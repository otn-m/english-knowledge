# deny — 頻出フレーズ

NGSL順位: 1429

| フレーズ・型 | 意味・使い方 |
|---|---|
| deny that ... | ～であることを否定する |
| deny doing ... | ～したことを否定する |
| deny an allegation | 疑惑を否定する |
| deny a claim | 主張を否定する |
| deny a charge | 容疑を否認する |
| deny an accusation | 非難・告発を否定する |
| deny responsibility | 責任を否定する |
| deny involvement | 関与を否定する |
| deny wrongdoing | 不正行為を否定する |
| deny any knowledge of ... | ～について何も知らないと言う |
| deny the existence of ... | ～の存在を否定する |
| deny the truth | 真実を否定する |
| strongly deny ... | ～を強く否定する |
| firmly deny ... | ～をきっぱり否定する |
| repeatedly deny ... | ～を繰り返し否定する |
| publicly deny ... | ～を公に否定する |
| categorically deny ... | ～を断固として否定する |
| refuse to deny ... | ～を否定することを拒む |
| cannot deny that ... | ～であることは否定できない |
| there is no denying that ... | ～であることは否定できない |
| deny someone access to ... | 人に～への立ち入り・利用を認めない |
| deny someone permission | 人に許可を与えない |
| deny someone entry | 人の入場を拒む |
| deny someone a visa | 人へのビザ発給を拒む |
| deny someone treatment | 人に治療を受けさせない |
| deny someone their rights | 人から権利を奪う |
| deny yourself something | 自分に～を禁じる |
| deny yourself the pleasure of ... | ～する楽しみを自分に許さない |
| be denied access | 利用・立ち入りを拒否される |
| be denied the opportunity to do | ～する機会を与えられない |
| justice delayed is justice denied | 遅れた正義は正義の否定である |

## 要点

内容の否定は `deny that ...`、行為は `deny doing ...`。人から何かを拒むときは `deny someone something` または `deny something to someone`。
