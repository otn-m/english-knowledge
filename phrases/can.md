| can get | ～を得られる |
| can help | 助けられる |
| can use | 使用できる |
| can see | 見える／分かる |
| can hear | 聞こえる |
| can afford to do | ～する余裕がある |
| can hardly | ほとんど～できない |
| can easily | 容易に～できる |
| can always | いつでも～できる |
| can still | まだ～できる |
| can no longer | もはや～できない |

## 要点

能力・可能性・許可・依頼に使う。過去の一度きりの達成には `was/were able to` が自然なことが多い。
