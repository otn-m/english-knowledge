# effective — 頻出フレーズ

NGSL順位: 1031

| フレーズ・型 | 意味・使い方 |
|---|---|
| highly effective | 非常に効果的な |
| extremely effective | 極めて効果的な |
| very effective | とても効果的な |
| particularly effective | 特に効果的な |
| equally effective | 同程度に効果的な |
| relatively effective | 比較的効果的な |
| cost-effective | 費用対効果の高い |
| be effective in doing ... | …するのに効果的である |
| be effective against ... | …に対して効果がある |
| be effective at ... | …に有効である |
| prove effective | 効果的だと分かる |
| remain effective | 効果を保つ |
| become effective | 効果を持つ／発効する |
| an effective way | 効果的な方法 |
| an effective method | 効果的な方法 |
| an effective strategy | 効果的な戦略 |
| an effective approach | 効果的な取り組み方 |
| an effective solution | 効果的な解決策 |
| an effective treatment | 効果的な治療 |
| an effective tool | 効果的な手段 |
| an effective system | 効果的な制度 |
| effective communication | 効果的な意思疎通 |
| effective leadership | 効果的な指導力 |
| effective management | 効果的な管理 |
| effective control | 有効な管理・統制 |
| take effective action | 効果的な行動を取る |
| effective immediately | 即日発効で |
| an effective date | 発効日 |
| come into effect | 発効する |
| no longer effective | もはや効果がない |
| effective use of ... | …の効果的な利用 |
| an effective response | 効果的な対応 |

## 要点

用途には `effective in doing ...`、対象には `effective against ...` を使います。`effective immediately` は「即日発効」です。
