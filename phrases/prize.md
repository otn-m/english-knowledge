# prize — 頻出フレーズ

NGSL順位: 2005

| フレーズ・型 | 意味・使い方 |
|---|---|
| win a prize | 賞を取る |
| receive a prize | 賞を受け取る |
| get a prize | 賞品をもらう |
| award a prize | 賞を授与する |
| give someone a prize | 人に賞を与える |
| offer a prize | 賞品を提供する |
| claim a prize | 賞金・賞品を受け取る |
| share a prize | 賞を共同受賞する |
| a first prize | 一等賞 |
| a second prize | 二等賞 |
| a top prize | 最高賞 |
| a grand prize | 大賞 |
| a major prize | 主要な賞 |
| a special prize | 特別賞 |
| a cash prize | 賞金 |
| prize money | 賞金 |
| a Nobel Prize | ノーベル賞 |
| a literary prize | 文学賞 |
| a peace prize | 平和賞 |
| a prize winner | 受賞者 |
| a prize-winning author | 受賞作家 |
| a prize competition | 懸賞競技 |
| compete for a prize | 賞を目指して競う |
| the prize goes to ... | 受賞者は… |
| prize possession | 何より大切な所有物 |
| prize asset | 非常に価値ある資産 |
| prize open | こじ開ける（主に英） |
| prize something from someone | 人から〜を苦労して聞き出す |
| prize something highly | 〜を非常に大切にする |
| a highly prized item | 非常に珍重される品 |

## 要点

競技・功績に対する「賞・賞品」と、動詞で「高く評価する・こじ開ける」を表します。
