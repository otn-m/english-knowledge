# observe — 頻出フレーズ

NGSL順位: 1098

| フレーズ・型 | 意味・使い方 |
|---|---|
| observe carefully | 注意深く観察する |
| closely observe ... | …を綿密に観察する |
| directly observe ... | …を直接観察する |
| observe behavior | 行動を観察する |
| observe changes | 変化を観察する |
| observe the effects of ... | …の影響を観察する |
| observe a pattern | パターンを観察する |
| observe an event | 出来事を観察する |
| observe someone doing ... | 人が…しているのを観察する |
| observe that ... | …だと気づく／述べる |
| be observed in ... | …で観察される |
| commonly observed | よく観察される |
| frequently observed | 頻繁に観察される |
| rarely observed | めったに観察されない |
| difficult to observe | 観察しにくい |
| observe the law | 法律を守る |
| observe the rules | 規則を守る |
| observe a tradition | 伝統を守る |
| observe a custom | 慣習を守る |
| observe a holiday | 祝日を祝う・守る |
| observe a religious festival | 宗教祭日を祝う |
| observe a moment of silence | 黙とうする |
| observe the anniversary | 記念日を祝う・追悼する |
| strictly observe ... | …を厳守する |
| fail to observe ... | …を守らない |
| observe protocol | 儀礼・手順を守る |
| observe safety precautions | 安全上の注意を守る |
| observe from a distance | 遠くから観察する |
| observe under a microscope | 顕微鏡で観察する |
| an observed difference | 観察された違い |
| observe and record ... | …を観察して記録する |
| observe how ... | どのように…かを観察する |

## 要点

「観察する」のほか、法律・慣習・祝日を「守る・執り行う」という意味があります。
