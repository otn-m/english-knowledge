# aim — 頻出フレーズ

NGSL順位: 794

| フレーズ・型 | 意味・使い方 |
|---|---|
| aim to do ... | …することを目指す |
| aim to improve ... | …の改善を目指す |
| aim to reduce ... | …の削減を目指す |
| aim to increase ... | …の増加を目指す |
| aim to provide ... | …の提供を目指す |
| aim to achieve ... | …の達成を目指す |
| aim for ... | …を目指す |
| aim for success | 成功を目指す |
| aim for a target | 目標を狙う |
| aim at ... | …を狙う、対象とする |
| aim a gun at ... | 銃を…に向ける |
| aim high | 高い目標を掲げる |
| aim low | 低い目標を設定する |
| be aimed at ... | …を対象・目的としている |
| be aimed at doing ... | …することを目的としている |
| be specifically aimed at ... | 特に…を対象としている |
| a main aim | 主な目的 |
| a primary aim | 第一の目的 |
| a clear aim | 明確な目的 |
| a common aim | 共通の目的 |
| a long-term aim | 長期目標 |
| achieve an aim | 目的を達成する |
| accomplish an aim | 目的を達成する |
| pursue an aim | 目的を追求する |
| state an aim | 目的を述べる |
| have the aim of doing ... | …する目的を持つ |
| with the aim of doing ... | …することを目的として |
| the aim is to do ... | 目的は…することである |
| take aim at ... | …に狙いを定める、…を批判する |
| miss your aim | 狙いを外す |
| a political aim | 政治的目的 |
| a strategic aim | 戦略的目標 |
| aims and objectives | 目的と目標 |
| ultimately aim to ... | 最終的に…を目指す |

## 要点

行動目標は `aim to do ...`、達成対象は `aim for ...`、狙う対象は `aim at ...` で表します。
