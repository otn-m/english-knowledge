# admit — 頻出フレーズ

NGSL順位: 1034

| フレーズ・型 | 意味・使い方 |
|---|---|
| admit that ... | …だと認める |
| admit doing ... | …したことを認める |
| admit to doing ... | …したことを認める |
| admit the truth | 真実を認める |
| admit a mistake | 間違いを認める |
| admit defeat | 敗北を認める |
| admit responsibility | 責任を認める |
| freely admit ... | …を率直に認める |
| openly admit ... | …を公に認める |
| readily admit ... | …をあっさり認める |
| finally admit ... | …をついに認める |
| refuse to admit ... | …を認めることを拒む |
| be forced to admit ... | …を認めざるを得ない |
| I must admit ... | 正直に言うと… |
| I have to admit ... | 認めざるを得ないが… |
| admittedly, ... | 確かに…ではあるが |
| admit someone to hospital | 人を入院させる |
| be admitted to hospital | 入院する |
| admit a patient | 患者を入院させる |
| admit someone to a program | 人をプログラムに受け入れる |
| be admitted to university | 大学への入学を認められる |
| admit students | 学生を受け入れる |
| admit members | 会員を受け入れる |
| admit visitors | 入場者を受け入れる |
| admit one person | 1人の入場を認める |
| no one admitted | 入場不可 |
| admit light | 光を通す |
| admit of no doubt | 疑いの余地がない |
| admit someone into ... | 人を…の中へ入れる |
| be admitted as a member | 会員として認められる |
| admission is free | 入場無料 |
| admit your feelings | 自分の気持ちを認める |

## 要点

告白・承認には `admit that/doing/to doing ...`、入院・入学には `be admitted to ...` を使います。
