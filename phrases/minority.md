| a small minority | 少数派 |
| a tiny minority | ごく少数 |
| a significant minority | かなりの少数派 |
| a substantial minority | 相当数の少数派 |
| a large minority | 大きな少数派 |
| a vocal minority | 声の大きい少数派 |
| an ethnic minority | 少数民族 |
| a racial minority | 人種的少数派 |
| a religious minority | 宗教的少数派 |
| a national minority | 国内少数民族 |
| a sexual minority | 性的少数者 |
| a minority group | 少数派集団 |
| a minority community | 少数派共同体 |
| minority rights | 少数者の権利 |
| minority interests | 少数派の利益 |
| minority representation | 少数派の代表 |

| belong to a minority | 少数派に属する |

| remain a minority | 少数派のままである |
| only a minority | 少数にすぎない |

| a minority party | 少数政党 |
| a minority stake | 少数持分 |
| a minority shareholder | 少数株主 |

## 要点

全体の半数未満の「少数・少数派」と、社会的少数集団を表します。`in the minority` が頻出です。
