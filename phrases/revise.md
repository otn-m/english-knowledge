# revise — 頻出フレーズ

NGSL順位: 2688

| フレーズ・型 | 意味・使い方 |
|---|---|
| revise a document | 文書を修正する |
| revise a report | 報告書を修正する |
| revise an essay | 作文・論文を推敲する |
| revise a draft | 草稿を修正する |
| revise a manuscript | 原稿を改訂する |
| revise a plan | 計画を見直す |
| revise a proposal | 提案を修正する |
| revise a policy | 政策を見直す |
| revise a law | 法律を改正する |
| revise the rules | 規則を改定する |
| revise the guidelines | 指針を改訂する |
| revise a schedule | 日程を修正する |
| revise a budget | 予算を見直す |
| revise an estimate | 見積もりを修正する |
| revise a forecast | 予測を修正する |
| revise your opinion | 意見を改める |
| revise your view | 見方を改める |
| revise your expectations | 予想・期待を修正する |
| revise something upward | 数値を上方修正する |
| revise something downward | 数値を下方修正する |
| significantly revise | 大幅に改訂する |
| substantially revise | 大幅に改訂する |
| carefully revise | 注意深く修正する |
| completely revise | 全面的に改訂する |
| revise for an exam | 試験の復習をする |
| revise your notes | ノートを復習する |
| revise regularly | 定期的に復習する |
| a revised version | 改訂版 |
| a revised edition | 改訂版 |
| newly revised | 新たに改訂された |

## 要点

文書・計画・数値を「修正・改訂する」を表します。英語では `revise for an exam` が「試験勉強として復習する」の意味でも使われます。
