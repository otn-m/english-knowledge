# differ — 頻出フレーズ

NGSL順位: 1976

| フレーズ・型 | 意味・使い方 |
|---|---|
| differ from something | 〜と異なる |
| differ from each other | 互いに異なる |
| differ between groups | 集団間で異なる |
| differ among individuals | 個人間で異なる |
| differ in size | 大きさが異なる |
| differ in quality | 品質が異なる |
| differ in degree | 程度が異なる |
| differ in important respects | 重要な点で異なる |
| differ according to something | 〜によって異なる |
| differ depending on something | 〜次第で異なる |
| differ greatly | 大きく異なる |
| differ significantly | 著しく異なる |
| differ considerably | かなり異なる |
| differ substantially | 大幅に異なる |
| differ markedly | 著しく異なる |
| differ sharply | 大きく対立・相違する |
| differ slightly | 少し異なる |
| differ widely | 大きく異なる |
| differ fundamentally | 根本的に異なる |
| opinions differ | 意見が分かれる |
| results differ | 結果が異なる |
| views differ | 見解が異なる |
| tastes differ | 好みは人それぞれである |
| circumstances differ | 状況が異なる |
| may differ | 異なる場合がある |
| tend to differ | 異なる傾向がある |
| appear to differ | 異なるように見える |
| beg to differ | 同意しかねる |
| agree to differ | 意見の相違を認め合う |
| differ over an issue | 問題をめぐって意見が異なる |

## 要点

基本形は `differ from` と `differ in` です。意見の相違には `differ over/on` も使います。
