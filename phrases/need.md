# need — 頻出フレーズ

NGSL順位: 90

| フレーズ・型 | 意味・使い方 |
|---|---|
| need something | ～が必要である |
| need to do | ～する必要がある |
| need someone to do | （人）に～してもらう必要がある |
| need doing | ～される必要がある（主にイギリス英語） |
| need to be done | ～される必要がある |
| really need | 本当に必要とする |
| still need | まだ必要とする |
| just need | ただ～する必要がある |
| only need to do | ～しさえすればよい |
| may need to do | ～する必要があるかもしれない |
| will need to do | ～する必要が生じる |
| no need to do | ～する必要はない |
| don't need to do | ～する必要はない |
| need not do | ～する必要はない（やや硬い） |
| need not have done | ～する必要はなかったのにした |
| need help | 助けが必要である |
| need more time | もっと時間が必要である |
| need information | 情報が必要である |
| need attention | 注意・対応を必要とする |
| need support | 支援を必要とする |
| need a break | 休憩が必要である |
| need a hand | 手助けが必要である |
| in need | 困窮して／必要として |
| in need of | ～を必要として |
| meet a need | ニーズを満たす |
| meet the needs of | ～のニーズに応える |
| feel the need to do | ～する必要を感じる |
| have everything one needs | 必要なものがすべてある |
| as needed | 必要に応じて |
| if needed | 必要なら |
| when needed | 必要なときに |
| What do you need? | 何が必要ですか |
| Do you need help? | 手伝いが必要ですか |
| All you need to do is ... | ～しさえすればよい |
| There's no need to worry. | 心配する必要はありません |

## 要点

`don't need to` は「不要」。`mustn't` の「禁止」とは異なる。
