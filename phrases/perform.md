# perform — 頻出フレーズ

NGSL順位: 935

| フレーズ・型 | 意味・使い方 |
|---|---|
| perform a task | 作業を行う |
| perform a function | 機能を果たす |
| perform a role | 役割を果たす |
| perform a duty | 職務を遂行する |
| perform an operation | 手術・操作を行う |
| perform surgery | 手術を行う |
| perform a test | 検査を行う |
| perform an experiment | 実験を行う |
| perform an analysis | 分析を行う |
| perform a check | 点検を行う |
| perform a service | サービスを提供する |
| perform an action | 動作を実行する |
| perform well | よい成果を上げる |
| perform badly | 成績・業績が悪い |
| perform better | よりよい成果を上げる |
| perform poorly | うまく機能しない／成績が悪い |
| perform consistently | 安定した成果を上げる |
| perform effectively | 効果的に機能する |
| perform as expected | 期待どおりに機能する |
| perform under pressure | プレッシャーの中で力を発揮する |
| perform live | ライブで演奏・演技する |
| perform on stage | 舞台で演じる |
| perform in public | 人前で演じる |
| perform a song | 歌を演奏・歌唱する |
| perform a dance | 踊りを披露する |
| perform a concert | コンサートで演奏する |
| perform for an audience | 観客のために演じる |
| be performed by ... | …によって演じられる／実施される |
| high-performing teams | 高い成果を上げるチーム |
| outperform the market | 市場平均を上回る |
| perform to a high standard | 高い水準で実行する |
| perform the same way | 同じように機能する |

## 要点

作業には `perform a task/test/function`、成果には `perform well/poorly`、舞台には `perform live/on stage` を使います。
