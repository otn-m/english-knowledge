# finish — 頻出フレーズ

NGSL順位: 609

| フレーズ・型 | 意味・使い方 |
|---|---|
| finish ... | …を終える |
| finish doing ... | …し終える |
| finish work | 仕事を終える |
| finish school | 学校を卒業する、授業を終える |
| finish a task | 作業を終える |
| finish a project | プロジェクトを終える |
| finish a book | 本を読み終える |
| finish a meal | 食事を終える |
| finish your homework | 宿題を終える |
| finish the job | 仕事を完遂する |
| finish on time | 時間どおりに終える |
| finish early | 早く終える |
| finish late | 遅く終える |
| finish first | 1位で終える |
| finish second | 2位で終える |
| finish with ... | …で締めくくる |
| finish by doing ... | …して締めくくる |
| finish in ... minutes | …分で終える |
| be nearly finished | ほぼ終わっている |
| be completely finished | 完全に終わっている |
| have finished | 終えた |
| wait for ... to finish | …が終わるのを待つ |
| let someone finish | 人に最後まで話させる |
| finish off ... | …を完全に終える、食べきる |
| finish up | 終える、片づける |
| finish up with ... | …で締めくくる |
| finish line | ゴールライン |
| from start to finish | 最初から最後まで |
| a strong finish | 力強い締めくくり |
| a close finish | 接戦のゴール |
| a smooth finish | 滑らかな仕上げ |
| add the finishing touches | 最後の仕上げをする |
| finish what you started | 始めたことを最後までやる |
| a fight to the finish | 決着がつくまでの戦い |

## 要点

動作を続けるときは `finish doing ...` とし、`finish to do` とはしません。`from start to finish` も頻出です。
