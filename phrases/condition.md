# condition — 頻出フレーズ

| フレーズ・型 | 意味・使い方 |
|---|---|
| in good condition | 良好な状態で |
| in poor condition | 状態が悪く |
| in perfect condition | 完璧な状態で |
| in excellent condition | 非常に良い状態で |
| in working condition | 使用可能な状態で |
| improve one's condition | 状態を改善する |
| remain in stable condition | 安定した状態を保つ |
| a medical condition | 疾患 |
| a health condition | 健康状態・疾患 |
| a heart condition | 心臓疾患 |

| physical condition | 体調 |

## 要点

状態・病状・環境条件・契約条件を表す。状態には `in ... condition`、条件には `on condition that`。
