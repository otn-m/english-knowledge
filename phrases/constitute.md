# constitute — 頻出フレーズ

NGSL順位: 2357

| フレーズ・型 | 意味・使い方 |
|---|---|
| constitute a majority | 過半数を構成する |
| constitute a minority | 少数派を構成する |
| constitute a large proportion | 大きな割合を占める |
| constitute a small percentage | 小さな割合を占める |
| constitute the main part | 主要部分を構成する |
| constitute an important element | 重要な要素を構成する |
| constitute the basis of ... | ～の基礎を成す |
| constitute evidence | 証拠となる |
| constitute proof | 証明となる |
| constitute a threat | 脅威となる |
| constitute a risk | リスクとなる |
| constitute a danger | 危険となる |
| constitute a challenge | 課題となる |
| constitute a problem | 問題となる |
| constitute an obstacle | 障害となる |
| constitute a violation | 違反となる |
| constitute an offense | 犯罪・違反となる |
| constitute a crime | 犯罪を構成する |
| constitute discrimination | 差別に当たる |
| constitute a breach of contract | 契約違反となる |
| constitute grounds for dismissal | 解雇理由となる |
| constitute a significant change | 大きな変化に当たる |
| constitute an improvement | 改善となる |
| constitute an alternative | 代替案となる |
| constitute recognition of ... | ～を認めることになる |
| legally constitute | 法的に構成する・該当する |
| may constitute ... | ～に当たる可能性がある |
| do not constitute ... | ～には当たらない |
| be constituted by ... | ～によって構成される |
| constitute themselves as a group | 自ら集団を結成する |

## 要点

複数の要素が全体を「構成する」と、行為や事実が法的・実質的に何かに「当たる」という意味で使います。
