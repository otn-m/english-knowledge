# satisfy — 頻出フレーズ

NGSL順位: 1154

| フレーズ・型 | 意味・使い方 |
|---|---|
| satisfy a need | 必要を満たす |
| satisfy the needs of ... | …のニーズを満たす |
| satisfy demand | 需要を満たす |
| satisfy a requirement | 要件を満たす |
| satisfy the requirements | 必要条件を満たす |
| satisfy the criteria | 基準を満たす |
| satisfy a condition | 条件を満たす |
| satisfy all conditions | すべての条件を満たす |
| satisfy customers | 顧客を満足させる |
| satisfy consumer demand | 消費者需要を満たす |
| satisfy expectations | 期待に応える |
| satisfy someone's curiosity | 人の好奇心を満たす |
| satisfy an appetite | 食欲を満たす |
| satisfy a desire | 欲求を満たす |
| satisfy a craving | 強い欲求を満たす |
| satisfy an obligation | 義務を果たす |
| satisfy a debt | 債務を返済する |
| fully satisfy ... | …を完全に満たす |
| completely satisfy ... | …を完全に満足させる |

| leave someone satisfied | 人を満足させる結果となる |
| difficult to satisfy | 満足させるのが難しい |

## 要点

要求・条件を「満たす」と、人を「満足させる」の二つが中心です。状態を表す場合は `be satisfied with ...` を使います。
