# permit — 頻出フレーズ

NGSL順位: 1589

| フレーズ・型 | 意味・使い方 |
|---|---|
| permit someone to do | 人が～することを許可する |
| permit access | 立ち入り・利用を許可する |
| permit entry | 入場を許可する |
| permit the use of ... | ～の使用を許可する |
| permit construction | 建設を許可する |
| permit smoking | 喫煙を許可する |
| permit development | 開発を許可する |
| if circumstances permit | 状況が許せば |
| if time permits | 時間が許せば |
| weather permitting | 天気がよければ |
| be permitted to do | ～することを許可される |
| not be permitted | 許可されない |
| legally permitted | 法的に許可された |
| expressly permitted | 明示的に許可された |
| a building permit | 建築許可証 |
| a work permit | 就労許可証 |
| a parking permit | 駐車許可証 |
| an entry permit | 入国・入場許可証 |
| a residence permit | 居住許可証 |
| a travel permit | 旅行許可証 |
| an export permit | 輸出許可証 |
| a special permit | 特別許可証 |
| apply for a permit | 許可証を申請する |
| obtain a permit | 許可証を取得する |
| get a permit | 許可証を得る |
| issue a permit | 許可証を発行する |
| grant a permit | 許可を与える |
| renew a permit | 許可証を更新する |
| revoke a permit | 許可を取り消す |
| without a permit | 許可証なしで |
| permit holder | 許可証保有者 |

## 要点

動詞は `permit someone to do` で、`allow` より改まった表現。名詞は各種許可証を表し、名詞と動詞で強勢位置が異なる。
