# affect — 頻出フレーズ

NGSL順位: 639

| フレーズ・型 | 意味・使い方 |
|---|---|
| affect someone | 人に影響を与える |
| affect people | 人々に影響を与える |
| affect children | 子どもに影響を与える |
| affect the economy | 経済に影響を与える |
| affect the environment | 環境に影響を与える |
| affect health | 健康に影響する |
| affect performance | 成績・性能に影響する |
| affect behavior | 行動に影響する |
| affect development | 発達・発展に影響する |
| affect growth | 成長に影響する |
| affect the outcome | 結果に影響する |
| affect the results | 結果に影響する |

| affect the ability to do ... | …する能力に影響する |

| affect how ... | どのように…するかに影響する |

| affect your daily life | 日常生活に影響する |

## 要点

`affect` は通常動詞で「影響を与える」、`effect` は通常名詞で「影響・効果」です。`affect ...` には前置詞を挟みません。
