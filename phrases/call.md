| フレーズ・型 | 意味・使い方 |
|---|---|

| call a doctor | 医者を呼ぶ |
| call the police | 警察を呼ぶ |
| call for help | 助けを求める |
| call by name | 名前で呼ぶ |
| call someone by name | （人）を名前で呼ぶ |
| call someone something | （人）を～と呼ぶ |
| be called | ～と呼ばれる |
| be called after | ～にちなんで名づけられる |
| call back | 電話をかけ直す |
| call in | 電話を入れる／呼び入れる |
| call off | 中止する |

| call out | 大声で呼ぶ／出動を要請する |
| call up | 電話する／思い出させる |
| call for | ～を必要とする／要求する |
| call attention to | ～に注意を向ける |

## 要点

`call someone` は `to` を使わない。「（人）に電話する」は `call to someone` ではない。
