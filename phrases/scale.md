|---|---|

| on a small scale | 小規模に |
| on a global scale | 世界規模で |
| on a national scale | 全国規模で |
| on a local scale | 地域規模で |
| on an industrial scale | 産業規模で |
| on an unprecedented scale | 前例のない規模で |
| the scale of ... | …の規模 |
| the full scale of ... | …の全容・全規模 |
| a large-scale project | 大規模プロジェクト |

## 要点

規模・尺度・縮尺・目盛りを表すほか、動詞の `scale up/down` で規模の拡大・縮小を表します。`on a ... scale` は頻出の型です。
