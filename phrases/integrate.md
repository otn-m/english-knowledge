# integrate — 頻出フレーズ

NGSL順位: 1955

| フレーズ・型 | 意味・使い方 |
|---|---|
| integrate A into B | AをBに組み込む |
| integrate A with B | AをBと統合する |
| integrate technology into teaching | 技術を授業に取り入れる |
| integrate a system | システムを統合する |
| integrate services | サービスを統合する |
| integrate operations | 業務を統合する |
| integrate data | データを統合する |
| integrate information | 情報を統合する |
| integrate different approaches | 異なる手法を統合する |
| integrate multiple functions | 複数機能を統合する |
| integrate theory and practice | 理論と実践を統合する |
| integrate work and family life | 仕事と家庭生活を調和させる |
| fully integrate something | 〜を完全に統合する |
| successfully integrate something | 〜をうまく統合する |
| seamlessly integrate something | 〜を継ぎ目なく統合する |
| be integrated into something | 〜に組み込まれる |
| be closely integrated | 密接に統合されている |
| become integrated | 統合される |
| integrate into society | 社会に溶け込む |
| integrate into a community | 地域社会に溶け込む |
| integrate with a group | 集団に溶け込む |
| help someone integrate | 人が溶け込むのを助ける |
| socially integrate | 社会的に統合する |
| economically integrate | 経済的に統合する |
| integrate schools | 学校の人種隔離を撤廃する |
| integrate the workforce | 職場の人種隔離を撤廃する |
| integrate an equation | 方程式を積分する |
| integrate over an interval | 区間で積分する |
| vertically integrate | 垂直統合する |
| horizontally integrate | 水平統合する |

## 要点

複数要素を「統合する」、人が社会に「溶け込む」、数学で「積分する」を表します。
