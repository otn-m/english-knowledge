# due — 頻出フレーズ

NGSL順位: 574

| フレーズ・型 | 意味・使い方 |
|---|---|
| due to ... | …が原因で、…のために |
| largely due to ... | 主に…が原因で |
| partly due to ... | 一部は…が原因で |
| mainly due to ... | 主に…が原因で |
| be due to ... | …によるものである |
| be due on Monday | 月曜日が期限である |
| be due tomorrow | 明日が期限である |
| be due next week | 来週が期限である |
| be due by ... | …までが期限である |
| payment is due | 支払い期限が来ている |
| payment due | 支払期日、支払うべき金額 |
| the due date | 期日、出産予定日 |
| before the due date | 期日前に |
| after the due date | 期日後に |
| past due | 期限を過ぎた |
| become due | 期限が来る |
| fall due | 支払期限が来る |
| be due for ... | …の予定である、…を受ける時期である |
| be due for release | 発売・公開予定である |
| be due for completion | 完成予定である |
| be due for an update | 更新が必要な時期である |
| be due for a checkup | 健診を受ける時期である |
| be due to do ... | …する予定である |
| be due to arrive | 到着予定である |
| be due to start | 開始予定である |
| be due to leave | 出発予定である |
| be due back | 戻る予定である |
| be due in May | 5月に出産予定である |
| give someone their due | 人を正当に評価する |
| with all due respect | 失礼ながら |
| in due course | やがて、しかるべき時に |
| due process | 適正な法的手続き |
| due care | 相当な注意 |
| due attention | 当然払うべき注意 |
| due consideration | 十分な検討 |

## 要点

原因の `due to ...`、期限の `be due ...`、予定の `be due to do ...` は意味が異なるので、型ごと覚えるのが安全です。
