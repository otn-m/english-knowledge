# beyond — 頻出フレーズ

NGSL順位: 826

| フレーズ・型 | 意味・使い方 |
|---|---|
| beyond ... | …を越えて |
| beyond the border | 国境の向こうに |
| beyond the city | 市の向こうに |
| beyond the horizon | 地平線の向こうに |
| beyond the age of ... | …歳を越えて |
| beyond the end of ... | …の終わりを越えて |
| beyond this point | この地点より先に |
| beyond a certain point | ある地点・程度を越えて |
| beyond the limit | 限界を超えて |
| beyond your control | 自分ではどうにもできない |
| beyond your reach | 手の届かない |
| beyond your ability | 自分の能力を超えて |
| beyond recognition | 見分けがつかないほど |
| beyond repair | 修理不能で |
| beyond recovery | 回復不能で |
| beyond doubt | 疑いの余地なく |
| beyond question | 疑いの余地なく |
| beyond belief | 信じられないほど |
| beyond description | 言葉で表せないほど |
| beyond comparison | 比べものにならないほど |
| beyond expectations | 期待を超えて |
| beyond reasonable doubt | 合理的疑いの余地なく |
| go beyond ... | …を超える |
| extend beyond ... | …を越えて広がる |
| look beyond ... | …の先・表面を見る |
| move beyond ... | …を乗り越えて先へ進む |
| reach beyond ... | …を越えて届く |
| far beyond ... | …をはるかに超えて |
| well beyond ... | …を大きく超えて |
| beyond what ... | …する範囲を超えて |
| beyond that | それ以上に、それ以外に |
| above and beyond | 期待・義務を超えて |
| the great beyond | あの世 |
| beyond words | 言葉では言い表せない |

## 要点

場所・限度を「越えて」を表します。`beyond your control/repair/doubt` と `go beyond ...` が特に頻出です。
