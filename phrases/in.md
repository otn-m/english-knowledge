# in — 頻出フレーズ

NGSL順位: 7

場所や時間の基本用法に加え、会話・文章を組み立てる定型句と、日常的な状態表現を優先した。

| フレーズ・型 | 意味・使い方 |
|---|---|
| in fact | 実際には／それどころか |
| in general | 一般に |
| in particular | 特に |
| in advance | 前もって |
| in case | 万一に備えて／～の場合には |
| in time | 間に合って／やがて |
| in the future | 将来 |
| in the past | 過去に |
| in the end | 最終的に |
| in the beginning | 初めのうちは |
| in the middle of | ～の途中・真ん中で |
| in the morning | 朝に |
| in the afternoon | 午後に |
| in the evening | 夕方・夜に |
| in the world | 世界で／一体全体 |
| in a way | ある意味では |
| in a sense | ある意味では |
| in other words | 言い換えると |
| in my opinion | 私の意見では |
| in detail | 詳細に |
| in practice | 実際には |
| in theory | 理論上は |
| in person | 直接会って |
| in public | 人前で／公に |
| in private | 内密に／二人きりで |
| in common | 共通して |
| in charge of | ～を担当して |
| in control of | ～を管理して |
| in danger | 危険な状態で |
| in trouble | 困って／問題を抱えて |
| in love with | ～に恋をして |
| in favor of | ～に賛成して |
| in front of | ～の前に |
| in spite of | ～にもかかわらず |
| in terms of | ～の点で／～に関して |
| in order to do | ～するために |
| be interested in | ～に興味がある |
| take part in | ～に参加する |

## 要点

- `in time` は「手遅れになる前に」、`on time` は「予定時刻どおりに」。
- 朝・午後・夕方は `in` だが、夜は通常 `at night`。
- `in the end` は「最終的に」、`at the end of ...` は「～の終わりに」。
