# each — 頻出フレーズ

NGSL順位: 145

| フレーズ・型 | 意味・使い方 |
|---|---|
| each of ... | …のそれぞれ |
| each of us | 私たち一人ひとり |
| each of them | それら・彼らのそれぞれ |
| each person | 一人ひとり |
| each student | 各学生 |
| each member | 各メンバー |
| each country | 各国 |
| each time | その都度・毎回 |
| each day | 毎日・一日ごとに |
| each week | 毎週 |
| each year | 毎年 |
| each morning | 毎朝 |
| each side | それぞれの側 |
| each end | 両方の端のそれぞれ |
| each case | それぞれの場合 |
| each type | それぞれの種類 |
| each other | お互いに |
| see each other | お互いに会う |
| help each other | 助け合う |
| know each other | お互いを知っている |
| talk to each other | お互いに話す |
| work with each other | 互いに協力して働く |
| different from each other | 互いに異なる |
| close to each other | 互いに近い |
| one on each side | 両側に一つずつ |
| two of each | それぞれ二つずつ |
| for each ... | …一つ・一人につき |
| in each case | それぞれの場合に |
| at each stage | 各段階で |
| from each other | お互いから |
| each and every ... | どの…も一つ残らず |
| each to their own | 人それぞれ・好みは人それぞれ |

## 要点

集団の構成員を一つずつ個別に捉えます。`each of + 複数形` の後の動詞は原則単数形で、`each other` は「互いに」です。
