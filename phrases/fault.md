# fault — 頻出フレーズ

NGSL順位: 1995

| フレーズ・型 | 意味・使い方 |
|---|---|
| be someone's fault | 人のせいである |
| It's my fault. | 私のせいです |
| It's not your fault. | あなたのせいではありません |
| whose fault | 誰のせい |
| find fault with someone | 人のあら探しをする |
| find fault with something | 〜の欠点を指摘する |
| admit fault | 非を認める |
| accept fault | 責任を認める |
| deny fault | 責任を否定する |
| assign fault | 責任の所在を決める |
| be at fault | 責任がある |
| be partly at fault | 一部責任がある |
| through no fault of your own | 自分には何の落ち度もなく |
| no-fault insurance | 無過失保険 |
| a serious fault | 重大な欠点 |
| a major fault | 大きな欠点 |
| a minor fault | 小さな欠点 |
| a common fault | よくある欠点 |
| a technical fault | 技術的故障 |
| an electrical fault | 電気系統の故障 |
| a mechanical fault | 機械的故障 |
| develop a fault | 故障が生じる |
| detect a fault | 故障を検出する |
| repair a fault | 故障を修理する |
| a fault in the system | システムの欠陥 |
| a fault line | 断層線 |
| an earthquake fault | 地震断層 |
| to a fault | 過度なほど |
| generous to a fault | 気前が良すぎる |
| faults and weaknesses | 欠点と弱点 |

## 要点

責任としての「せい」、物や性格の「欠点・故障」、地質の「断層」を表します。
