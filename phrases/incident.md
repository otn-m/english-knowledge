| フレーズ・型 | 意味・使い方 |
|---|---|
| a serious incident | 重大事件 |
| a major incident | 大事件 |
| a minor incident | 小さな出来事 |
| a violent incident | 暴力事件 |
| a shooting incident | 発砲事件 |
| a security incident | セキュリティー事件 |
| a terrorist incident | テロ事件 |
| a diplomatic incident | 外交問題 |
| an international incident | 国際問題 |
| a border incident | 国境での事件 |
| a traffic incident | 交通上の事故・事件 |
| a workplace incident | 職場での事故・出来事 |
| an isolated incident | 単発の事件 |
| a similar incident | 類似事件 |
| a previous incident | 過去の事件 |
| the latest incident | 最新の事件 |
| report an incident | 事件を報告する |
| investigate an incident | 事件を調査する |

| recall the incident | 事件を思い出す |

| an incident occurs | 事件が起こる |
| an incident involving someone | 人が関わる事件 |
| an incident at a school | 学校での事件 |
| details of the incident | 事件の詳細 |
| the scene of the incident | 事件現場 |
| without incident | 何事もなく |
| incident report | 事故・事件報告書 |

## 要点

注目を要する「出来事・事件」を指します。`without incident` は「問題なく」の定型表現です。
