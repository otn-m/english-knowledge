# versus — 頻出フレーズ

NGSL順位: 2482

| フレーズ・型 | 意味・使い方 |
|---|---|
| A versus B | A対B・AとBの比較 |
| one team versus another | 一方のチーム対もう一方のチーム |
| the final is Brazil versus Spain | 決勝はブラジル対スペインだ |
| home team versus away team | ホームチーム対アウェーチーム |
| individual versus team competition | 個人競技対団体競技 |
| nature versus nurture | 遺伝か環境か |
| theory versus practice | 理論対実践 |
| quality versus quantity | 質か量か |
| cost versus benefit | 費用対効果 |
| risk versus reward | リスク対リターン |
| supply versus demand | 供給と需要の対比 |
| public versus private | 公的か私的か |
| local versus global | 地域的か世界的か |
| online versus offline | オンライン対オフライン |
| old versus new | 古いもの対新しいもの |
| short-term versus long-term | 短期対長期 |
| men versus women | 男性と女性の比較 |
| urban versus rural | 都市部対農村部 |
| human versus machine | 人間対機械 |
| freedom versus security | 自由か安全か |
| needs versus wants | 必要なものと欲しいもの |
| perception versus reality | 認識と現実の違い |
| fact versus opinion | 事実と意見の違い |
| style versus substance | 見た目か中身か |
| us versus them | 身内対よそ者という構図 |
| versus the previous year | 前年と比較して |
| versus expectations | 予想と比較して |
| actual versus planned costs | 実際の費用対計画費用 |
| price versus performance | 価格対性能 |
| case A versus case B | A事件対B事件 |

## 要点

競技・訴訟の「～対～」と、二つの選択肢・数値を「比較して」を表します。略記は `vs.` または `v.` です。
