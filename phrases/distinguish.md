# distinguish — 頻出フレーズ

NGSL順位: 1893

| フレーズ・型 | 意味・使い方 |
|---|---|
| distinguish between A and B | AとBを区別する |
| distinguish A from B | AをBと区別する |
| clearly distinguish something | 〜を明確に区別する |
| carefully distinguish something | 〜を慎重に区別する |
| easily distinguish something | 〜を容易に見分ける |
| be difficult to distinguish | 区別が難しい |
| be easy to distinguish | 区別しやすい |
| distinguish fact from fiction | 事実と虚構を区別する |
| distinguish right from wrong | 善悪を区別する |
| distinguish cause from effect | 原因と結果を区別する |
| distinguish one thing from another | ある物を別の物と区別する |
| distinguish different types | 異なる種類を見分ける |
| distinguish sounds | 音を聞き分ける |
| distinguish colors | 色を見分ける |
| distinguish a pattern | パターンを識別する |
| distinguish a voice | 声を聞き分ける |
| distinguish a figure in the dark | 暗闇で人影を見分ける |
| features distinguish A from B | 特徴がAをBと区別する |
| what distinguishes A from B | AとBを分けるもの |
| distinguish yourself | 頭角を現す |
| distinguish yourself as something | 〜として名を上げる |
| distinguish yourself by doing something | 〜して頭角を現す |
| a distinguished career | 輝かしい経歴 |
| a distinguished professor | 著名な教授 |
| a distinguished guest | 著名な来賓 |
| a distinguished scientist | 著名な科学者 |
| a distinguished record | 輝かしい実績 |
| become distinguished | 著名になる |
| clearly distinguished | 明確に区別された |
| sharply distinguish between ... | …をはっきり区別する |

## 要点

基本形は `distinguish between A and B` または `distinguish A from B` です。再帰形では「頭角を現す」です。
