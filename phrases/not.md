# not — 頻出フレーズ

NGSL順位: 14

単純な否定だけでなく、返答、程度の調整、対比、婉曲表現として頻出する `not` のまとまりを選んだ。

| フレーズ・型 | 意味・使い方 |
|---|---|
| not at all | まったく～ない／どういたしまして |
| not really | あまり～ない／そうでもない |
| not quite | 完全には～ない／今一歩で |
| not yet | まだ～ない |
| not anymore / not any more | もう～ない |
| not necessarily | 必ずしも～ではない |
| not exactly | 正確には～でない／そういうわけでもない |
| not even | ～さえ…ない |
| not very | あまり～でない |
| not much | あまり多くない |
| not many | あまり多くない |
| not enough to do | ～するには十分でない |
| not as ... as | ～ほど…ではない |
| not only A but also B | AだけでなくBも |
| not so much A as B | AというよりむしろB |
| not A but B | AではなくB |
| not too bad | それほど悪くない／まあまあ良い |
| not bad | 悪くない／かなり良い |
| not a chance | 絶対に無理／あり得ない |
| not a problem | 問題ありません |
| not my thing | 自分の好み・得意分野ではない |
| not worth it | その価値がない |
| not be sure | 確信がない／分からない |
| not be able to do | ～することができない |
| not have to do | ～する必要はない |
| must not do | ～してはいけない |
| had better not do | ～しないほうがよい |
| try not to do | ～しないようにする |
| prefer not to do | できれば～したくない |
| why not? | なぜだめなの？／いいですね |
| if not | もしそうでなければ |
| or not | ～かどうか／それとも違うのか |
| I hope not | そうでないことを願う |
| I'm afraid not | 残念ながら違います／できません |
| believe it or not | 信じられないかもしれないが |
| last but not least | 最後だが決して重要でないわけではなく |
| not to mention | ～は言うまでもなく |
| not until | ～になって初めて |
| not long ago | 少し前に |
| not in the least | 少しも～ない |

## 要点

- `not have to` は「不要」、`must not` は「禁止」。意味が大きく違う。
- `not really` は直接的な `no` を和らげる返答として非常によく使われる。
- `not until` を文頭に置く硬い表現では倒置が起こる。例: `Not until later did I understand.`
