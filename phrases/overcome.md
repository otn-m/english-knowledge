# overcome — 頻出フレーズ

NGSL順位: 2222

| フレーズ・型 | 意味・使い方 |
|---|---|
| overcome a problem | 問題を克服する |
| overcome a difficulty | 困難を克服する |
| overcome an obstacle | 障害を乗り越える |
| overcome a challenge | 課題を乗り越える |
| overcome a barrier | 障壁を乗り越える |
| overcome resistance | 抵抗を克服する |
| overcome opposition | 反対を乗り越える |
| overcome fear | 恐怖を克服する |
| overcome anxiety | 不安を克服する |
| overcome depression | うつ状態を克服する |
| overcome addiction | 依存症を克服する |
| overcome prejudice | 偏見を克服する |
| overcome poverty | 貧困を克服する |
| overcome limitations | 限界を乗り越える |
| overcome differences | 相違を乗り越える |
| successfully overcome something | 〜をうまく克服する |
| eventually overcome something | 最終的に〜を克服する |
| struggle to overcome something | 〜を克服しようと苦闘する |
| help someone overcome something | 人が〜を克服するのを助ける |
| be difficult to overcome | 克服するのが難しい |
| be overcome by emotion | 感情に圧倒される |
| be overcome with grief | 悲しみに打ちひしがれる |
| be overcome with joy | 喜びで胸がいっぱいになる |
| be overcome with fear | 恐怖に襲われる |
| be overcome by smoke | 煙に巻かれる |
| overcome the odds | 不利な状況を乗り越える |
| overcome all doubts | あらゆる疑念を払拭する |
| an obstacle to overcome | 克服すべき障害 |
| impossible to overcome | 克服不可能な |
| determination to overcome | 克服しようとする決意 |

## 要点

困難・恐怖などを「克服する」と、受動態で感情・煙などに「圧倒される」を表します。
