# characterize — 頻出フレーズ

NGSL順位: 2325

| フレーズ・型 | 意味・使い方 |
|---|---|
| characterize A as B | AをBだと評する |
| be characterized as ... | ～であると評される |
| characterize the problem as serious | 問題を深刻だと評する |
| characterize the move as necessary | その措置を必要だと評する |
| characterize the remarks as unfair | 発言を不当だと評する |
| characterize the event as historic | 出来事を歴史的だと評する |
| characterize the relationship as close | 関係を緊密だと評する |
| characterize the situation as dangerous | 状況を危険だと評する |
| characterize the decision as a mistake | 決定を誤りだと評する |
| characterize the attack as terrorism | 攻撃をテロだと位置づける |
| accurately characterize | 正確に特徴づける |
| broadly characterize | 大まかに特徴づける |
| generally characterize | 一般的に特徴づける |
| wrongly characterize | 誤って特徴づける |
| unfairly characterize | 不当に評する |
| best characterize | 最もよく特徴を表す |
| characterize a person | 人の特徴を述べる |
| characterize a society | 社会を特徴づける |
| characterize an era | 時代を特徴づける |
| characterize a style | 様式の特徴を示す |
| characterize the nature of ... | ～の性質を明らかにする |
| characterize the behavior of ... | ～の挙動を明らかにする |
| characterize the structure of ... | ～の構造を解析する |
| characterize the effects of ... | ～の影響の特徴を明らかにする |
| characterize the sample | 試料の特性を調べる |

| be characterized by diversity | 多様性を特徴とする |
| be characterized by uncertainty | 不確実性を特徴とする |

| be characterized by a lack of ... | ～の欠如を特徴とする |

## 要点

`characterize A as B` はAをBと「評する」、`A is characterized by B` はAがBを「特徴とする」という重要な型です。
