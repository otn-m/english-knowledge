# consider — 頻出フレーズ

NGSL順位: 295

| フレーズ・型 | 意味・使い方 |
|---|---|
| consider the options | 選択肢を検討する |
| consider the evidence | 証拠を検討する |
| consider the facts | 事実を考慮する |
| consider the possibility | 可能性を検討する |
| consider the consequences | 結果を考慮する |
| consider the impact | 影響を考慮する |
| consider the needs of ... | ～の必要性を考慮する |
| consider all aspects | あらゆる側面を考慮する |
| carefully consider | 慎重に検討する |
| seriously consider | 真剣に検討する |
| consider doing ... | ～することを検討する |
| consider changing ... | ～を変えることを検討する |
| consider whether ... | ～かどうか検討する |
| consider how ... | どう～するか検討する |
| consider what ... | 何を～するか考える |
| consider it necessary | それを必要と考える |
| consider it important | それを重要と考える |
| consider someone a friend | 人を友人だと考える |
| consider something a success | ～を成功だと考える |
| consider A to be B | AをBと見なす |
| be considered to be ... | ～であると考えられる |
| be widely considered ... | 広く～と考えられる |
| be generally considered ... | 一般に～と考えられる |
| be considered as ... | ～として考慮される |
| take something into consideration | ～を考慮に入れる |
| all things considered | すべてを考慮すると |
| consider the source | 情報源を考慮する |
| consider one's position | 自分の立場を検討する |
| consider a proposal | 提案を検討する |
| consider an application | 申請を審査する |
| consider a request | 要請を検討する |
| consider an alternative | 代替案を検討する |
| consider oneself lucky | 自分は幸運だと思う |
| consider it done | 引き受けた／任せてほしい |

## 要点

`consider doing` は使うが `consider to do` は使わない。「AをBと見なす」は `consider A (to be) B`。
