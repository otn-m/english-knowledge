NGSL順位: 457

| フレーズ・型 | 意味・使い方 |
|---|---|

| describe a place | 場所を描写する |
| describe a situation | 状況を説明する |
| describe a process | 過程を説明する |
| describe an experience | 経験を語る |
| describe an event | 出来事を説明する |
| describe a problem | 問題を説明する |
| describe the results | 結果を説明する |
| describe the relationship | 関係を説明する |
| describe the difference | 違いを説明する |
| describe in detail | 詳細に説明する |
| briefly describe | 簡潔に説明する |
| clearly describe | 明確に説明する |
| accurately describe | 正確に描写する |
| fully describe | 十分に説明する |
| describe how ... | どのように～かを説明する |
| describe what ... | 何が～かを説明する |
| describe why ... | なぜ～かを説明する |
| describe someone as ... | 人を～と評する |
| describe something as ... | ～を…と表現する |
| be described as ... | ～と評される |
| be best described as ... | ～と表現するのが最も適切である |
| be widely described as ... | 広く～と評される |
| words cannot describe ... | 言葉では表せない |

| as described above | 上述のとおり |

| describe the scene | その場面を描写する |

| describe the nature of ... | ～の性質を説明する |
| describe the role of ... | ～の役割を説明する |

## 要点

「AをBと表現する」は `describe A as B`。`describe about` とはせず、対象を直接目的語に取る。
