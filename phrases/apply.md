# apply — 頻出フレーズ

NGSL順位: 611

| フレーズ・型 | 意味・使い方 |
|---|---|
| apply for ... | …に応募・申請する |
| apply for a job | 仕事に応募する |
| apply for a visa | ビザを申請する |
| apply for a loan | ローンを申し込む |
| apply for admission | 入学を申請する |
| apply to ... | …に応募する、…に当てはまる |
| apply to a university | 大学に出願する |
| apply to do ... | …することを申請する |
| apply online | オンラインで申請する |
| apply in person | 本人が直接申請する |
| apply by mail | 郵送で申請する |
| apply before ... | …より前に申請する |
| apply ... to ... | …を…に適用する、塗る |
| apply a rule to ... | 規則を…に適用する |
| apply the law | 法律を適用する |
| apply a method | 方法を適用する |
| apply a principle | 原則を適用する |
| apply knowledge | 知識を応用する |
| apply pressure | 圧力をかける |
| apply force | 力を加える |
| apply heat | 熱を加える |
| apply for funding | 資金を申請する |
| apply makeup | 化粧をする |
| apply sunscreen | 日焼け止めを塗る |
| apply directly to the skin | 皮膚に直接塗る |
| the rule applies | その規則が適用される |
| apply to everyone | 全員に当てはまる |
| apply equally to ... | …に等しく適用される |
| apply in this case | この場合に当てはまる |
| apply only to ... | …にのみ適用される |
| apply broadly | 広く適用される |
| conditions apply | 条件が適用される |
| restrictions apply | 制限が適用される |
| apply yourself | 熱心に取り組む |
| apply yourself to ... | …に専念する |

## 要点

申請対象には `apply for ...`、申請先には `apply to ...`、適用には `apply ... to ...` を使います。
