# suffer — 頻出フレーズ

NGSL順位: 838

| フレーズ・型 | 意味・使い方 |
|---|---|
| suffer from ... | 病気・問題などに苦しむ |
| suffer from stress | ストレスに苦しむ |
| suffer from anxiety | 不安に悩む |
| suffer from depression | うつ病に苦しむ |
| suffer from headaches | 頭痛に悩む |
| suffer from a disease | 病気を患う |
| suffer from a lack of ... | …の不足に悩む |
| suffer from poor health | 健康状態が悪い |
| suffer pain | 痛みに苦しむ |
| suffer severe pain | 激しい痛みに苦しむ |
| suffer an injury | けがを負う |
| suffer serious injuries | 重傷を負う |
| suffer a heart attack | 心臓発作を起こす |
| suffer a stroke | 脳卒中を起こす |
| suffer brain damage | 脳に損傷を受ける |
| suffer damage | 損害を受ける |
| suffer heavy damage | 大きな被害を受ける |
| suffer a loss | 損失を被る |
| suffer heavy losses | 大きな損失を被る |
| suffer a defeat | 敗北を喫する |
| suffer a setback | 挫折・後退を経験する |
| suffer the consequences | 結果の責任を負う／報いを受ける |
| suffer in silence | 黙って苦しむ |
| suffer badly | ひどく苦しむ／大きな被害を受ける |
| suffer greatly | 大いに苦しむ |
| suffer unnecessarily | 不必要に苦しむ |
| make someone suffer | 人を苦しませる |
| continue to suffer | 苦しみ続ける |
| suffer as a result | その結果、損害を受ける |
| the economy suffers | 経済が打撃を受ける |
| performance suffers | 性能・業績が低下する |
| quality suffers | 品質が低下する |
| suffer for your mistakes | 自分の過ちの報いを受ける |

## 要点

病気や問題には `suffer from ...`、けが・損失・敗北には `suffer an injury/a loss/a defeat` の形がよく使われます。
