NGSL順位: 1204

| フレーズ・型 | 意味・使い方 |
|---|---|
| meet a requirement | 要件を満たす |
| meet the requirements | 必要条件を満たす |
| satisfy a requirement | 要件を満たす |
| fulfill a requirement | 要件を履行する |
| comply with a requirement | 要件を順守する |
| a legal requirement | 法的要件 |
| a regulatory requirement | 規制上の要件 |
| a statutory requirement | 法令上の要件 |
| a technical requirement | 技術要件 |
| a safety requirement | 安全要件 |
| a minimum requirement | 最低要件 |
| a basic requirement | 基本要件 |
| an essential requirement | 必須要件 |
| a specific requirement | 特定の要件 |
| an entry requirement | 入学・入国などの要件 |
| an admission requirement | 入学要件 |

| a requirement for ... | …に対する要件 |

| impose a requirement | 要件を課す |

| change the requirements | 要件を変更する |

| mandatory requirements | 必須要件 |

## 要点

満たすべき条件・必要事項を表します。動詞は `meet/satisfy/fulfill a requirement`、規則への適合は `comply with` がよく使われます。
