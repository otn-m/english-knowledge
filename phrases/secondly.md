# secondly — 頻出フレーズ

NGSL順位: 1946

| フレーズ・型 | 意味・使い方 |
|---|---|
| Firstly ..., secondly ... | 第一に…、第二に… |
| First ..., secondly ... | 第一に…、第二に… |
| Secondly, ... | 第二に… |
| and secondly, ... | そして第二に… |
| but secondly, ... | しかし第二に… |
| secondly, because ... | 第二に、…だから |
| secondly, consider ... | 第二に、…を考えてみよう |
| secondly, examine ... | 第二に、…を検討する |
| secondly, note that ... | 第二に、…に注意する |
| secondly, remember that ... | 第二に、…を覚えておく |
| secondly, we need to ... | 第二に、私たちは…する必要がある |
| secondly, we must ... | 第二に、私たちは…しなければならない |
| secondly, it is important to ... | 第二に、…することが重要だ |
| secondly, there is ... | 第二に、…がある |
| secondly, the study shows ... | 第二に、研究は…を示す |
| secondly, the results suggest ... | 第二に、結果は…を示唆する |
| secondly, this means ... | 第二に、これは…を意味する |
| secondly, this allows ... | 第二に、これにより…が可能になる |
| secondly, this approach ... | 第二に、この方法は… |
| secondly, another factor ... | 第二に、別の要因は… |
| secondly, a further issue ... | 第二に、さらなる問題は… |
| secondly, from a practical perspective ... | 第二に、実務的観点から… |
| secondly, in terms of cost ... | 第二に、費用の点では… |
| secondly, on the other hand ... | 第二に、その一方で… |
| secondly, in addition ... | 第二に、さらに… |
| secondly, by contrast ... | 第二に、対照的に… |
| secondly, and more importantly, ... | 第二に、そしてさらに重要なのは… |
| secondly, the question is ... | 第二に、問題は… |

| secondly, as noted above ... | 第二に、上で述べたように… |

## 要点

論点を順序立てて示す「第二に」です。文章や改まった発表で使い、日常会話では `second` も一般的です。
