# undertake — 頻出フレーズ

NGSL順位: 2036

| フレーズ・型 | 意味・使い方 |
|---|---|
| undertake a task | 任務を引き受ける |
| undertake a project | プロジェクトに着手する |
| undertake a study | 研究を行う |
| undertake research | 研究を行う |
| undertake an investigation | 調査を行う |
| undertake a review | 見直しを行う |
| undertake an assessment | 評価を実施する |
| undertake an analysis | 分析を行う |
| undertake a survey | 調査を実施する |
| undertake a journey | 旅に出る |
| undertake a mission | 任務を引き受ける |
| undertake a major operation | 大規模な作戦・手術を行う |
| undertake work | 作業を請け負う |
| undertake repairs | 修理を行う |
| undertake training | 研修を受ける |
| undertake further study | さらに研究・勉強をする |
| undertake reform | 改革に取り組む |
| undertake measures | 措置を講じる |
| undertake an obligation | 義務を引き受ける |
| undertake responsibility | 責任を引き受ける |
| undertake to do something | 〜すると約束する |
| undertake to provide something | 〜を提供すると約束する |
| undertake to pay | 支払うことを請け合う |
| agree to undertake something | 〜を引き受けることに同意する |
| be willing to undertake something | 〜を進んで引き受ける |
| be required to undertake something | 〜を行うよう求められる |
| be commissioned to undertake something | 〜を行うよう委託される |
| jointly undertake something | 〜を共同で行う |
| successfully undertake something | 〜を無事に成し遂げる |
| undertake on behalf of someone | 人に代わって引き受ける |

## 要点

やや改まった語で、重要な仕事・調査・責任を「引き受けて実行する」、または `undertake to do` で「〜すると約束する」です。
