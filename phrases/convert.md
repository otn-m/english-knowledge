# convert — 頻出フレーズ

NGSL順位: 2110

| フレーズ・型 | 意味・使い方 |
|---|---|
| convert A into B | AをBに変換する |
| convert A to B | AをBに変換する |
| convert data | データを変換する |
| convert a file | ファイル形式を変換する |
| convert a document to PDF | 文書をPDFに変換する |
| convert video to audio | 動画を音声に変換する |
| convert dollars into euros | ドルをユーロに換える |
| convert currency | 通貨を換算する |
| convert units | 単位を換算する |
| convert miles to kilometers | マイルをキロに換算する |
| convert energy | エネルギーを変換する |
| convert heat into electricity | 熱を電気に変換する |
| convert a building | 建物を改装する |
| convert a house into apartments | 家を集合住宅に改装する |
| convert land to farmland | 土地を農地に転換する |
| convert to renewable energy | 再生可能エネルギーへ転換する |
| convert to digital | デジタル方式へ移行する |
| convert to Islam | イスラム教に改宗する |
| convert someone to Christianity | 人をキリスト教に改宗させる |
| a religious convert | 改宗者 |
| a recent convert | 最近の転向者 |
| convert customers | 顧客を購入者に転換する |
| convert leads into sales | 見込み客を売上につなげる |
| convert an opportunity | 好機を得点・成果につなげる |
| convert a penalty | ペナルティーキックを決める |
| successfully convert something | 〜の変換に成功する |
| easily convert something | 〜を簡単に変換する |
| be converted into something | 〜に変換される |
| a converted barn | 改装された納屋 |
| conversion rate | コンバージョン率 |

## 要点

`convert A into/to B` は形式・用途・単位などを「変換する」です。宗教の「改宗」や営業上の「成約」にも使います。
