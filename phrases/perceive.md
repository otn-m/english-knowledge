# perceive — 頻出フレーズ

NGSL順位: 2103

| フレーズ・型 | 意味・使い方 |
|---|---|
| perceive something as something | 〜を…と認識する |
| be perceived as something | 〜と見なされる |
| perceive someone as a threat | 人を脅威と見なす |
| perceive something as a problem | 〜を問題と捉える |
| perceive something as unfair | 〜を不公平だと感じる |
| perceive a difference | 違いを認識する |
| perceive a change | 変化に気づく |
| perceive a threat | 脅威を感じ取る |
| perceive a risk | リスクを認識する |
| perceive a need | 必要性を認識する |
| perceive an opportunity | 機会を見いだす |
| perceive the world | 世界を認識する |
| perceive reality | 現実を認識する |
| perceive that ... | 〜だと理解する |
| clearly perceive something | 〜を明確に認識する |
| correctly perceive something | 〜を正しく認識する |
| directly perceive something | 〜を直接知覚する |
| visually perceive something | 〜を視覚的に認識する |
| widely perceived as ... | 〜と広く見なされて |
| generally perceived as ... | 一般に〜と見なされて |
| commonly perceived as ... | 通常〜と認識されて |
| negatively perceived | 否定的に受け取られて |
| positively perceived | 肯定的に受け取られて |
| a perceived threat | 認識された脅威 |
| a perceived need | 認識されている必要性 |
| a perceived lack of something | 〜が不足しているという認識 |
| perceived value | 知覚価値 |
| perceived risk | 知覚リスク |
| difficult to perceive | 認識しにくい |
| perceive yourself as ... | 自分を〜だと認識する |

## 要点

感覚で「知覚する」と、物事を一定の仕方で「認識・理解する」を表します。`perceive A as B` が基本です。
