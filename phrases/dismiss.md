# dismiss — 頻出フレーズ

NGSL順位: 2392

| フレーズ・型 | 意味・使い方 |
|---|---|
| dismiss an employee | 従業員を解雇する |
| dismiss a worker | 労働者を解雇する |
| be dismissed from your job | 仕事を解雇される |
| be unfairly dismissed | 不当に解雇される |
| dismiss someone for misconduct | 不正行為を理由に人を解雇する |
| dismiss a claim | 主張・請求を退ける |
| dismiss a case | 訴訟を棄却する |
| dismiss a lawsuit | 訴訟を棄却する |
| dismiss an appeal | 上訴を棄却する |
| dismiss the charges | 告発・訴追を棄却する |
| dismiss an allegation | 申し立てを退ける |
| dismiss an argument | 議論を退ける |
| dismiss an idea | 考えを一蹴する |
| dismiss a suggestion | 提案を退ける |
| dismiss a proposal | 提案を却下する |
| dismiss a possibility | 可能性を退ける |
| dismiss concerns | 懸念を軽視する |
| dismiss criticism | 批判を一蹴する |
| dismiss something as nonsense | 何かをばかげていると一蹴する |
| dismiss something as irrelevant | 何かを無関係だと退ける |
| easily dismiss | 簡単に退ける |
| summarily dismiss | 即座に退ける・解雇する |
| initially dismiss | 当初は軽視する |
| refuse to dismiss ... | ～を退けることを拒む |
| cannot be dismissed | 無視・否定できない |
| dismiss someone from the room | 人を部屋から退出させる |
| dismiss the class | 授業を終えて学生を解散させる |
| be dismissed early | 早く解散となる |
| wrongful dismissal | 不当解雇 |

## 要点

人を「解雇・退出させる」、訴訟や考えを「退ける・一蹴する」を表します。`dismiss A as B` が重要な型です。
