| フレーズ・型 | 意味・使い方 |
|---|---|

| get a taxi | タクシーをつかまえる・手配する |
| call a taxi | タクシーを呼ぶ |

| catch a taxi | タクシーをつかまえて乗る |
| order a taxi | タクシーを手配する |
| book a taxi | タクシーを予約する |
| wait for a taxi | タクシーを待つ |

| take a taxi home | タクシーで帰宅する |
| take a taxi to the airport | 空港までタクシーで行く |
| a taxi to/from ... | …行き／…発のタクシー |
| a taxi ride | タクシーでの移動 |

## 要点

乗車には `take a taxi`、手配には `call/book a taxi`、路上で止める場合は `hail/flag down a taxi` がよく使われます。
