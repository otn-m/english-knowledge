# lean — 頻出フレーズ

NGSL順位: 1974

| フレーズ・型 | 意味・使い方 |
|---|---|
| lean against a wall | 壁にもたれる |
| lean on someone | 人にもたれる・頼る |
| lean on something | 〜にもたれる |
| lean toward someone | 人の方へ身を傾ける |
| lean forward | 前かがみになる |
| lean back | 後ろにもたれる |
| lean over | 身を乗り出す |
| lean out of a window | 窓から身を乗り出す |
| lean down | 身をかがめる |
| lean to one side | 片側に傾く |
| lean toward an option | ある選択肢に傾く |
| lean in favor of something | 〜を支持する方に傾く |
| a lean body | 引き締まった体 |
| a lean figure | やせて引き締まった体つき |
| lean muscle | 引き締まった筋肉 |
| lean meat | 脂肪の少ない肉 |
| a lean cut of meat | 脂身の少ない肉 |
| a lean diet | 低脂肪の食事 |
| lean production | リーン生産方式 |
| lean manufacturing | 無駄のない生産方式 |
| a lean organization | 無駄の少ない組織 |
| a lean operation | 効率化された業務 |
| a lean year | 不作・不振の年 |
| lean times | 苦しい時期 |
| a lean budget | 切り詰めた予算 |
| a lean season | 不作・閑散期 |
| tall and lean | 背が高く引き締まった |
| strong and lean | 強く引き締まった |
| lean heavily on something | 〜に大きく依存する |
| lean into something | 〜に身を乗り出す・積極的に取り組む |

## 要点

動詞では「傾く・もたれる・頼る」、形容詞では「脂肪や無駄が少ない」を表します。
