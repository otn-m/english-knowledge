# extract — 頻出フレーズ

NGSL順位: 2647

| フレーズ・型 | 意味・使い方 |
|---|---|
| extract information | 情報を取り出す |
| extract data | データを抽出する |
| extract text | 文字列を抽出する |
| extract a file | ファイルを展開する |
| extract files from an archive | アーカイブからファイルを展開する |
| extract a tooth | 歯を抜く |
| have a tooth extracted | 歯を抜いてもらう |
| extract oil | 油を抽出する |
| extract juice | 果汁を搾り取る |
| extract DNA | DNAを抽出する |
| extract a sample | 試料を採取する |
| extract minerals | 鉱物を採取する |
| extract gold | 金を採掘・抽出する |
| extract gas | ガスを採取する |
| extract resources | 資源を採取する |
| extract value from ... | …から価値を引き出す |
| extract meaning from ... | …から意味を読み取る |
| extract a promise | 約束を取り付ける |
| extract a confession | 自白を引き出す |
| extract something from ... | …から何かを取り出す |
| a plant extract | 植物抽出物 |
| vanilla extract | バニラエッセンス |
| yeast extract | 酵母エキス |
| herbal extract | ハーブ抽出物 |
| a natural extract | 天然抽出物 |
| an extract from a book | 本からの抜粋 |
| a short extract | 短い抜粋 |
| read an extract | 抜粋を読む |
| publish an extract | 抜粋を掲載する |
| concentrated extract | 濃縮エキス |

## 要点

動詞では中から「取り出す・抽出する」、名詞では「抽出物・抜粋」を表します。動詞は後ろに `from ...` を伴うことが多い語です。
