# circumstance — 頻出フレーズ

NGSL順位: 1229

| フレーズ・型 | 意味・使い方 |
|---|---|
| under the circumstances | この状況では |
| in the circumstances | この状況では（主に英） |
| under no circumstances | どんな場合にも…ない |
| in no circumstances | どんな場合にも…ない（主に英） |
| under normal circumstances | 通常の状況では |
| under difficult circumstances | 困難な状況下で |
| under unusual circumstances | 異常な状況下で |
| under similar circumstances | 同様の状況下で |
| under certain circumstances | 特定の状況下では |
| in particular circumstances | 特定の状況では |
| in exceptional circumstances | 例外的な状況では |
| given the circumstances | 事情を考慮すれば |

| circumstances beyond your control | 自分では制御できない事情 |
| personal circumstances | 個人的事情 |
| family circumstances | 家庭の事情 |

| changing circumstances | 変化する状況 |

## 要点

ある出来事を取り巻く条件・事情を表し、通常は複数形で使います。`under the circumstances` と強い禁止の `under no circumstances` が重要です。
