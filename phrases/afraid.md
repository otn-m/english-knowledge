# afraid — 頻出フレーズ

NGSL順位: 1353

| フレーズ・型 | 意味・使い方 |
|---|---|
| be afraid of ... | …を恐れている |
| be afraid to do ... | 怖くて…できない |
| be afraid that ... | …ではないかと心配する |
| be afraid for someone | 人の身を心配する |
| I'm afraid so | 残念ながらそうです |
| I'm afraid not | 残念ながら違います・できません |
| I'm afraid I can't ... | 申し訳ありませんが…できません |
| don't be afraid | 怖がらないで |
| not be afraid to ... | 恐れずに…する |
| too afraid to ... | 怖すぎて…できない |
| a little afraid | 少し怖がって |
| very afraid | とても怖がって |

| terribly afraid | ひどく怖がって |

| look afraid | 怖がっているように見える |
| become afraid | 怖くなる |
| make someone afraid | 人を怖がらせる |
| afraid of heights | 高所恐怖で |
| afraid of the dark | 暗闇を怖がって |
| afraid of dogs | 犬を怖がって |
| afraid of failure | 失敗を恐れて |

| deathly afraid of ... | …を死ぬほど怖がって |

## 要点

対象には `afraid of ...`、怖くて行動できない場合は `afraid to do ...` を使います。`I'm afraid ...` は残念な情報を丁寧に伝える表現です。
