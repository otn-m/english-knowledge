| フレーズ・型 | 意味・使い方 |

| enable access to ... | …へのアクセスを可能にする |
| enable communication | コミュニケーションを可能にする |
| enable growth | 成長を可能にする |
| enable change | 変化を可能にする |
| enable development | 発展を可能にする |
| enable learning | 学習を可能にする |
| enable participation | 参加を可能にする |
| enable recovery | 回復を可能にする |

| enable a feature | 機能を有効にする |
| enable a function | 機能を有効にする |
| enable an option | オプションを有効にする |
| enable a service | サービスを有効にする |
| enable users to ... | 利用者が…できるようにする |
| fully enable ... | …を完全に有効にする |
| automatically enable ... | …を自動的に有効にする |

## 要点

人・仕組みが行動できるようにすることと、設定・機能を有効にすることを表します。基本構文は `enable someone to do ...` です。
