# conclude — 頻出フレーズ

| フレーズ・型 | 意味・使い方 |
|---|---|

| conclude from ... that ... | ～から…だと結論づける |
| conclude by doing | ～して締めくくる |
| conclude with ... | ～で締めくくる |
| conclude on a positive note | 前向きな形で締めくくる |
| conclude a deal | 取引を成立させる |
| conclude an agreement | 合意を締結する |

| conclude negotiations | 交渉を終える／妥結する |
| conclude an investigation | 調査を終了する |

## 要点

`conclude` には「結論づける」と「終える・締結する」の二つの中心義がある。判断では `conclude that ...`、文章や発表の締めでは `conclude with/by ...` が特によく使われる。
