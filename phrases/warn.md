# warn — 頻出フレーズ

NGSL順位: 1132

| フレーズ・型 | 意味・使い方 |
|---|---|
| warn someone about ... | 人に…について警告する |
| warn someone of ... | 人に…を警告する |
| warn someone against ... | 人に…をしないよう警告する |
| warn someone not to do ... | 人に…しないよう警告する |
| warn someone to do ... | 人に…するよう注意する |
| warn that ... | …だと警告する |
| warn of danger | 危険を警告する |
| warn of the risks | リスクを警告する |
| warn about possible delays | 遅延の可能性を警告する |
| repeatedly warn ... | …に繰り返し警告する |
| clearly warn ... | …にはっきり警告する |
| publicly warn ... | …に公に警告する |
| be warned about ... | …について警告を受ける |
| be warned not to ... | …しないよう警告される |
| I must warn you ... | 念のため警告しますが… |
| do not say I did not warn you | 忠告しなかったとは言わせない |
| experts warn that ... | 専門家は…と警告する |
| police warn residents ... | 警察が住民に警告する |
| a warning sign | 警告サイン |
| an early warning | 早期警告 |
| a severe weather warning | 悪天候警報 |
| issue a warning | 警告を出す |
| give someone a warning | 人に警告する |
| heed a warning | 警告に従う |
| ignore a warning | 警告を無視する |
| without warning | 予告なく |
| a word of warning | 一言忠告 |
| warn someone in advance | 人に前もって警告する |
| warn against complacency | 油断しないよう警告する |
| warn of consequences | 結果について警告する |
| warn people away | 人々に近寄らないよう警告する |
| fair warning | 前もっての十分な警告 |

## 要点

対象には `warn someone about/of ...`、禁止には `warn someone against/not to ...`、節には `warn that ...` を使います。
