# guilty — 頻出フレーズ

| フレーズ・型 | 意味・使い方 |
|---|---|
| feel guilty | 罪悪感を覚える |
| feel guilty about something | 〜について罪悪感を覚える |
| feel guilty for doing something | 〜したことを申し訳なく思う |
| look guilty | やましそうに見える |
| a guilty conscience | やましい良心 |
| a guilty feeling | 罪悪感 |
| a guilty look | やましそうな表情 |
| a guilty smile | やましそうな笑み |
| guilty of a crime | 犯罪について有罪で |
| be found guilty | 有罪判決を受ける |

| a guilty verdict | 有罪評決 |
| the guilty party | 責任のある者 |

| make someone feel guilty | 人に罪悪感を抱かせる |

## 要点

法律上「有罪の」と、日常的に「罪悪感・やましさを感じる」を表します。`feel guilty about ...` が会話で頻出します。
