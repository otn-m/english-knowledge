# charge — 頻出フレーズ

NGSL順位: 498

| フレーズ・型 | 意味・使い方 |
|---|---|
| charge a fee | 料金を請求する |
| charge $10 | 10ドル請求する |
| charge someone for ... | 人に～の料金を請求する |
| charge something to an account | ～を口座につける |
| charge a battery | バッテリーを充電する |
| charge a phone | 携帯電話を充電する |
| charge someone with ... | 人を～の罪で起訴する |
| be charged with murder | 殺人罪で起訴される |
| charge at someone | 人に突進する |
| a service charge | サービス料 |
| an extra charge | 追加料金 |
| a delivery charge | 配送料 |
| a monthly charge | 月額料金 |
| free of charge | 無料で |
| at no extra charge | 追加料金なしで |
| pay a charge | 料金を支払う |
| face charges | 起訴・容疑に直面する |
| press charges | 告訴する |
| drop the charges | 起訴を取り下げる |
| criminal charges | 刑事告発 |
| a serious charge | 重大な容疑 |
| in charge | 責任者で |
| in charge of ... | ～を担当して |
| take charge | 主導権を握る |
| take charge of ... | ～を引き受ける |
| put someone in charge | 人を責任者にする |
| leave someone in charge | 人に任せる |
| under someone's charge | 人の管理下で |
| a charge against someone | 人に対する告発 |
| electric charge | 電荷 |
| positive charge | 正電荷 |
| negative charge | 負電荷 |
| charge up | 充電する |
| admission charge | 入場料 |
| cover charge | 席料 |

## 要点

料金請求・充電・起訴・突進を表す。責任者は `in charge of`、主導権を握るなら `take charge`。
