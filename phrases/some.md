| some of us | 私たちの一部・何人か |
| some of them | それら・彼らの一部 |
| some people | 一部の人々 |

| some day | いつか |

| some say that ... | …だと言う人もいる |

## 要点

肯定文で不特定の量・数を表すほか、勧誘や依頼では疑問文でも `some` を使います。`some of ...` と `for some reason` は特に頻出です。
