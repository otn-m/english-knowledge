# afford — 頻出フレーズ

NGSL順位: 1488

| フレーズ・型 | 意味・使い方 |
|---|---|

| cannot afford ... | ～を買う余裕がない |
| can afford to do | ～する余裕がある |
| cannot afford to do | ～する余裕がない |
| can barely afford ... | ～を買う余裕がほとんどない |
| can hardly afford ... | ～する余裕がほとんどない |
| can easily afford ... | ～を楽に買える |
| be able to afford ... | ～を買う余裕がある |
| afford a house | 家を買う余裕がある |
| afford a car | 車を買う余裕がある |
| afford the rent | 家賃を払う余裕がある |
| afford the cost | その費用を負担できる |
| afford health care | 医療費を負担できる |
| afford an education | 教育費を払える |
| afford a vacation | 休暇旅行をする余裕がある |
| afford to buy ... | ～を買う余裕がある |
| afford to pay ... | ～を支払う余裕がある |

## 要点

通常は `can/can't afford + 名詞/to do` の形で使う。お金だけでなく、時間・損失・危険を受け入れる余裕にも用いる。
