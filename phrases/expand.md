# expand — 頻出フレーズ

NGSL順位: 1321

| フレーズ・型 | 意味・使い方 |
|---|---|
| expand a business | 事業を拡大する |
| expand operations | 事業活動を拡大する |
| expand a market | 市場を拡大する |
| expand market share | 市場占有率を伸ばす |
| expand a product range | 製品の品ぞろえを広げる |
| expand services | サービスを拡充する |
| expand production | 生産を拡大する |
| expand capacity | 能力・容量を拡大する |
| expand the workforce | 従業員数を増やす |
| expand a team | チームを拡大する |
| expand a network | ネットワークを拡大する |
| expand a program | プログラムを拡充する |
| expand access to ... | …へのアクセスを広げる |
| expand your knowledge | 知識を広げる |
| expand your vocabulary | 語彙を増やす |
| expand into ... | …の分野・地域へ進出する |
| expand to include ... | …を含むよう拡大する |
| expand by ... percent | …％拡大する |
| expand rapidly | 急速に拡大する |
| expand significantly | 大幅に拡大する |
| expand gradually | 徐々に拡大する |
| continue to expand | 拡大し続ける |
| plan to expand | 拡大を計画する |
| seek to expand | 拡大しようとする |
| help expand ... | …の拡大に役立つ |
| an opportunity to expand | 拡大する機会 |
| expand on/upon ... | …をさらに詳しく説明する |
| expand your horizons | 視野を広げる |
| the universe expands | 宇宙が膨張する |
| metal expands when heated | 金属は熱すると膨張する |
| expand globally | 世界的に拡大する |

## 要点

事業・範囲を拡大することと、物質が膨張することを表します。分野への進出は `expand into`、説明の追加は `expand on/upon` です。
