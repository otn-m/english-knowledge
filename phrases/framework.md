# framework — 頻出フレーズ

| フレーズ・型 | 意味・使い方 |
|---|---|
| a legal framework | 法的枠組み |
| a regulatory framework | 規制の枠組み |
| a policy framework | 政策の枠組み |
| an institutional framework | 制度的枠組み |
| a conceptual framework | 概念的枠組み |
| a theoretical framework | 理論的枠組み |
| an analytical framework | 分析の枠組み |
| a general framework | 一般的な枠組み |
| a common framework | 共通の枠組み |
| a comprehensive framework | 包括的な枠組み |
| a clear framework | 明確な枠組み |
| a flexible framework | 柔軟な枠組み |
| an existing framework | 既存の枠組み |
| a basic framework | 基本的な骨組み |
| a development framework | 開発の枠組み |
| a security framework | セキュリティの枠組み |
| a software framework | ソフトウェアフレームワーク |
| within the framework | その枠組みの中で |
| within the framework of something | 〜の枠組みの中で |
| under the current framework | 現行の枠組みの下で |
| provide a framework for something | 〜の枠組みを提供する |
| establish a framework | 枠組みを確立する |
| create a framework | 枠組みを作る |
| develop a framework | 枠組みを策定する |
| adopt a framework | 枠組みを採用する |
| use a framework | 枠組みを用いる |
| apply a framework | 枠組みを適用する |
| strengthen the framework | 枠組みを強化する |
| the framework of a building | 建物の骨組み |
| a framework agreement | 枠組み協定 |

## 要点

建物の「骨組み」から、法律・政策・理論などを整理する「枠組み」まで広く使います。
