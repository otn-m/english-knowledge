| フレーズ・型 | 意味・使い方 |
|---|---|
| develop a product | 製品を開発する |
| develop a system | システムを開発する |
| develop a plan | 計画を策定する |
| develop a strategy | 戦略を立てる |
| develop a method | 方法を開発する |
| develop a theory | 理論を発展させる |
| develop a model | モデルを開発する |
| develop a program | プログラムを開発する |
| develop software | ソフトウェアを開発する |
| develop technology | 技術を開発する |
| develop skills | 技能を身につける |
| develop knowledge | 知識を深める |
| develop an interest in ... | ～への興味を持つようになる |
| develop a habit | 習慣が身につく |
| develop a relationship | 関係を築く |
| develop confidence | 自信をつける |
| develop a problem | 問題が生じる |
| develop symptoms | 症状が出る |
| develop a disease | 病気を発症する |
| develop cancer | がんを発症する |
| develop into ... | 発展して～になる |
| develop from ... | ～から発展する |
| develop over time | 時間とともに発達する |
| fully develop | 十分に発達する |
| rapidly develop | 急速に発展する |
| continue to develop | 発展し続ける |
| be developed by ... | ～によって開発される |
| develop land | 土地を開発する |
| develop a film | フィルムを現像する |
| develop an idea | アイデアを練る |
| develop a market | 市場を開拓する |
| develop the economy | 経済を発展させる |
| develop further | さらに発展する |
| a developing country | 発展途上国 |
| a well-developed system | 高度に発達したシステム |

## 要点

他動詞では開発・育成、自動詞では発達・発症を表す。変化先は `develop into ...`。
