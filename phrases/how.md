# how — 頻出フレーズ

NGSL順位: 93

| フレーズ・型 | 意味・使い方 |
|---|---|
| How are you? | お元気ですか |
| How are things? | 調子はどうですか |
| How is it going? | 調子はどうですか |
| How do you do? | はじめまして（非常に改まった表現） |
| How about ...? | ～はどうですか |
| How about doing ...? | ～するのはどうですか |
| How come? | どうして |
| How so? | どういう点でですか |

| learn how to do | ～の仕方を学ぶ |

| How did it go? | どうでしたか |
| How was your day? | 今日はどうでしたか |

| I don't know how. | 方法が分かりません |

## 要点

間接疑問は平叙文語順。`Do you know how it works?` であり、`how does it work` にはしない。
