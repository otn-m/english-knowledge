# complain — 頻出フレーズ

NGSL順位: 1495

| フレーズ・型 | 意味・使い方 |
|---|---|
| complain about ... | ～について不平を言う |
| complain of ... | ～の症状を訴える |
| complain to someone | 人に苦情を言う |
| complain that ... | ～だと不満を述べる |
| complain about the service | サービスについて苦情を言う |
| complain about the noise | 騒音について苦情を言う |
| complain about the food | 食事について不満を言う |
| complain about the price | 価格について不平を言う |
| complain about the weather | 天気について愚痴を言う |
| complain of pain | 痛みを訴える |
| complain of a headache | 頭痛を訴える |
| complain to the manager | 管理者に苦情を言う |
| complain to the police | 警察に訴える |
| complain in writing | 書面で苦情を申し立てる |
| formally complain | 正式に苦情を申し立てる |
| constantly complain | 絶えず不平を言う |
| always complain | いつも文句を言う |
| bitterly complain | 激しく不満を訴える |
| publicly complain | 公に不満を表す |
| begin to complain | 文句を言い始める |
| have reason to complain | 苦情を言う理由がある |
| no one can complain | 誰も文句は言えない |
| I can't complain. | まあ順調です／悪くありません |
| stop complaining | 文句を言うのをやめる |
| without complaining | 文句を言わずに |
| a customer complaint | 顧客からの苦情 |
| file a complaint | 苦情・訴えを申し立てる |
| make a complaint | 苦情を申し立てる |
| handle a complaint | 苦情に対応する |
| complaints procedure | 苦情処理手続き |
| complain about doing ... | ～することについて不平を言う |

## 要点

一般的な不満は `complain about ...`、身体症状は `complain of ...`、苦情の相手は `complain to someone` と使い分ける。
