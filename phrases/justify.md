# justify — 頻出フレーズ

NGSL順位: 2122

| フレーズ・型 | 意味・使い方 |
|---|---|
| justify a decision | 決定の正当性を説明する |
| justify an action | 行動を正当化する |
| justify a policy | 政策を正当化する |
| justify the cost | 費用に見合う根拠を示す |
| justify the expense | 出費を正当化する |
| justify the price | 価格に見合う価値を示す |
| justify the use of force | 武力行使を正当化する |
| justify your behavior | 自分の行動を正当化する |
| justify your choice | 自分の選択の理由を示す |
| justify your answer | 答えの根拠を示す |
| justify your position | 自分の立場を正当化する |
| justify a claim | 主張の根拠を示す |
| justify an assumption | 前提の妥当性を示す |
| justify the conclusion | 結論の妥当性を示す |
| justify doing something | 〜することを正当化する |
| be justified in doing something | 〜するのは正当である |
| be fully justified | 完全に正当化される |
| be morally justified | 道徳的に正当化される |
| be legally justified | 法的に正当化される |
| difficult to justify | 正当化しにくい |
| hard to justify | 理由づけしにくい |
| seek to justify something | 〜を正当化しようとする |
| attempt to justify something | 〜を正当化しようと試みる |
| fail to justify something | 〜を正当化できない |
| nothing can justify something | 何をもってしても〜は正当化できない |
| evidence justifies concern | 証拠から懸念は妥当である |
| results justify the effort | 結果が努力に見合う |
| justify text | 文章を両端揃えにする |
| left-justified text | 左揃えの文章 |
| the end justifies the means | 目的は手段を正当化する |

## 要点

行動・判断の「正当な理由を示す」と、費用や努力に「見合う」を表します。文書では文字を揃える意味もあります。
