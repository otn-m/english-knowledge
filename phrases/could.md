# could — 頻出フレーズ

NGSL順位: 66

| フレーズ・型 | 意味・使い方 |
|---|---|
| could be | ～かもしれない |
| could have | ～した可能性がある |
| could do | ～できた／～してもよい |
| could help | 助けになるかもしれない |
| could mean | ～を意味するかもしれない |
| could lead to | ～につながる可能性がある |
| could result in | ～という結果になり得る |
| could happen | 起こり得る |
| could easily | 容易に～しかねない |
| could still | まだ～の可能性がある |
| could never | どうしても～できない |
| could hardly | ほとんど～できなかった |
| could not help doing | ～せずにはいられなかった |
| could have done | ～できたのに／～した可能性がある |
| could have been | ～だった可能性がある |
| could have gone | 行くこともできたのに |
| I could do that. | それならできるかもしれません |
| I could be wrong. | 私が間違っているかもしれません |
| I could use ... | ～があると助かります |
| I couldn't agree more. | まったく同感です |
| Could I ...? | ～してもよいでしょうか |
| Could I have ...? | ～をいただけますか |
| Could you ...? | ～していただけますか |
| Could you help me? | 手伝っていただけますか |
| Could you tell me ...? | ～を教えていただけますか |
| Could you say that again? | もう一度言っていただけますか |
| Could you speak more slowly? | もう少しゆっくり話していただけますか |
| Could we ...? | ～しませんか／～できますか |
| How could I ...? | どうすれば～できるでしょう |
| What could go wrong? | 何が問題になり得ますか |
| Who could have known? | 誰に分かっただろう |
| It could be better. | もっと良くなり得る／いまひとつだ |
| It could be worse. | もっと悪い可能性もある／まだましだ |
| Nothing could be further from the truth. | 事実とはまったく違う |

## 要点

`could` は過去の能力、控えめな可能性、丁寧な依頼に使う。依頼では `can` より丁寧。
