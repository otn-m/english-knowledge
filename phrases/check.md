# check — 頻出フレーズ

NGSL順位: 580

| フレーズ・型 | 意味・使い方 |
|---|---|
| check ... | …を確認する、点検する |
| check that ... | …であることを確認する |
| check whether ... | …かどうか確認する |
| check to see if ... | …かどうか確認する |
| check the time | 時間を確認する |
| check the date | 日付を確認する |
| check your email | メールを確認する |
| check your phone | 携帯を確認する |
| check the website | ウェブサイトを確認する |
| check the details | 詳細を確認する |
| check the facts | 事実を確認する |
| check your work | 自分の作業を見直す |
| check your spelling | スペルを確認する |
| check the weather | 天気を確認する |
| check the schedule | 予定を確認する |
| check someone's ID | 人の身分証を確認する |
| check for errors | 間違いがないか調べる |
| check for updates | 更新がないか確認する |
| check on ... | …の様子・進捗を確認する |
| check with someone | 人に確認する |
| check in | チェックインする、到着を知らせる |
| check in at ... | …でチェックインする |
| check into a hotel | ホテルにチェックインする |
| check out | チェックアウトする、調べる |
| check out of a hotel | ホテルをチェックアウトする |
| check ... out | …を調べる、見てみる |
| double-check ... | …を再確認する |
| keep ... in check | …を抑制する |
| a quick check | 簡単な確認 |
| a routine check | 定期点検 |
| a background check | 身元調査 |
| a security check | 保安検査 |
| a health check | 健康診断 |
| a reality check | 現実を認識させる出来事 |
| check the box | チェック欄に印を付ける |

## 要点

`check ...` は対象を直接続けられます。人に確認するなら `check with someone`、様子を見るなら `check on ...` です。
