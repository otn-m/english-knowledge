# test — 頻出フレーズ

NGSL順位: 332

| フレーズ・型 | 意味・使い方 |
|---|---|
| take a test | テストを受ける |
| sit a test | テストを受ける（主に英） |
| pass a test | テストに合格する |
| fail a test | テストに落ちる |
| study for a test | テスト勉強をする |
| prepare for a test | テストに備える |
| give someone a test | 人にテストを受けさせる |
| a written test | 筆記試験 |
| a driving test | 運転試験 |
| a blood test | 血液検査 |
| a medical test | 医学的検査 |
| a pregnancy test | 妊娠検査 |
| a drug test | 薬物検査 |
| a diagnostic test | 診断検査 |
| a test result | 検査結果 |
| test score | テストの点数 |
| test data | 試験データ |
| test case | テストケース／判例 |
| test method | 試験方法 |
| put something to the test | ～を試す |
| stand the test of time | 時の試練に耐える |
| a test of strength | 力試し |
| a test of character | 人格が試される出来事 |

| test positive for ... | ～の検査で陽性となる |
| test negative for ... | ～の検査で陰性となる |

## 要点

試験を受けるなら `take a test`、合否は `pass/fail`。医療では `test positive/negative for` が頻出。
