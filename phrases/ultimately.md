# ultimately — 頻出フレーズ

NGSL順位: 2020

| フレーズ・型 | 意味・使い方 |
|---|---|
| ultimately depend on something | 最終的には〜に依存する |
| ultimately result in something | 最終的に〜という結果になる |
| ultimately lead to something | 最終的に〜につながる |
| ultimately determine something | 最終的に〜を決定する |
| ultimately decide something | 最終的に〜を決める |
| ultimately succeed | 最終的に成功する |
| ultimately fail | 最終的に失敗する |
| ultimately become something | 最終的に〜になる |
| ultimately prove something | 最終的に〜を証明する |
| ultimately achieve something | 最終的に〜を達成する |
| ultimately win | 最終的に勝つ |
| ultimately lose | 最終的に負ける |
| ultimately return | 最終的に戻る |
| ultimately accept something | 最終的に〜を受け入れる |
| ultimately reject something | 最終的に〜を拒否する |
| ultimately choose something | 最終的に〜を選ぶ |
| ultimately responsible | 最終的な責任がある |
| ultimately accountable | 最終的に説明責任がある |
| ultimately based on something | 最終的には〜に基づく |
| ultimately derived from something | 最終的に〜に由来する |
| ultimately caused by something | 最終的には〜が原因である |
| ultimately controlled by something | 最終的には〜に支配される |
| ultimately owned by someone | 最終的には人が所有する |
| ultimately a matter of ... | 結局は…の問題 |
| ultimately the same | 結局は同じ |
| ultimately impossible | 最終的には不可能な |
| ultimately unsuccessful | 最終的には不成功の |
| ultimately, the question is ... | 結局、問題は… |

| ultimately, what matters is ... | 結局、重要なのは… |

## 要点

長い過程の「最終的には」と、議論をまとめる「結局」を表します。
