# fail — 頻出フレーズ

NGSL順位: 711

| フレーズ・型 | 意味・使い方 |
|---|---|
| fail to do ... | …しない、…できない |
| fail to appear | 現れない |
| fail to arrive | 到着しない |
| fail to notice ... | …に気づかない |
| fail to understand ... | …を理解できない |
| fail to recognize ... | …を認識できない |
| fail to meet ... | …を満たさない |
| fail to meet expectations | 期待に応えられない |
| fail to provide ... | …を提供できない |
| fail to prevent ... | …を防げない |
| fail to respond | 応答しない |
| fail to act | 行動しない |
| fail an exam | 試験に落ちる |
| fail a test | テストに落ちる |
| fail a course | 科目の単位を落とす |
| fail a student | 学生を不合格にする |
| fail badly | 大失敗する |
| fail completely | 完全に失敗する |
| fail miserably | 惨めに失敗する |
| never fail | 決して失敗しない |
| be likely to fail | 失敗しそうである |
| be bound to fail | 失敗するに決まっている |
| try and fail | 試みて失敗する |
| succeed or fail | 成功するか失敗するか |
| a plan fails | 計画が失敗する |
| a business fails | 事業が破綻する |
| an engine fails | エンジンが故障する |
| your health fails | 健康が衰える |
| words fail me | 言葉もない |
| without fail | 必ず |
| fail-safe | 故障しても安全な |
| fail in your duty | 義務を果たせない |
| fail for lack of ... | …不足のため失敗する |
| fail under pressure | 圧力に耐えられず失敗する |
| fail someone when needed | 必要なときに人の役に立てない |

## 要点

動作には `fail to do ...`、試験には `fail an exam`、機械や事業が機能しなくなる場合にも `fail` を使います。
