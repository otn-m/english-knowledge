# none — 頻出フレーズ

NGSL順位: 1014

| フレーズ・型 | 意味・使い方 |
|---|---|
| none of ... | …のどれも・誰も…ない |
| none of us | 私たちの誰も…ない |
| none of them | それら・彼らのどれも…ない |
| none of you | あなた方の誰も…ない |
| none of these | これらのどれも…ない |
| none of those | それらのどれも…ない |
| none of the above | 上記のどれにも該当しない |
| none of the following | 以下のどれにも該当しない |
| none of your business | あなたには関係ない |
| none at all | 一つも・誰もまったくない |
| almost none | ほとんど一つもない |

| none left | 一つも残っていない |

| none whatsoever | まったく一つもない |

## 要点

`none of + 複数名詞・代名詞` が基本です。動詞は文脈により単数・複数の両方が使われます。`second to none` は「最高水準の」という重要表現です。
