# to — 頻出フレーズ

NGSL順位: 5

不定詞の `to` と前置詞の `to` の両方を含む。後ろが動詞原形になる型と、名詞・動名詞になる型を区別して覚える。

| フレーズ・型 | 意味・使い方 |
|---|---|
| want to do | ～したい |
| need to do | ～する必要がある |
| have to do | ～しなければならない |
| be going to do | ～するつもりだ／～しそうだ |
| would like to do | ～したい（丁寧） |
| used to do | 以前はよく～した／～だった |
| be able to do | ～することができる |
| be supposed to do | ～することになっている |
| be likely to do | ～する可能性が高い |
| be about to do | まさに～しようとしている |
| in order to do | ～するために |
| so as to do | ～するために（やや硬い） |
| too ... to do | ～すぎて…できない |
| enough to do | ～するのに十分…である |
| know how to do | ～の仕方を知っている |
| what to do | 何をすべきか |
| to be honest | 正直に言うと |
| to tell the truth | 本当のことを言うと |
| to some extent | ある程度 |
| to date | 現在まで |
| to my surprise | 驚いたことに |
| according to | ～によれば／～に従って |
| due to | ～が原因で／～のために |
| thanks to | ～のおかげで |
| up to | 最大～まで／～次第で |
| next to | ～の隣に |
| close to | ～の近くに／もう少しで～ |
| in addition to | ～に加えて |
| as opposed to | ～とは対照的に／～ではなく |
| from A to B | AからBまで |
| prefer A to B | BよりAを好む |
| look forward to doing | ～するのを楽しみにする |
| be used to doing | ～することに慣れている |
| get used to doing | ～することに慣れる |
| lead to | ～につながる／～を引き起こす |
| belong to | ～に属する |
| listen to | ～を聴く |
| happen to do | たまたま～する |

## 要点

- `look forward to`、`be used to`、`get used to` の `to` は前置詞なので、後ろは名詞または `doing`。
- `used to do` は過去の習慣、`be going to do` は意図または根拠のある予測。
- `according to me` は通常不自然。自分の意見には `in my opinion` を使う。
