# disturb — 頻出フレーズ

NGSL順位: 2272

| フレーズ・型 | 意味・使い方 |
|---|---|
| disturb someone | 人の邪魔をする |
| disturb the neighbors | 近所の人に迷惑をかける |
| disturb a patient | 患者を起こす・邪魔する |
| disturb someone's sleep | 人の睡眠を妨げる |
| disturb the peace | 平穏を乱す |
| disturb the silence | 静寂を破る |
| disturb the balance | 均衡を乱す |
| disturb the natural environment | 自然環境を乱す |
| disturb wildlife | 野生動物を脅かす |
| disturb a crime scene | 犯行現場を荒らす |
| do not disturb | 邪魔をしないでください |
| sorry to disturb you | お邪魔してすみません |

| try not to disturb someone | 人の邪魔をしないようにする |
| easily disturbed | 簡単に乱される |
| be disturbed by noise | 騒音に悩まされる |
| be disturbed by something | 〜に不安を覚える |
| deeply disturb someone | 人をひどく不安にさせる |
| greatly disturb someone | 人を大いに動揺させる |
| something disturbs me | 何かが私を不安にさせる |
| disturb someone's concentration | 人の集中を妨げる |

| disturb the soil | 土をかき乱す |

| a disturbed mind | 乱れた精神状態 |

## 要点

人の休息・集中を「邪魔する」、秩序を「乱す」、人を精神的に「不安にさせる」を表します。
