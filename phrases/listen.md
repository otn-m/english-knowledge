# listen — 頻出フレーズ

NGSL順位: 573

| フレーズ・型 | 意味・使い方 |
|---|---|
| listen to ... | …を聞く |
| listen to music | 音楽を聴く |
| listen to the radio | ラジオを聴く |
| listen to a podcast | ポッドキャストを聴く |
| listen to the news | ニュースを聞く |
| listen to someone | 人の話を聞く |
| listen to what someone says | 人の言うことを聞く |
| listen carefully | 注意深く聞く |
| listen closely | よく耳を傾ける |
| listen attentively | 注意を傾けて聞く |
| listen quietly | 静かに聞く |
| just listen | とにかく聞く |
| sit and listen | 座って話を聞く |
| stop and listen | 立ち止まって耳を澄ます |
| listen for ... | …が聞こえるか注意して聞く |
| listen for your name | 自分の名前が呼ばれるのを聞き取ろうとする |
| listen out for ... | …を聞き逃さないよう注意する |
| listen in | 盗み聞きする、放送を聴く |
| listen in on ... | …を盗み聞きする |
| listen up | よく聞いて |
| listen here | いいか、よく聞け |
| listen to reason | 道理を聞き入れる |
| refuse to listen | 聞こうとしない |
| be willing to listen | 話を聞く気がある |
| learn to listen | 人の話を聞くことを学ぶ |
| take time to listen | 時間を取って話を聞く |
| listen with interest | 興味を持って聞く |
| listen with care | 注意を払って聞く |
| listen to advice | 助言に耳を傾ける |
| listen to your body | 自分の体の声に耳を傾ける |
| listen to your heart | 自分の心に従う |
| listen to both sides | 双方の言い分を聞く |
| listen and learn | よく聞いて学ぶ |
| nobody listens | 誰も話を聞いてくれない |
| thanks for listening | 聞いてくれてありがとう |

## 要点

対象には前置詞 `to` が必要です。`listen for ...` は「聞こえるか注意する」、`listen to ...` は実際に「…を聞く」です。
