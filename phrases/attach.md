# attach — 頻出フレーズ

NGSL順位: 1742

| フレーズ・型 | 意味・使い方 |
|---|---|
| attach something to something | 〜を…に取り付ける |

| attach a tag | タグを付ける |
| attach a photo | 写真を添付する |
| attach a file | ファイルを添付する |
| attach a document | 文書を添付する |
| attach a copy | コピーを添付する |
| attach a link | リンクを添付する |
| attach a note | メモを添える |
| attach a list | 一覧を添付する |

| attach your signature | 署名を付す |

| I've attached ... | …を添付しました |
| see the attached file | 添付ファイルを参照してください |
| attach importance to something | 〜を重視する |
| attach significance to something | 〜に重要性を認める |
| attach value to something | 〜に価値を置く |
| attach meaning to something | 〜に意味を持たせる |

## 要点

物を「取り付ける」、メールに「添付する」、価値を「付与する」が中心です。`be attached to` は愛着も表します。
