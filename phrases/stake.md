# stake — 頻出フレーズ

NGSL順位: 2525

| フレーズ・型 | 意味・使い方 |
|---|---|
| have a stake in ... | ～に利害関係がある |
| own a stake in a company | 会社の持ち分を所有する |
| buy a stake | 株式・持ち分を買う |
| acquire a stake | 株式・持ち分を取得する |
| sell a stake | 株式・持ち分を売却する |
| increase your stake | 持ち株比率を増やす |
| reduce your stake | 持ち株比率を減らす |
| a majority stake | 過半数の株式 |
| a minority stake | 少数持ち分 |
| a controlling stake | 支配株式 |
| a 20 percent stake | 20パーセントの持ち分 |
| a financial stake | 金銭的利害関係 |
| at stake | 危機にさらされて・懸かって |
| lives are at stake | 人命が懸かっている |
| a lot is at stake | 多くのものが懸かっている |
| put something at stake | 何かを危険にさらす |
| raise the stakes | 賭け金・緊張を高める |
| high stakes | 大きな賭け・重大な利害 |
| a high-stakes game | 大きなものが懸かった試合 |
| a stake in the outcome | 結果への利害関係 |
| have no stake in ... | ～に利害関係がない |
| place a stake in the ground | 杭を地面に打つ |
| drive a stake into the ground | 地面に杭を打ち込む |
| tie something to a stake | 物を杭につなぐ |
| burn at the stake | 火あぶりにする |
| a wooden stake | 木の杭 |
| gamble your stake | 賭け金を賭ける |
| stake money on ... | ～に金を賭ける |
| stake a claim | 権利を主張する |
| stake out a position | 立場を明確にする |

## 要点

会社の「持ち分」、賭けや結果に懸かる「利害」、地面に打つ「杭」を表します。`at stake` は最重要表現です。
